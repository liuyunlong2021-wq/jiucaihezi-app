# JC Raw Wiki 剧本实体双链设计

> 日期：2026-07-24
> 范围：`public/skills/jc-raw-wiki/references/能力标准/双链与Obsidian.md`

## 目标

让 `jc-raw-wiki` 根据固定剧本格式，将每场实际使用的角色、场景和道具与本集正文建立可验证的双链。只增强双链标准，不改变剧本格式、Wiki 骨架或其它 Wiki Skill 职责。

## 唯一识别入口

固定场次头中的三行是实体识别的唯一依据：

```markdown
场景：[[wiki/场景/顾家客厅]]
人物：[[wiki/角色/林风]] [[wiki/角色/顾晚]]
道具：[[wiki/道具/离婚协议]]
```

不扫描台词角色名、动作描写或正文自然语言补链接。`道具：无` 等明确空值不创建实体或链接。

## 双链合同

1. 保留场次头中指向实体档案的现有链接；链接目标不存在时，根据正文中已确认的信息创建最小档案。
2. 每个被场次头引用的角色、场景和道具档案必须回链本集正文。
3. 同一实体在同一集的档案中只保留一条本集回链；实体出现在多场时不重复追加。
4. 实体档案已有适合的出场章节时增量追加；没有时创建 `## 出现集数`。不得覆盖或重排档案其它内容。
5. 正文已有链接路径是实体目标的唯一事实源，不猜测扁平文件或多级目录结构。

回链格式：

```markdown
## 出现集数

- [[wiki/剧本/第1集]]
```

## 验证

完成后逐项检查：

1. 每个场次头的场景、人物和道具实体均使用有效 Wiki 链接；明确空值除外。
2. 每个链接目标存在，或已在本轮创建最小档案。
3. 每个被引用实体档案都包含本集回链，且同一集没有重复回链。
4. 台词、动作描写和非场次头正文未因本次双链处理被改写。

## 非目标

- 不在台词中的角色名上增加链接。
- 不新增每集角色、场景、道具汇总区。
- 不创建实体首页或改变现有 Wiki 目录结构。
- 不生成 Canvas、Bases 或其它派生产物。
