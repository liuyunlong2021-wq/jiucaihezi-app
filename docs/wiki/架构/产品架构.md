# 通用记忆工作台产品架构

> 更新：2026-08-05
> 现行依据：[[开发/通用记忆工作台单产品化分离SDD]]、[[开发/通用记忆对话独立App SDD]]

## 1. 唯一产品边界

本仓库只保留通用记忆工作台：**记忆工作台现在拥有的全部功能都保留；记忆工作台现在没有的功能全部迁出。**

归属判断按记忆入口的实际依赖闭包进行：从默认 `src/App.vue`、各平台入口、Gateway、同步服务、发布配置和门禁测试出发，直接或间接可达且维持现有能力所必需的代码、资源、配置、Skill 和服务都属于记忆工作台。模块名中出现 `Studio`、`OpenCode`、`creation` 或历史产品词，不能成为移动或删除依据。

OpenCode 产品、旧 Studio、文/武/道/创模式、电商、漫剧和制作工作台属于迁出范围。它们的 SDD 是历史与迁出依据，不再定义当前产品。

## 2. 当前能力闭包

- 项目中心、项目文件树、Raw 对话、快速/记忆模式和完整 Wiki 能力。
- 项目内受限读写、附件、文档转换、站内预览、Markdown 阅读编辑。
- 标准 `.canvas` 项目地图、`.jccanvas` 创作画布、Desktop `.jcscene` 与 MP4 导出。
- 对话内图片、视频、音频生成及既有媒体任务链路。
- 登录、Provider、模型、用户 Skill、系统 Skill、MCP、审批和账号能力。
- Desktop、Web、Mobile 当前已经具备的平台差异能力。
- 文字云覆盖、Gateway、Web Production、桌面更新与移动端发布基础设施。

上述能力保留现有共享基础设施；旧产品专属代码已经迁出，分离门禁阻止其重新进入默认产品。

## 3. 平台边界

| 平台 | 当前保留边界 |
| --- | --- |
| Desktop | 完整记忆工作台、本机项目、项目工具、文档转换、用户 Skill/MCP、本地模型、`.jcscene` 和 FFmpeg MP4 导出 |
| Web | 浏览器项目存储、快速/记忆对话、完整 Wiki、项目内受限读写、附件/文档转换、预览、`.canvas` / `.jccanvas` 和云媒体 |
| Mobile | App 管理目录、快速/记忆对话、完整 Wiki、项目内受限读写、附件/文档转换、预览、`.canvas` / `.jccanvas` 和云媒体；平台布局与账号合规入口按现行实现保留 |

平台能力不要求完全相同，但任何平台现有的记忆工作台功能都不能因分离减少。

## 4. 数据与同步

项目文件由 `ProjectFileService` 及平台适配器管理；Raw Markdown 是对话唯一持久化真源，Wiki 保存已确认知识。

云端文字传输只有两个手动动作：

1. `上传并覆盖云端`：本地完整可同步文字快照覆盖云端；云端独有可同步文字删除。
2. `下载并覆盖本地`：云端完整可同步文字快照覆盖本地；本地独有可同步文字删除。

两个动作都不合并正文、不创建冲突副本、不自动双向同步。媒体、空目录、凭据、设置、Skill、MCP、Provider、Session 和 `.raw/.sync` 不比较、不传输、不删除。设置页只显示状态；项目中心是唯一操作入口。

## 5. 不可变发布身份

分离前后必须保持：

- Desktop 产品名“韭菜盒子”、Bundle ID `com.jiucaihezi.desktop`、`jiucaihezi://`、现有签名、更新地址和公钥；
- iOS Bundle ID `com.jiucaihezi.mobile` 及现有 Apple 身份；Android 当前无稳定独立身份，继续暂停；
- 正式 Web <https://jiucaihezi.studio>、Gateway <https://api.jiucaihezi.studio>；
- 应用数据目录、浏览器项目存储、账号、云 `project_id` 绑定和升级链路；
- `v*` tag、生产 `latest.json` 和三种桌面安装包通道。

`v2.1.9` / `f302c251` 是分离前正式回滚基线。

## 6. 分离实施状态

单产品分离已按 [[开发/通用记忆工作台单产品化分离SDD]] 实施：默认构建只指向 `src/App.vue`；模型目录改用 Gateway；创作面板和全局搜索解除旧 Session 依赖；OpenCode TypeScript/Rust/SDK、旧 Studio、多产品工作台和专属发布物已迁出。Raw、Wiki、媒体、同步、身份、Gateway、更新与发布路径保持不变。

自动门禁、Node、Rust、TypeScript、Web/Desktop quick build和产物审计通过。真实 Windows、Intel Mac、iOS 升级与云绑定连续性仍待人工验收；Android 暂停。
