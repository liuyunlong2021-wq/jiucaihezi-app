# 创作画布本地图片、视频预览空白（2026-08-13）

> 状态：代码修复与用户 Desktop 截图验收完成。

## 现象

- 创作画布中的图片、视频只显示边框，音频卡正常。
- 文件已在项目媒体目录中，问题不是生成或画布布局失败。

## 根因

- Desktop 共享媒体地址曾改为 Tauri `asset://`。
- Leafer 图片加载和浏览器视频首帧提取不能稳定读取该地址；图片错误被删除节点、视频错误被空 `catch` 静默吞掉，因而只剩空框。
- 音频另走 `dev_read_file -> data:`，所以没有同时失效。

## 最小修复

- 仅恢复共享 `getMediaRuntimeUrl()`：Desktop 用既有 `dev_read_file` 读取项目内字节，返回带正确 MIME 的 `data:` URL。
- 图片显示和视频首帧共用该路径；支持 `mp4`、`webm`、`mov`、`avi`、`mkv`。
- 不改画布布局、资源持久化、音频链路，也不增加新服务。

## 下次排查

1. 先确认文件存在，区分“未生成”与“预览地址失效”。
2. 图片和视频同时空白、音频正常时，先查 `getMediaRuntimeUrl()` 返回的地址类型。
3. 在共享解析函数修复，不给图片、视频节点分别加兜底。

## 验证边界

- 用户已确认图片预览恢复。
- `pnpm exec vue-tsc -b`、画布媒体相关 focused 用例和 `git diff --check` 通过。
- 完整 focused 的唯一失败是既有测试登记清单遗漏两个文件，与本修复无关。
