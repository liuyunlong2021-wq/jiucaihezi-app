# 素材上传 KV 额度耗尽与 R2 迁移

> R2 方案未部署，已由 2026-10-06 NewAPI 本地临时存储方案取代。此文保留故障与原方案证据；当前状态见 [[开发/APP使用者与NewAPI唯一后台实施方案-2026-10-06]]。

## 根因

2026-10-05 用户截图：上传返回 500 `KV put() limit exceeded for the day.`。
原链路 `uploadCreationAsset` → Gateway `/api/creations/uploads`：鉴权缓存和媒体文件均写
共享 `PLUGIN_KV`，鉴权缓存写失败也会阻断上传；媒体每次随机 token 写入，重试继续消耗额度。
截图足以确认 KV 当日写额度耗尽；没有账户用量明细，不能归因某个用户或某类请求的精确次数。

## 修复合同

- URL 与接口不变，App 无需升级。文件上限保留 20 MB；原鉴权规则不变。
- 新素材仅写 `CREATION_MEDIA` R2，采用流式上传，失效时间存对象元数据。
- GET 强制 7 天逻辑有效期；素材前缀配置 7 天物理清理。不是永久素材库。
- 鉴权正向缓存使用当前 Worker 内存，最多 256 项，5 分钟有效；仅存摘要，冷启动重新鉴权。
- 原账号 KV/D1 能力保留；迁移前 URL 继续读旧 KV，不回退向 KV 写素材。
- 存储写故障返回 503 `media_storage_unavailable`，日志只记阶段和异常类型，不输出凭据。
- 长于 7 天的生成/重新提交需再次上传参考素材；不承诺任意长任务永久可读。
