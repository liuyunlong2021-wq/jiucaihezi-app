# 通用记忆工作台 Wiki

> 当前产品、架构、SDD、排障和历史的总入口。开发前先读 [[hot]]，开发哲学见项目根目录 `AGENTS.md`。

## 当前产品

通用记忆工作台是本仓库唯一保留产品。边界只有一句话：**记忆工作台现在拥有的全部功能都保留；记忆工作台现在没有的功能全部迁出。**

- OpenCode、旧 Studio、文/武/道/创、电商、漫剧和制作工作台属于迁出范围。
- 共享模块按实际依赖归属，不按名称或目录归属。只要记忆工作台仍直接或间接使用，就必须保留。
- 单产品代码和目录分离已按 [[开发/通用记忆工作台单产品化分离SDD]] 的 TDD 阶段完成；旧产品完整历史保留在独立备份仓库。

## 维护规则

- 功能、排障或发布收尾：使用原生 Wiki“填充”合同更新现行结论、来源索引、`hot.md` 和 `log.md`。
- 确定性断链或命名错误：使用原生 Wiki“修正”合同预览、修复并复查。
- 查询现状：使用原生 Wiki“查询”合同；巡检后必须形成“检查、修正、复检”闭环。
- 架构变化只更新记忆工作台现行入口；旧产品页面不得重新成为当前导航。
