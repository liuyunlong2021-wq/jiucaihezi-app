## 四、核心成果

### 1. 用户体验改进

**对话连续性：**
- 之前：不选能力时只有当前消息，看不到历史
- 现在：始终包含最近 3 轮，最多 24K tokens

**Skill 使用体验：**
- 之前：每轮回答后 Skill 清空，需要重新选择
- 现在：Skill 持续到用户手动移除，支持多轮任务流

**记忆查询：**
- 之前：必须手动选择 `jc-jiyi` Skill
- 现在：`memory_search` 原生工具，自动可用

### 2. 架构改进

**上下文管理：**
- 能力选择不再控制对话历史
- 历史、Skill、工具三者解耦
- 统一的 24K token 预算

**数据持久化：**
- Skill 状态记录在 Raw user turn 中
- 向后兼容旧格式
- 无需数据迁移

**原生工具集：**
- `memory_search` 作为内置能力
- 不依赖 Skill 选择
- 当前对话范围限定，避免跨对话干扰
