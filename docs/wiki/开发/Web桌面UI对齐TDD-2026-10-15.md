# Web 桌面 UI 对齐 TDD

> 日期：2026-10-15；分支：`1001-shoujiweb`；实施起点：`9b4b36b7`。
> 桌面参考：本地 `main` 的 `e89225b8`；仅只读参考，未修改桌面工作树。

## 1. 用户决定与边界

用户要求 Web 的 UI、创作面板和参数以桌面 App 为标准，保留此前完成的 Web Runtime；本轮明确不考虑手机端。采用依赖闭包同步，不整目录覆盖，不新建通用 UI 框架，也不恢复桌面 Harness。

“一致”指共同能力的视觉、控件、参数、默认值、校验、提交和画布交互一致，不假装浏览器拥有本机权限。保留 Web 登录流程、浏览器文件/媒体存储、项目身份，以及 Web Runtime 的三路线、记忆与查询开关、视频分析附件能力。桌面专属更新器、截图、终端、进程和 stdio 不移植成可点击的空壳。

## 2. 最小实施顺序

1. 锁定 Web 保留边界、增加 UI 合同测试 → 验证：新增四项合同先红后绿。
2. 同步创作面板及参数依赖 → 验证：注册表、媒体白名单、RunPlan、HTTP 请求体、画布保存/回填和任务行为测试。
3. 同步工作台与设置 → 验证：主题、Markdown、输入、文件树、设置、MCP 与会话搜索测试和浏览器宽屏操作。
4. 回归与记录 → 验证：类型检查、Web quick build、产物审计、差异检查、完整前端回归与原有失败项比对。

## 3. 实施内容与依赖

| 范围 | 处理 |
| --- | --- |
| 创作面板 | 复用桌面 `CreationPanel.vue`、`useCreation.ts`；同步模型分组、默认值、时长输入、参考素材、计费说明、工具栏、提示词区与任务记录 |
| 参数与提交 | 同步 `creationModelRegistry.ts`、`mediaModelCapabilities.ts`、可用性、RunPlan、媒体 API 和对应请求执行；任务服务依赖的媒体类型、合同校验与协议模块一并复用，未增加新的聊天 Runtime |
| 画布 | 同步 viewport 持久化、结果按目标画布回填、去重和避免重叠、文件定位；保留浏览器项目 ID 与 Blob/IndexedDB 路径 |
| 展示与输入 | 同步语义主题、Markdown/代码块、增量渲染、滚动提示、剪贴板文本输入和消息/媒体操作样式 |
| 工作台 | 同步顶栏与桌面控件、文件树拖宽/键盘调整/宽度恢复、设置分类与抽屉；Web 特有的 Runtime 控件仍存在，窄对话 Dock 内折叠工具而不是手机适配 |
| 设置 | 同款“账号、模型与服务、同步、Skill、MCP、主题”；兼容 API 复用现有 Provider 校验与模型刷新，仍受浏览器 CORS/HTTPS 限制 |
| MCP/搜索 | 暴露现有远程 MCP 管理和会话搜索；GitHub OAuth 配置改用桌面现行 Gateway 读取方式；原有桌面创作 MCP 注册和解析保留，本地 stdio 在 Web 禁用 |

`src/runtime/memory/`、`src/runtime/direct/` 的实现文件本轮没有改动：Wiki、记忆索引/查询、Raw、动态上下文和唯一 Web Direct Loop 保留。`main`、Rust、Gateway、插件部署和生产数据没有改动；没有依赖安装或账号/Provider 缓存清理。

## 4. 平台差异与保护

- 本机 ComfyUI 的参数合同保留；Web 模型菜单标注“桌面专用”且禁用，提交入口同样阻止，不能只靠按钮隐藏保护。
- 浏览器不加载桌面更新器、不启动本机进程或本地 stdio；远程 MCP 仅提供已有连接能力，本轮未连接任何真实服务。
- 保留原有 Web 登录获取调用 Key 的流程，不顺带迁移账号或更改用户凭据。
- 关闭的设置抽屉使用 `inert`/`aria-hidden`，避免仍能通过键盘或辅助功能操作屏外控件。
- 模型目录与报价同步桌面源代码，不代表新增渠道服务已部署、真实生成或扣费已验收。
- 本轮不开发、验收或发布手机端；桌面安装包也未构建。
