# 3D 编辑器与 Agent 四项闭环 TDD

> 2026-10-19；用户同意优先实施前四项。源码已实现，真实桌面与真实 Agent 回合未验收，未打包发布。

## 保留边界

保留所有现有桌面编辑、姿态按钮、骨骼与手型、运镜、截图、录制和导出；不引入新依赖或新文件格式。不在本轮扩展完整人物属性、摄影灯光和排列/时间线的增量工具。

## 1. 选中对象与视角

- 场景输入先等待手动保存完成；保存失败时停止发送。
- 指令带当前场景路径、版本、选中对象 ID、选中关节、相机和播放时间，自动启用 3D 工具。
- `inspect_3d_scene(path, includeImage?)` 返回完整已校验场景、版本和已打开编辑器上下文。场景标签与文本只作为数据。
- 不再依赖角色显示名称猜测“这个人”；没有选中目标时返回 null。

## 2. 修改后画面检查

- 创建、重建、增量编辑后自动调用现有 Three.js 渲染器，等待真实人物加载，截图保存到 `.raw/jc-media/图片/`，使用 keepBoth 保留每次检查图。
- Direct 通过图片消息回传；Harness 工具输出使用官方 `ctx.attachments.saveImage` 保存后返回原生 image block；MCP 代理保留图片内容块。
- Harness 核对实际调用模型的图片输入能力；不支持看图或截图失败时明确“视觉检查未完成”。保存成功不冒充视觉验收成功。
- 检查图基于保存后的场景；若同一场景已打开，则按编辑器当前时间与镜头取景，选中对象 ID 另由上下文返回。

## 3. 人物落座

- 新增增量操作 `{action:"seat",target:"人物ID",seat:"坐垫ID",floorY:0}`。
- 先应用 sitting 并清除旧手动骨骼、对齐坐垫朝向，再使用加载后的实际骨骼和蒙皮几何测量坐垫顶面与人物位置，支持人物处于平移分组中。
- 座面限定为独立水平 box 坐垫；不接受整把椅子、倾斜座面或变换动画中的相关对象/分组。坐垫局部 +Z 为朝向。
- 臀部接触高度使用髋骨与脊柱距离估算，不是物理接触求解。返回 contactMethod=hip-bone-estimate、人物最低点与指定地面的高度差和截图检查要求；高度差超过 5cm 提示调整坐垫高度或人物比例。
- 不通过强行移动整个角色同时满足互相冲突的“臀部贴座面”和“双脚落地”；结果必须结合截图检查。

## 4. 保存、冲突与撤销

- `edit_3d_scene` 必须带 inspect 返回的 expectedRevision；重建现有场景也必须带版本。
- 整批操作先在内存中校验和测量，之后复用 `dev_write_file_if_revision` 一次写回，再读回核对；失败不部分写入。
- 原生读取在读前/读后核对版本，拒绝把旧内容与新版本号配对；条件保存以共享 Mutex 串行保护“版本检查 + 原子替换”，覆盖同一进程多窗口的条件写入。
- Agent 操作先排队并等待手动保存，暂时锁定可见编辑器；在途拖动先通过原有保存处理器收尾。手动录制时拒绝 Agent 修改。
- 成功后立即刷新打开的同一场景；外部场景更新进入已有撤销历史，撤销后继续编辑会清除旧 redo 分支。不同场景按 owner/path 重新挂载，避免串历史。
- 隐藏渲染器串行复用截图、落座测量和视频录制入口。
