## 已实施边界

- `dao` 不再投影为 OpenCode Agent，Provider 配置不再注册 `dao`。
- Desktop 和 Web 的道模式均复用 Direct Engine；请求只使用当前模型、用户/助手可见消息和本轮原始附件。
- 道模式请求不加载项目记忆、Skill、Wiki、搜索、媒体计划或项目工具；`tools` 始终为空，且不设置产品固定 `max_tokens`。
- Desktop 道模式不创建 OpenCode prompt parts、session 或 sidecar 请求；取消只中止当前 HTTP 请求。
- 道模式使用既有 `sessionStore` 保存可见对话，Desktop 不再把本地道模式会话 ID 当作 OpenCode session 打开；其本地历史不按项目目录筛选，重复切换复用同一条道会话。
- 进入道模式时只投影当前可见的用户/助手文字和原始附件，丢弃工具过程、媒体任务与旧文件上下文；回到文/武显示层合并可见正文而不合并内部 runtime session，进入创模式则投影到创模式会话。
- 道模式隐藏 Skill 选择、项目引用、OpenCode 权限、Todo、Diff、Review、共享、媒体任务与工具/审批面板；Web 可在道/创之间选择，Desktop 保留文/武/创/道。
- 道模式跳过项目 pill 解析、粘贴项目媒体引用与产品收发插件钩子，避免这些预处理读取或改写本轮输入。

## 自动验证

- 道模式请求级测试：无 Skill 目录请求、无 `tools`、无 `max_tokens`、原始视频附件进入一次模型请求；SSE 断流不续发第二次请求。
- 静态运行时合同：道模式不触发 OpenCode 启动/水合、只使用本地会话、隐藏项目/Agent/Skill 引用，并跳过项目与插件预处理。
- `pnpm run test:focused`
- `pnpm exec vue-tsc -b`
- `pnpm exec vite build`
- `node scripts/prune-web-dist.mjs && pnpm run audit:web-dist`
- `node scripts/prune-desktop-dist.mjs && pnpm run audit:desktop-dist`
