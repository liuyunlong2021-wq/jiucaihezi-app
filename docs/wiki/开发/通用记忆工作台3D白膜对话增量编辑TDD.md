# 通用记忆工作台 3D 白膜对话增量编辑 TDD

> 日期：2026-08-07
> 状态：实施中

## 目标

Desktop 打开 `.raw/jc-media/文档/*.jcscene` 后，在 3D 编辑器下方直接用自然语言修改当前白模。普通“增加、移动、删除、调整镜头”只提交增量操作；只有用户明确要求“重做/重新生成”才允许完整覆盖场景。Web 保持现有只查看边界。

## 文件合同

- 可编辑源文件：`.raw/jc-media/文档/*.jcscene`。
- 截图结果：`.raw/jc-media/图片/*.png`。
- 自动动画和手动运镜结果：`.raw/jc-media/视频/*.mp4`。
- 不增加新的素材分类或文件类型。

## 红灯合同

- 新增 `edit_3d_scene`，只接收当前场景路径和原子操作，不接收完整场景 JSON。
- 支持增加独立对象/排列、移动目标、删除目标、调整相机。
- 所有操作先在内存中应用并通过现有 `.jcscene` 校验，再一次写回；任一操作无效则原文件不变。
- 场景预览底部提供当前场景输入框，自动绑定当前路径；完成后重新读取同一文件并刷新编辑器。
- `create_3d_scene(existingPath)` 只用于用户明确要求完整重做，不用于普通局部修改。

## 非目标

- 不做写实模型、材质库、背景库、人物资产市场或照片级 3D 重建。
- 不做关键帧编辑器、版本树或第二套聊天记录。
- 不新增模型、后端、依赖或文件监听器。
