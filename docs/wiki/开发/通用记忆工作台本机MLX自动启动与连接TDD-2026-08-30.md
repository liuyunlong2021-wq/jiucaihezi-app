# 通用记忆工作台本机 MLX 自动启动与连接 TDD

> 状态：实施中
> 日期：2026-08-30

## 目标

在已有 MLX 运行环境和模型的 Desktop 上，用户点击一次“启动并连接”即可启动本机 OpenAI-compatible MLX 服务并连接。韭菜盒子不下载模型、不打包 Python、不管理 Hugging Face 账号。

## 用户合同

首次使用只需在系统外完成一次准备：安装 MLX 运行环境并下载模型，在设置中填写模型路径或仓库 ID。之后 App 复用已保存配置，自动启动服务并探测 `/v1/models`。

完全没有 MLX 环境或模型时，App 不伪造自动安装；设置页明确提示缺少依赖，并指向用户说明文档。

## 最小流程

```text
已有模型配置
  -> 点击“启动并连接”
  -> App 启动 mlx_lm.server
  -> 等待 /v1/models
  -> 保存模型列表并选择本地模型
```

## 禁入边界

- 不下载或更新模型。
- 不打包 Python、mlx-lm 或模型文件。
- 不执行用户任意 shell 字符串；启动参数由程序按字段组装。
- 只允许本机回环地址和固定 MLX 服务端口配置。
- 非 Apple Silicon 平台不显示自动启动入口。

## 验收

1. 已配置模型路径时，点击“启动并连接”无需终端即可启动并识别模型。
2. 服务已经运行时，点击同一按钮只连接，不重复启动进程。
3. 缺少模型路径或 MLX 命令时，显示可操作错误，不覆盖已有模型配置。
4. App 退出时回收由 App 启动的 MLX 进程。
5. 连接后的对话继续复用现有 OpenAI、SSE 和工具调用链。
