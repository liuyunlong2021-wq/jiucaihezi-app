日期：2026-10-13。范围：内置 `jc-gongchengjuben` 正文、五份导演参考，以及脑暴工程交接条款。依据：用户连续反馈的镜内合镜、上下文复述、单人镜头补画外人体与反应，以及本轮整体审计要求。

本次修正的是指令合同与示例；静态校验和规则走查不能证明真实 App 模型绝不违约。相关现行合同见 [[开发/漫剧制作合同]] §3.2。

## 发现与处理

| 问题 | 影响 | 修正 |
| --- | --- | --- |
| 文戏参考仍允许倾听者同镜反应，术法参考允许邪祟远景／影子反应 | 可绕过单人可见性，补出画外手、胸口与视线 | 只有明确多人可见交互才写双方行动；单人覆盖只写主体与可见道具 |
| “新节拍就拆”与归勺、抽刀、抬刀的正例含义不清 | 可能把同一威胁动作拆碎，也可能把整场戏当一节拍 | 用核心戏剧任务定义边界；直接子动作可连续，新的独立任务另镜 |
| 文戏要求两三个线索、主动作次级响应和稳定落点；动画要求脸部、手势、身体及四阶段收尾 | 每镜为完整表演硬补动作，违背简洁与继承上下文 | 改为按需方法，普通对白可仅台词与简短说法，不配齐动作类别 |
| 拔刀要求多阶段结构展示与空鞘特写 | 普通持刀威胁被扩成武器准备仪式 | 普通拔刀只交代必要持握与来源；精细结构仅在任务需要时展开 |
| 具名术法强制多镜准备及特写—大范围长镜—反应配方 | 无视短镜头、单一运镜、已有准备与用户时长 | 保留术法因果与表现方法，镜头配方改为可选菜单，不因名称强制镜数或长镜头 |
| 时间规则既保留已确认起止又允许超容量直接调整 | 可能偷偷改变锁定时间；缺少终点时又强迫落到已有终点 | 锁定时间只报缺口和调整方案；暂定预算可重分，没有终点时明确推导预算 |
| 全景／固定镜头配额、词汇目录和冗长写实影像范例 | 为数量凑镜、强加摄影运动或给其他媒介套写实犯罪风格 | 保留竖屏快节奏与单人覆盖偏好，配额仅作参考；摄影词汇简化，影像基调依据项目按需写 |
| 全景示例将时间码放在规格之后，“看不见脸”直接换成剪影 | 示范违反编号行唯一时间码，或改变原构图与光线 | 删除违约示例，使用用户的标准逐镜正例；可见内容按实际取景表述，不默认改剪影 |

正文重复的镜头禁令、时间校验、表演因果与连续性说明已合并为共享合同和六项交付检查。参考仍保留文戏、单场戏、功夫、动画、术法设计能力，细度按用户任务选择。

## 规则走查

以下检查文本规则是否一致，并非调用 App 模型生成的新测试结果。

| 场景 | 检查结论 |
| --- | --- |
| 潘金莲归勺、抽刀、抬向前方并说威胁台词 | 是同一主体的威胁任务，可连续拍摄；不重述床边距离，不补大郎手、胸口、视线和句尾停稳 |
| 大郎辨认古装、跳床、质问、逐处确认，潘金莲再反应 | 不同观看任务逐镜输出，不能用一个五秒中景或一个镜头组段落代替 |
| 原稿明确刀刃抵住胸口 | 接触事实保留在参与部位可见的交互镜头，不在单人过肩补画外身体，也不删成悬空指向 |
| 已锁定五秒但原台词与动作放不下 | 报告具体容量冲突与最小调整，不加速、删句或擅自延长；未锁定预算才重分时间 |
| 简单拔刀、短促术法、轻微动画反应 | 不自动添加空鞘特写、多镜蓄势、复杂摄影或表情／手势／身体全套收尾 |

## 后续实测：先取景再写正文

用户再次反馈“看见潘金莲递来的药碗”“潘金莲的左手仍握着碗侧”。仅在整场互动稿生成后做删句自审仍会漏掉物件来源、持物所有格与画外角色。工程写作现改为先确定主体、镜头类型、可见部位和物件，再只从该清单写画面；新增包内 `shot-visibility.md` 方法及改写示例。

默认过肩不在规格中提示画外人物名字；已锁定具名规格保留，但单人正文与表演括号仍只有主体和入镜物件。原台词按原文保留。真实双方接触使用交互镜头，不把所有双人剧情删掉。

按 skill-creator 的独立前测方法完成三个新场景，稿件在 `/tmp/jc-shot-visibility-forward.md`：

- 单人托杯：正文只写赵衡放手、托杯、笑与向前推杯，没有林瑶、画外持杯手或折扇；锁定的林瑶肩后规格仍保留。
