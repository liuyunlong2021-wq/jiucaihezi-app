# 通用记忆工作台改编 Wiki 建库与双链输入 TDD

> 状态：已实施，自动化验证通过，待跨平台人工验收
> 日期：2026-09-10
> 范围：Web、Mac、Windows、iPhone、iPad 的共享文件树与 Markdown 编辑区
> 上游合同：[[开发/通用记忆工作台稳定性修复与Markdown体验升级SDD]]、[[开发/通用记忆工作台故事拆分与语义沉淀TDD-2026-09-09]]、[[架构/产品架构]]

## 1. 目标

韭菜盒子提供一套不绑定具体题材的改编基础设施：用户可从文件树一键建立标准 Wiki 骨架，在 Markdown 编辑过程中快速插入角色、场景、道具和剧本文件的 Wiki 双链，再由用户选择的 Skill 负责理解资料和完成具体创作。

本期只实施以下四项产品能力：

1. 文件树顶部“建库”按钮；
2. Markdown 编辑区 `[[双链]]` 按钮；
3. `Command/Ctrl + Shift + K` 双链快捷键；
4. 输入 `[[` 自动打开项目 Markdown 文件联想。

本期不实现标题或场次锚点、未创建链接自动建页、文件移动后的批量改链、反链上下文摘录、关系图谱、角色专用选择器或自动识别人名。

## 2. 职责边界

### 2.1 程序

程序只负责结果必须确定的基础设施：

- 创建和补齐唯一 Wiki 根目录、目录骨架及各级 `index.md`；
- 复用现有原文导入、文档转换和故事拆分能力；
- 读取、保存、冲突检测和跨平台文件适配；
- 解析、渲染、校验和跳转 `[[路径]]`、`[[路径|别名]]`；
- 根据项目 Markdown 正链动态计算反向链接。

程序不判断应有哪些角色、场景、道具，不生成资产档案或剧本，不根据普通正文中的名称自动建链，也不维护第二份关系数据库。

### 2.2 Markdown 编辑器

编辑器负责让用户低成本建立明确关系：

- 点击按钮、使用快捷键或输入 `[[`，均进入同一个双链选择流程；
- 从当前项目已有 Markdown 文件中选择唯一目标；
- 写入项目相对路径，默认去掉 `.md`；
- 有选区时保留选中文字作为别名；
- 不调用模型，不读取目标正文，不改变目标文件。

### 2.3 Skill

Skill 负责需要语义判断的业务：

- 理解原始材料、改编约束和创作目标；
- 判断实际出场角色、实际表演场景和实际使用道具；
- 沿用户或工作流明确的正链读取所需档案；
- 创建或补充有依据的资产资料；
- 编写剧本，并在角色、场景、道具字段中输出真实正链；
- 发现缺档、冲突或目标歧义时停止并请求确认。

通用程序不内置 `jc-duanju` 的写作规则。具体项目可以由工作流 Skill 编排资料，再由 `jc-duanju` 执行短剧写作；APP 只提供文件和双链能力。

## 3. “建库”按钮合同

### 3.1 位置与入口

- 在文件树顶部操作栏增加带文字或明确提示的“建库”按钮，与“新建文件”“新建文件夹”“刷新”“故事拆分”同级。
- Desktop、Web 和 Mobile 使用同一入口语义；移动端允许图标加 tooltip/无障碍名称，但不得隐藏为只能通过右键进入的功能。
- 点击后展示将创建或补齐的路径预览，用户确认后执行；不发起模型请求。

### 3.2 唯一 Wiki 根

- 新项目默认使用项目内 `wiki/`。
- 已存在唯一 `wiki/` 或 `docs/wiki/` 时沿用现有根，不创建平行 Wiki。
- 两者同时存在、存在旧 `_index.md` 迁移歧义或目标路径被普通文件占用时停止，列出冲突，等待用户决定。

### 3.3 改编基础骨架

“建库”只创建目录与索引，不创建空白业务正文：

```text
wiki/
├── index.md
├── 原始材料/
│   └── index.md
├── 改编方案/
│   └── index.md
├── 剧本/
│   └── index.md
└── 资产/
    ├── index.md
    ├── 角色/
    │   └── index.md
    ├── 场景/
    │   └── index.md
    └── 道具/
        └── index.md
```

每个 `index.md` 只导航直属子项，使用相对 Markdown 链接和一句用途摘要。角色档案、场景档案、道具档案、故事拆解、改编方案和分集剧本均在有真实内容时由用户或 Skill 创建。

### 3.4 幂等与保护

- 重复点击只补缺失目录、缺失 `index.md` 和缺失的直属导航；
- 已有文件和已有索引正文不得被覆盖或重排；
- 同名目标内容冲突时本次不写入，并显示具体路径；
- 创建完成后重新读取实际目录和索引，只有结构、导航和链接均可解析才显示成功；
- 部分失败时保留已成功写入的内容，明确列出未完成项，不伪装成整体成功。

## 4. 双链输入合同

### 4.1 工具栏按钮

Markdown 编辑态增加“双链”按钮，优先使用现有图标库中的链接图标，tooltip 为“插入双链（Command/Ctrl + Shift + K）”。阅读态不显示该编辑命令。

- 无选区：插入 `[[]]`，光标放到中间，并打开文件联想；
- 有选区：以选中文字作为搜索词，选择目标后写入 `[[完整项目相对路径|选中文字]]`；
- 光标已位于未完成双链内：不重复插入括号，只打开或刷新联想。

### 4.2 快捷键

- macOS：`Command + Shift + K`；
- Windows/Linux：`Ctrl + Shift + K`；
- 快捷键与按钮调用同一命令，不维护第二套插入逻辑；
- 只在 Markdown 编辑器获得焦点时拦截，不覆盖阅读态或全局浏览器行为；
- 输入法组合期间不触发，避免中文输入被截断。

### 4.3 输入 `[[` 自动联想

- 用户输入第二个 `[` 后打开项目 Markdown 文件联想；
- 候选只来自当前项目内已有的非隐藏 Markdown 文件，不扫描文件正文；
- 支持中文、拼音和路径模糊匹配；
- 支持方向键、Enter、Escape、鼠标点击和触摸选择；
- 候选显示文件名与所属目录；同名文件必须显示完整路径；
- 选择后默认写入去掉 `.md` 的完整项目相对路径，例如 `[[wiki/资产/角色/林默/角色档案]]`；
- 用户已选中文字“林默”并选择上述目标时，写入 `[[wiki/资产/角色/林默/角色档案|林默]]`；
- 联想关闭或无结果时保留用户草稿，不自动创建文件。

## 5. 正链、反链与业务关系

- 剧本中对角色、场景、道具的显式 WikiLink 是“该剧本使用该资产”的正链真源。
- 打开资产档案时，现有反向链接区域根据项目 Markdown 文件实时派生来源文件；点击来源打开对应剧本文档。
- 关系只声明一次：Skill 不创建反链文件，也不在资产正文中重复维护完整的“被哪些集使用”清单。
- 首次出现、重大状态变化和造型版本适用范围属于业务事实，可由 Skill 写入资产档案；普通复用关系由程序反链呈现。
- `index.md` 负责目录导航，正文 WikiLink 负责知识关系，两者不得互相替代。

## 6. 数据与实现边界

- 继续复用 `ProjectFileService`、`MemoryWorkbench`、`PromptSelectionRevision`、`markdownFileLinks` 和现有拼音模糊搜索，不引入第二套编辑器或关系数据库。
- 插入双链只修改内存中的 Markdown 草稿；用户点击保存后才通过 revision 合同写入文件。
- 取消编辑恢复原文件；保存冲突保留当前草稿，不覆盖外部或其他设备修改。
- 候选列表按目录/路径元数据构建，不因打开联想而批量读取正文。
- Desktop、Web、Mobile 保持相同 Markdown 源文本和 WikiLink 语法。

## 7. TDD 实施顺序

1. 先为建库计划、唯一 Wiki 根、幂等补齐和冲突拒绝写 Runtime 测试。
2. 实施确定性建库 Runtime，再接入文件树顶部按钮和确认预览。
3. 先为无选区、有选区、未完成双链和输入法组合状态写编辑命令测试。
4. 实施统一的双链插入命令，并同时接入按钮和跨平台快捷键。
5. 先为 `[[` 检测、中文/拼音搜索、键盘选择、取消和完整路径插入写测试。
6. 实施联想浮层，复用项目路径搜索与现有 Markdown 保存链路。
7. 回归已有正链跳转、反向链接、故事拆分、普通 Markdown 编辑与跨平台构建。

## 8. 验收标准

- 空项目点击“建库”后得到完整骨架和全部必需 `index.md`；第二次点击零覆盖、零重复导航。
- 已存在唯一 Wiki 时只补缺项；双根或路径冲突时零覆盖并明确报错。
- 无选区点击按钮或按快捷键后出现 `[[]]` 且光标位于中间。
- 选中“林默”后选择角色档案，生成带别名的完整相对路径双链。
- 直接输入 `[[linmo` 能通过拼音选中林默档案；Enter 插入，Escape 只关闭联想。
- 保存后正链可打开目标；目标页现有反链可返回来源文件。
- 打开联想不读取候选正文，不调用模型，不改变其他文件。
- Web、Mac、Windows、iPhone、iPad 均完成按钮、触摸/键盘、保存和跳转验证后，才能标记本合同实施完成。

## 9. 非目标

- 本期不实现 `[[文件#标题]]` 的场次定位和高亮；
- 不实现未创建双链点击建页；
- 不实现文件移动、重命名后的全库自动改链；
- 不实现角色、场景、道具专用表单或多选器；
- 不实现自动识别人名并强制建链；
- 不修改任何具体创作 Skill，不把项目工作流硬编码进 APP。
