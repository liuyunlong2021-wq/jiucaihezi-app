# 通用记忆工作台对话记忆索引按钮 TDD V2

> 日期：2026-09-01  
> 状态：代码实施完成，待真实模型与跨端验收  
> 前置设计：[[通用记忆工作台对话记忆索引正确链路设计-2026-09-01]]  
> V1 记录：[[通用记忆工作台对话记忆索引按钮TDD-2026-09-01]]

## 1. 目标

把对话记忆索引收敛为“当前 assistant 输出的导航索引”。写入只做一次摘要模型请求和一次固定路径索引更新；查询先读索引，命中后沿正链读取 assistant 输出。

## 2. 行为合同

### T1：V2 索引格式

- 单条索引只保存简介、关键词和 Raw 正链。
- 正链包含 Raw 相对路径与 `#jc-turn-<assistantTurnId>` 锚点。
- 时间、顺序和 `userTurnId` 不参与索引定位或查询返回。
- `conversation-id`、`source` 和 `version="2"` 只承担文件级身份校验。

### T2：写入路径

```text
当前 assistant 输出
-> 一次 summary + keywords 模型请求
-> 程序拼装固定索引路径和正链
-> 按固定路径创建或条件更新索引
```

写入不得读取或解析 Raw，不得调用项目目录列表。已有索引只允许按固定路径读取一次以完成幂等更新和 revision 写入；索引目录已由项目骨架创建，缺失时直接创建，不以扫描确认存在。

### T3：查询路径

```text
固定索引路径
-> 匹配简介和关键词
-> 无命中：返回空，不读 Raw
-> 有命中：按正链分组读取 Raw
-> 返回 assistant 输出
```

同一 Raw 的多个命中只读取一次。默认返回 assistant 内容和 `assistantTurnId`，不把用户问题拼入结果。

### T4：兼容与孤链

- 读取旧 V1 索引时允许兼容解析，但新写入统一 V2。
- 正链对应的 Raw 或 assistant turn 不存在时丢弃该命中，不返回孤链。
- 重复点击同一 assistant turn 保持一条记录。

## 3. 测试先行

新增和修改测试覆盖：

1. V2 格式只输出简介、关键词、正链。
2. 写入路径的 adapter `list()` 调用次数为零，Raw `readText` 调用次数为零。
3. 查询无命中时 Raw `readText` 调用次数为零。
4. 查询命中同一 Raw 多条记录时 Raw 只读取一次。
5. 查询返回 assistant 内容，不返回 user 内容。
6. 重复写入幂等，孤链被过滤。

## 4. 实施顺序

1. 先修改纯函数和测试，锁定 V2 格式。
2. 增加按路径读取能力，改写入 Runtime。
3. 改写查询 Runtime。
4. 更新 `jc-jiyi` Skill 的能力声明、格式和返回结构。
5. 运行定向测试、TypeScript、focused 回归和 `git diff --check`。

## 5. 不做

- 自动后台索引、全量重建、向量库、Embedding、复杂缓存。
- 多 Skill 编排协议。
- 索引内复制 assistant 正文。
- 伪造写入百分比进度。
