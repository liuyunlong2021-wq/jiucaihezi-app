# 桌面对话目录对齐 DSH 官方

日期：2026-10-19。用户明确要求删除桌面 localStorage 对话目录，只保留官方 DSH 会话来源；保留全部桌面功能，不打包发布。

## 根因与边界

旧 UI 列表存于 WebView localStorage，正文在原生 Harness 数据目录。开发版 `http://localhost:1420` 与安装版 `tauri://localhost` 的浏览器存储隔离，导致列表为空但官方历史仍在。不能把清浏览器缓存后重新扫描私有文件作为长期方案。

本地只读核验：`3D-MiniMax` 经官方接口读取到 7 个会话、788 条用户/助手消息，无标题读取警告。此证据只说明该项目原生历史存在，不证明所有安装版或项目都已验收。

## 实施

- 列表复用固定版本 `0.2.1-rc.2` 的官方 GUI `ApiSessionList`，时间/项目来自 sessionQuery，标题来自官方投影及 readTitleSnapshots，正文仍由 observeSession 读取。
- 新建与改名走官方 agents / sessionTitle / sessions.flush。离线读取和空会话创建不初始化 LLM、不要求 API Key、不发送模型消息。
- 删除 localStorage 目录写入、空列表才补恢复的服务、Rust 私有 session_projcache 扫描命令及权限。前端只留可丢弃内存视图；读取失败保留已有视图并报错，不伪造新对话。
- 旧 localStorage 只读一次迁移标题和应用偏好；成功持久化后删除旧键，失败保留并允许重试。不同 WebView 源在各自首次启动时处理，不能从开发版替安装版删除其浏览器存储。
- 漫剧/小说/短剧偏好、旧 Raw 路径与删除隐藏标记走官方 storageDomain；域内无消息正文、标题或第二份会话目录。
- 保留 Raw 兼容读取与首次成功发送后的移交标记、搜索/新建/切换/改名/删除、远程 Host 与原生会话 ID；项目素材不随对话隐藏删除。
- UI 操作按工作区串行，失败不提交视图；官方原生 ID 不重复加前缀，别名冲突仍保持会话独立。

## 验证

1. 先复现无浏览器目录不能发现官方历史、迁移失败误删来源及原生/旧前缀 ID 冲突，再实现修复。
2. SDK 集成在隔离临时目录、空 API Key、不可用模型地址下运行：列出/新建/改名/偏好/重启恢复/读取/隐藏再次重启；确认没有用户消息或模型请求，隐藏不物理删除官方日志。
3. 目录单元测试覆盖隔离、操作提交、删除后迟到更新、查询失败保留旧视图、迁移失败重试。
4. Rust：493 通过、2 忽略；类型检查通过。全量 Node：2016 项，2013 通过、1 跳过、2 失败；两项失败均为无关渠道模型断言（灵动定价、小易图片分辨率），未修改其实现。新增会话 SDK 定向测试 5 项另行通过。

尚待：真实桌面界面重启、安装版升级与 Windows/Intel Mac 验收；未打包发布、未执行收费模型请求。不承诺硬盘损坏、主动清数据等情况下历史永不丢失。
