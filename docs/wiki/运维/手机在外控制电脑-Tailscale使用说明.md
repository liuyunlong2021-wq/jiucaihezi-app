# 手机在外控制电脑：Tailscale 使用说明

> **2026-10-25 定位调整**：用户无需安装 Tailscale——在外使用的正式方案是韭菜盒子自己的云端中继（M3b，两端只做出站连接，扫码配对即可）。本页只适用于**已经在用 Tailscale** 的人，作为额外的一条直连路径。

> **适用**：iPhone 上的韭菜盒子控制家里/公司电脑上的韭菜盒子 Desktop 对话（[[开发/韭菜盒子Mobile控制器完善计划-2026-10-25]] M3a）。
> **原理**：Tailscale 把电脑和手机放进同一个私有网络，手机用电脑的 `100.x` 地址直连回去。韭菜盒子自己的 Noise 加密与电脑公钥校验不变；不需要路由器端口转发，电脑不暴露在公网。
> **状态（2026-10-25）**：代码已支持（电脑自动上报 Tailscale 地址、手机可手填地址）；**蜂窝网络真机验证待补**。

## 1. 一次性准备

1. **电脑装 Tailscale**：从 <https://tailscale.com/download> 下载 macOS（或 Windows）版，安装后登录（可用 Google / Apple / GitHub 账号）。macOS 首次会要求允许系统扩展/VPN 配置，按提示允许。
2. **iPhone 装 Tailscale**：App Store 搜索「Tailscale」安装，用**同一个账号**登录，允许添加 VPN 配置，然后把开关打开（状态显示 Connected）。
3. **确认两台都在线**：在任一端的 Tailscale 里能看到两台设备。记下电脑那一行的地址（`100.` 开头），以及主机名（形如 `my-mac.tail1234.ts.net`，需开启 MagicDNS，默认开启）。
4. **电脑上的韭菜盒子**：「设置 → 手机控制器 → 开启」。开过一次之后，以后 App 启动会自动开启，端口保持不变。
5. **在家先配对、连一次**：手机和电脑在同一 Wi-Fi 下扫码配对（已配对过可跳过），并**用新版电脑端成功连上一次**。这一次连接时，电脑会把自己的 Tailscale 地址告诉手机，手机记住后在外面会自动尝试。

## 2. 在外面使用

- 手机打开 Tailscale（保持 Connected），再打开韭菜盒子，点「连接上次配对的电脑」。
- 手机会依次尝试：上次连上的地址 → 电脑报过的其余地址（局域网 IP、`名字.local`、Tailscale `100.x`）。在外面时局域网地址每个最多等 4 秒，随后会连上 Tailscale 地址；连上后它成为「上次连上的地址」，下次先试它。
- **自动没连上时手填**：配对页展开「编辑电脑地址（在外面用 Tailscale 时）」，填 `100.x` 地址或 `ts.net` 主机名，点「用这个地址连接」。不写端口就沿用配对时的端口。手填的地址只试这一个，连上后同样会被记住。
- 连上之后的用法与在家相同：进入对话、发消息、停止、审批、「选择对话」切换或新建对话。

## 3. 电脑端必须满足

- 电脑开机、**不睡眠**、联网，韭菜盒子 Desktop 正在运行，并打开了项目里的任一对话（手机的对话列表以电脑当前窗口的当前项目为准）。
- 防睡眠：macOS 在「系统设置 → 电池（笔记本接电源时）/ 显示器 → 高级」里打开「接通电源时防止自动进入睡眠」一类选项；合上笔记本盖子通常仍会睡眠。

## 4. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 手机一直「连接超时」 | 先看手机 Tailscale 是否 Connected、电脑是否在线且未睡眠；再用「编辑电脑地址」手填 `100.x`。 |
| iPhone 上开着 Clash / Shadowrocket 等代理 | iPhone 同一时间只能开一个 VPN，Tailscale 与代理 App 二选一；控制电脑时先关代理、开 Tailscale。 |
| 电脑开着 Clash Verge 的 TUN 模式 | TUN 可能把 `100.64.0.0/10` 的流量也接管，导致 Tailscale 不通。在 Clash 规则里把 `100.64.0.0/10` 与 `*.ts.net` 设为直连（DIRECT），或临时关闭 TUN。 |
| 提示「电脑身份不符」 | 连到的不是配对的那台电脑（地址填错，或电脑重装后身份变了）；核对地址，必要时回家重新扫码配对。 |
| 换了一台电脑 / 电脑重装 | 需要在同一网络下重新扫码配对。 |

## 5. 安全说明

- 只有登录同一 Tailscale 账号的设备能访问 `100.x` 地址；手机与电脑之间另有韭菜盒子的 Noise 端到端加密，手机只认配对时记录的电脑公钥。
- 不要为了在外面使用而在路由器上做端口转发，把电脑的手机控制端口暴露到公网。
