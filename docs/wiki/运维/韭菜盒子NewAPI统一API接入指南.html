使用韭菜盒子 NewAPI 发放的 Key。
模型名以 Key 实际返回为准。目录中的模型是现有公开接入合同汇总，不代表每个账号都已开通全部线路；仅有本地插件或待发布的模型也不视为可用。每次接入先查询 GET /v1/models；只使用该 Key 返回的精确 id，不要用展示名、上游模型名或猜测出来的别名。

示例中的 YOUR_API_KEY、YOUR_MODEL_ID 和 TASK_ID 都是占位文字。将 API Key 保存在服务端环境变量或密钥管理器，不要写入网页前端、公开仓库或日志。

02 · Discover

查询当前账号可用模型

curl 'https://api.jiucaihezi.studio/v1/models' \
  -H 'Authorization: Bearer YOUR_API_KEY'

响应中 data[].id 是后续请求要使用的精确模型名。模型列表受账号权限、分组和当前 NewAPI 渠道配置影响；如果下面目录中的型号没有出现在响应中，当前 Key 就不能按该型号发起调用。

{
  "object": "list",
  "data": [
    {
      "id": "YOUR_MODEL_ID",
      "object": "model",
      "owned_by": "jiucaihezi"
    }
  ]
}

seed-audio-1.0文本转语音/音频生成；文本长度 1–3000 字符；输出可选 MP3、WAV、PCM、Opus、Ogg Opus；参考音频最多 3 段。该接口成功响应为原始音频二进制，不是 JSON。

04 · Chat

聊天补全

POST /v1/chat/completions请求体使用 OpenAI Chat Completions JSON。消息至少包含一条 user 消息。

curl 'https://api.jiucaihezi.studio/v1/chat/completions' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {"role": "user", "content": "请用一句话介绍韭菜盒子。"}
    ],
    "stream": false
  }'

非流式从 choices[0].message.content 读取回复。流式请求设置 "stream": true，按 SSE 的 data: 行解析 JSON、拼接 choices[0].delta.content，收到 data: [DONE] 后结束。温度、工具调用和结构化输出应先确认所选模型支持。

05 · Images

图片生成与编辑

标准 OpenAI Images 线路

POST /v1/images/generations 文生图；POST /v1/images/edits 图生图。文生图传 JSON；编辑接口传 multipart/form-data，让客户端自动生成 boundary。

curl 'https://api.jiucaihezi.studio/v1/images/generations' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  --data '{
    "model": "YOUR_MODEL_ID",
    "prompt": "一间有自然光的现代工作室，写实摄影风格",
    "size": "1024x1024",
    "n": 1,
    "response_format": "url"
  }'

图生图例子（本地文件直接上传）：

curl 'https://api.jiucaihezi.studio/v1/images/edits' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -F 'model=YOUR_MODEL_ID' \
  -F 'prompt=保留主体和构图，改成电影级夜景' \
  -F 'size=2048x1152' \
  -F 'image=@./reference.png'

标准图片响应通常是 data[]，其中每项可能含 url 或 b64_json。客户端应按照该模型合同处理结果格式并及时下载 URL。

图片线路差异

Fk 图片

文生图用 JSON，可选 ratio 与 imageSize；比例支持 auto、1:1、9:16、16:9、4:3、3:4、3:2、2:3、5:4、4:5、21:9；尺寸为 1K、2K、4K。本地图生图用 multipart（重复 images 字段），公网图可通过 JSON imageUrls 提交。参考图最多 8 或 10 张，依模型而定。接口返回 URL；NewAPI 在服务端等待 Fk 任务，调用方没有图片任务轮询 API。返回签名 URL 后应尽快下载。

Grok Imagine Image

使用标准 Images 路径；支持 1:1、16:9、9:16、3:2、2:3；size 必须与 aspect_ratio 对应比例一致。图生图重复上传 image[]。NewAPI 在服务端轮询，调用方不使用 /v1/videos。

本机 Qwen Image

jc-qwen-image-2.1 可用 JSON images URL 数组或 Images 编辑 multipart。最多 10 张；最长边上限 2048；返回 URL。b64_json 不适用于该线路。

模型尺寸提示

OpenAI Images 的尺寸使用像素串（例如 1024x1024、2048x1152）。不要把 Gemini 的比例/画质参数、Fk 的 imageSize 或本机 Qwen 的尺寸上限直接套用到其他图片型号。

06 · Videos

视频任务：创建、轮询、取回

多数视频线路通过 POST /v1/videos 创建任务，再用同一 API Key 调用 GET /v1/videos/{task_id} 查询。创建响应中的 id 是 NewAPI 任务 ID；保存并复用它，不要拿上游 jobId 代替。查询看到 queued 只代表受理成功，继续轮询直到 completed 或 failed。

下面是 Fk Seedance 线路的请求示例；其它视频型号请使用目录和该型号合同指定的字段名。

curl 'https://api.jiucaihezi.studio/v1/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  --data '{
    "model": "YOUR_VIDEO_MODEL_ID",
    "prompt": "雨夜霓虹街道，骑手穿过积水，电影感冷色调",
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p",
    "imageUrls": ["https://example.com/reference.png"]
  }'

查询状态：

curl 'https://api.jiucaihezi.studio/v1/videos/TASK_ID' \
  -H 'Authorization: Bearer YOUR_API_KEY'

已完成的视频多数通过二进制接口保存：

curl 'https://api.jiucaihezi.studio/v1/videos/TASK_ID/content' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -o result.mp4
Dola Seedance 2.5 是一个合同例外：查询完成后读取响应中的 video_url；不要假定所有视频都能从轮询 JSON 取得地址，也不要假定每条线路都使用同一种下载方式。某型号文档指定 /content 时按其规定取回文件。

视频字段：以型号决定是否必填

字段常见用途注意
model选择模型精确复制 /v1/models 的模型 ID。
prompt视频描述个别型号有字符上限；提示词长度不代表无限制。
duration / seconds目标时长，单位秒兼容字段随线路而异；请传该型号支持的值。
resolution画质，如 480p、720p、768p、1080p本地 ComfyUI 有些型号使用 size 像素尺寸，而非 resolution 字符串。
ratio / aspect_ratio画幅枚举可能需要完整描述文字；短比例并非每条线路都接受。
imageUrls / images参考图片字段别名并非所有插件通用；素材槽位语义按模型决定。
videoUrls、audioUrls参考视频、音频只适用于明确支持该素材类型的型号。
first_frame、last_frame首帧或首尾帧生成主要用于 jc-minimax-h3；与参考图数组模式区分。

任务重试原则

  • 轮询间隔通常从 3–5 秒开始；若出现 429，降低频率并延长间隔。
  • 创建请求遇到网络超时或连接中断时，先确认任务是否已经受理；不要立即重复创建，以免生成重复任务或重复计费。
  • 异步任务的错误可能在查询响应的 error 字段中；检查任务最终状态。
  • 任务和结果的保留期按具体线路而异。部分线路为 24 小时、部分为 7 天；完成后尽快下载并保存到自己的存储。
07 · Audio

Seed Audio 1.0

POST /v1/audio/speech 使用 JSON 请求，成功响应为音频二进制。curl 示例中用 -o 将文件落盘。

curl 'https://api.jiucaihezi.studio/v1/audio/speech' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -o result.mp3 \
  --data '{
    "model": "seed-audio-1.0",
    "input": "请自然地说：这是一段音频测试。",
    "response_format": "mp3"
  }'

文本 input 为 1–3000 字符；格式支持 mp3、wav、pcm、opus、ogg_opus。参考音频通过 metadata.references 传入，最多 3 段；每项可使用可访问的 audio_url，或不带 data URI 前缀的原始 audio_data Base64。单段 audio_data 最大 10 MiB。

成功响应不是 JSON；不要尝试按图片数组或聊天 completions 解析。当前公开合同不保证 voice、speed、n 或 stream 字段有效。

08 · Prompt enhancement

MiniMax H3 Context IR

该接口只返回增强后的视频提示词，不会创建视频。使用 POST /v1/responses，建议后台模式；用响应顶层 id 查询结果。

curl 'https://api.jiucaihezi.studio/v1/responses' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  --data '{
    "model": "MiniMax-H3-Context-IR",
    "background": true,
    "content": [
      {"type": "text", "text": "雨夜的老街上，一名侦探撑伞走进霓虹灯下。"}
    ],
    "duration": 6,
    "ratio": "9:16"
  }'

以创建响应顶层 id（resp_...）作为 GET /v1/responses/{response_id} 的 ID，不要用 metadata.task_id（task_...）。完成后读取 output 里的非空 output_text。多模态内容可包括图、视频、音频 URL，但该模式尚未完成公网专项验收；可靠接入先使用纯文本后台任务。

多模态 content 每次至少带一段非空文本；图像项使用 image_url（角色可为 first_frame、last_frame 或 reference_image），视频与音频项分别使用 video_url / audio_url 及 reference_video / reference_audio 角色。首尾帧模式不能与多模态参考模式混用。

09 · Reference assets

参考素材怎么传

素材方式由模型接口合同决定，不存在一个适用于所有模型的上传格式：

  • 图片编辑接口：OpenAI Images 的本地参考图可直接作为 multipart 文件上传。
  • 视频模型接受 URL 数组时：可传公开 HTTPS 文件链接；部分线路也接受 HTTP 或内联 data URI，须以该型号合同为准。
  • 临时素材上传：需要 URL 且本地没有公网链接时，可调用 POST /api/creations/uploads，以 multipart 字段 file 上传。接口接受图片、音频或视频文件，单文件最大 20 MB，返回的 URL 在 15 分钟后失效。应在失效前创建任务。
curl 'https://api.jiucaihezi.studio/api/creations/uploads' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -F 'file=@./reference.png'
{
  "url": "https://api.jiucaihezi.studio/media/creation/TEMP_TOKEN"
}
本机路径、file:、blob: 地址不是服务器可访问的 URL。若接口要求公网地址，先直传可访问的 HTTPS 文件链接，或使用临时素材上传。已明确支持 multipart 直传的图片编辑接口无需先上传临时素材。
10 · Troubleshooting & security

常见错误与安全约定

错误检查方法
401 Unauthorized确认请求带有 Authorization: Bearer YOUR_API_KEY，Key 未失效。
403 Forbidden确认账号、分组和 Key 已开通该模型权限。
model_not_found重新获取 /v1/models，逐字复制返回的 ID。
400 Bad Request检查模型专属的必填字段、参数类型、素材数量、尺寸和枚举值。
429 Too Many Requests降低并发与查询频率；按退避间隔重试。
model_price_error / 余额不足确认该账号的模型价格已配置且额度充足；实际扣费以 NewAPI 账单为准。
5xx / 超时查看任务状态或请求记录。对创建型接口先确认请求是否已受理，再决定是否重试。
  • API Key 仅放在服务端密钥配置中，不放进浏览器端代码、移动端公开包、网页 HTML、截图或日志。
  • 请求只连接 api.jiucaihezi.studio。不要向 NewAPI 客户端发送供应商 Key、渠道编号、上游 Job ID 或内部适配器 URL。
  • 使用参考素材前确认有权提交该素材，并确保服务端能够读取。
  • 价格、模型权限、调用额度和结果保留期属于账号或线路配置，可能调整；按实际 NewAPI 返回、账户设置及账单确认。
最短接入流程：创建 API Key → 调用 /v1/models → 按模型类型选择接口 → 提交请求 → 按对应协议读取同步结果或轮询任务 → 及时保存媒体结果。
