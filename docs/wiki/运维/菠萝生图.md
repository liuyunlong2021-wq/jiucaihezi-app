# aimanplay.cn GPT 图片生成 API 使用文档

> 本文件供 AI agent 与开发者使用:请严格按本文档字段与取值调用,不要发明字段。
> 文档中的模型 id、参数枚举、字段名、计费金额均与平台代码一致,可直接照抄。

---

## 1. 平台总览

- 平台域名:**aimanplay.cn**(中文品牌:菠萝 max)
- 能力:GPT 图片生成 API(文生图 / 图生图),OpenAI Images 兼容协议
- 接口形态:**同步** —— 单次 HTTP 请求往返直接返回图片,无任务、无轮询
- 计费:按张计档计费 —— **1K/2K 档 ¥0.04 / 张,4K 档 ¥0.05 / 张**(4K 判定:请求 size 长边 ≥ 3072;按 `n` 乘张数),生成成功才扣费,失败不计费
- 额度换算:约 **1 元 ≈ 70000 quota**(金额 → quota 的展示换算按站点配置,此数值为站点约定值)
- 生成耗时:`gpt-image-2` / `gpt-image-2.5` 约 1 分钟(上游高峰期可能更久,实测可到 9 分钟以上);`flare` / `sunburst` 高质量版 3–6 分钟。**客户端超时建议 ≥ 30 分钟**(见第 6 节)
- 网站内置「图片操练场」可直接试用;操练场生成的图片平台保留 7 天,API 响应中的图片请调用方自行保存

四个可用模型:

| 模型名 | 说明 | 典型耗时 |
| --- | --- | --- |
| `gpt-image-2` | 标准文生图 / 图生图 | ~1 分钟 |
| `gpt-image-2.5` | 质量增强版 | ~1 分钟 |
| `gpt-image-2.5-flare` | 高质量版 | 3–6 分钟 |
| `gpt-image-2.5-sunburst` | 高质量版 | 3–6 分钟 |

## 2. 认证

所有接口使用 HTTP 头认证:

```
Authorization: Bearer sk-xxx
```

- 令牌前缀 `sk-`,在控制台「**令牌**」页面新建
- 不要使用 `X-API-Key` 等其它头部,一律走 Bearer

curl 通用写法:

```bash
curl https://aimanplay.cn/v1/images/generations -H "Authorization: Bearer sk-你的令牌"
```

Python 通用写法(全文变量 `TOKEN` 均指它):

```python
import os
TOKEN = os.environ["AIMANPLAY_TOKEN"]
AUTH_HEADERS = {"Authorization": f"Bearer {TOKEN}"}
```

## 3. 文生图(images/generations)

```
POST https://aimanplay.cn/v1/images/generations
Authorization: Bearer sk-xxx
Content-Type: application/json
```

请求体字段(JSON 对象):

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `model` | string | 模型名,见第 1 节表,必填 |
| `prompt` | string | 图片内容描述,必填 |
| `size` | string | 输出尺寸,`"{宽}x{高}"` 像素值。推荐按「宽高比 × 分辨率档」换算(见下表);也可以直接传显式像素(上游近似遵守,实际输出尺寸以上游响应为准)。缺省 `1024x1024` |
| `quality` | string | 画质:`auto`(默认)、`low`、`medium`、`high`。high 档上游 token 用量约 4 倍,产出通常更精细 |
| `n` | number | 生成数量,1–4,默认 1(计费按张数乘) |
| `response_format` | string | `url`(默认,返回图片链接)或 `b64_json`(返回 base64)。**生产建议 `b64_json`**:`url` 模式返回的是中转临时链接,约 24 小时失效 |

`size` 换算表(长边 = 分辨率档,短边 = 长边 ÷ 宽高比,四舍五入取整):

| 宽高比 | 1K(长边 1024) | 2K(长边 2048) | 4K(长边 3840) |
| --- | --- | --- | --- |
| 1:1 | 1024x1024 | 2048x2048 | 3840x3840 |
| 3:2 | 1024x683 | 2048x1365 | 3840x2560 |
| 2:3 | 683x1024 | 1365x2048 | 2560x3840 |
| 4:3 | 1024x768 | 2048x1536 | 3840x2880 |
| 3:4 | 768x1024 | 1536x2048 | 2880x3840 |
| 16:9 | 1024x576 | 2048x1152 | 3840x2160 |
| 9:16 | 576x1024 | 1152x2048 | 2160x3840 |
| 21:9 | 1024x432 | 2048x878 | 3840x1646 |
| 9:21 | 432x1024 | 878x2048 | 1646x3840 |

> 长边 ≥ 3072 的 size 按 4K 档计费(¥0.05/张),其余按标准档(¥0.04/张)。

curl:

```bash
curl -X POST https://aimanplay.cn/v1/images/generations \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只扁平风格的橙色狐狸头像,极简,白色背景",
    "size": "1024x1024",
    "response_format": "b64_json",
    "n": 1
  }' \
  --max-time 1800
```

Python:

```python
import base64
import requests

body = {
    "model": "gpt-image-2",
    "prompt": "一只扁平风格的橙色狐狸头像,极简,白色背景",
    "size": "1024x1024",
    "response_format": "b64_json",
    "n": 1,
}
resp = requests.post(
    "https://aimanplay.cn/v1/images/generations",
    headers={**AUTH_HEADERS, "Content-Type": "application/json"},
    json=body,
    timeout=1800,  # 同步接口,flare/sunburst 需 3-6 分钟,上游慢时可到 9 分钟以上,务必留足
)
resp.raise_for_status()
data = resp.json()

b64 = data["data"][0]["b64_json"]
with open("image.png", "wb") as f:
    f.write(base64.b64decode(b64))
```

## 4. 图生图(images/edits)

上传本地图片 + 文字描述进行修改/扩展。**`multipart/form-data`**,不是 JSON:

```
POST https://aimanplay.cn/v1/images/edits
Authorization: Bearer sk-xxx
Content-Type: multipart/form-data
```

表单字段:

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `model` | string | 同上,必填 |
| `prompt` | string | 基于参考图的修改/生成描述,必填 |
| `image` | file | 参考图文件。**多张时重复同名 `image` 字段**(不是 `image[]`、不是 `image0`) |
| `size` | string | 同第 3 节(px 值,可选) |
| `quality` | string | `auto`/`low`/`medium`/`high`,可选 |
| `response_format` | string | `url` 或 `b64_json`,同第 3 节 |

curl(单图):

```bash
curl -X POST https://aimanplay.cn/v1/images/edits \
  -H "Authorization: Bearer sk-你的令牌" \
  -F "model=gpt-image-2" \
  -F "prompt=把背景改成浅蓝色" \
  -F "image=@reference.png" \
  -F "response_format=b64_json" \
  --max-time 1800
```

curl(多图,重复 image 字段):

```bash
curl -X POST https://aimanplay.cn/v1/images/edits \
  -H "Authorization: Bearer sk-你的令牌" \
  -F "model=gpt-image-2" \
  -F "prompt=把两张图里的人物合并到同一张海报中" \
  -F "image=@a.png" \
  -F "image=@b.png" \
  --max-time 1800
```

Python:

```python
resp = requests.post(
    "https://aimanplay.cn/v1/images/edits",
    headers=AUTH_HEADERS,
    data={
        "model": "gpt-image-2",
        "prompt": "把背景改成浅蓝色",
        "response_format": "b64_json",
    },
    files=[("image", ("reference.png", open("reference.png", "rb"), "image/png"))],
    timeout=1800,
)
resp.raise_for_status()
```

## 5. 响应格式

两个接口响应结构相同(OpenAI Images 兼容):

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `created` | number | 请求时间(Unix 秒) |
| `data` | array | 图片数组,长度等于 `n` |
| `data[i].url` | string | `response_format=url` 时的图片链接(**中转临时链接,约 24 小时失效,请及时下载**) |
| `data[i].b64_json` | string | `response_format=b64_json` 时的图片 base64 |
| `data[i].revised_prompt` | string | 上游对提示词的改写(可能没有) |
| `usage` | object | token 用量统计 |

> 同一请求 `url` 与 `b64_json` 二选一返回。生产环境建议 `b64_json`,拿到即落盘,不依赖临时链接。

## 6. 超时与重试建议

- 接口为**同步阻塞**:`gpt-image-2` / `gpt-image-2.5` 约 1 分钟返回;`flare` / `sunburst` 3–6 分钟返回
- 客户端读超时**务必 ≥ 1800 秒**(requests 传 `timeout=1800`,curl 传 `--max-time 1800`);设成 30/60 秒会在高质量版模型上必然超时
- 服务器网关最长等待 1800 秒,超过则断连(此时未完成不会扣费)
- 生成失败(上游错误)返回非 2xx,**不计费**;网络层超时后可安全重试,不会重复扣费
- 无轮询、无任务查询接口;一次请求一次响应

## 7. 错误排错表

| 现象 | 说明 | 处理 |
| --- | --- | --- |
| HTTP **401** | 令牌无效 / 未传 `Authorization: Bearer sk-...` | 检查令牌是否在控制台新建、前缀是否为 `sk-`、是否过期 |
| HTTP **429** | 触发限流 | 降低请求频率,稍后重试 |
| 「余额不足」/ `insufficient_user_quota` | quota 不足以支付本次费用 | 到网站「钱包」充值,或使用兑换码 |
| HTTP **504** / 连接被断开 | 客户端或网关超时早于生成完成 | 加大客户端超时到 1800 秒;高质量模型(`flare`/`sunburst`)耗时 3–6 分钟属正常,上游高峰期可能更久 |
| `url` 模式链接 404 | 临时链接已过期(约 24 小时) | 改用 `response_format=b64_json`,或重新生成 |
| 上游报错(非 2xx + message) | 生成失败(内容审核不通过等) | 读取 message;失败不计费,可调整提示词后重试 |

## 8. 计费

- **单价:按张分档** —— 长边 < 3072(1K/2K 档)**¥0.04 / 张**;长边 ≥ 3072(4K 档)**¥0.05 / 张**;按 `n` 乘张数,生成失败不计费
- 网站图片操练场选好宽高比/分辨率后自动换算 size,计费档位随之生效
- 扣费在生成成功后结算;额度单位与展示:1 元 ≈ 70000 quota,余额以站点「钱包」展示为准
- 充值:网站「钱包」页在线充值,或使用兑换码
- 计费明细在控制台「日志 / 消费记录」可查
