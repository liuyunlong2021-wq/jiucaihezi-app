# 小易图片模型接口与 NewAPI 接入

> 更新日期：2026-09-04  
> 状态：创作面板已真实验证成功的图片接口合同。  
> 适用：韭菜盒子客户端和接入韭菜盒子图片 API 的其他客户端。

## 接口链路

当前图片链路使用 OpenAI 兼容图片接口，不走历史 `xiaoyi-image-adapter` 的异步 `/v1/videos` 方案。

```text
客户端
  -> https://api.jiucaihezi.studio/v1/images/generations
  -> NewAPI（鉴权、渠道选择、计费）
  -> https://image.xiaoyiapi.xyz/v1/images/generations
  -> 小易图片上游
```

图生图为 `POST /v1/images/edits`。客户端公共 Base URL 是 `https://api.jiucaihezi.studio`；NewAPI 上游 Base URL 填 `https://image.xiaoyiapi.xyz`，不能带 `/v1`。

## 认证

```http
Authorization: Bearer <JIUCAIHEZI_API_KEY>
Content-Type: application/json
```

示例全部使用占位符，不得把真实 API Key、Token、提示词、参考素材或临时结果 URL 写入 Wiki 或日志。

### Gemini 图片模型

| 创作面板显示名 | 客户端发送 `model` | NewAPI 上游模型 |
|---|---|---|
| Gemini 3.1 Flash Image | `gemini-3.1-flash-image-preview` | `gemini-3.1-flash-image-preview` |
| Gemini 3 Pro Image | `gemini-3-pro-image-preview` | `gemini-3-pro-image-preview` |

这两个模型必须加入小易的 `OpenAI` 类型渠道，不能进入 NewAPI Gemini/Vertex 渠道。

`gpt-image-2-Token` 使用客户端模型名 `[按token]gpt-image-2`，NewAPI 上游保持同名。它与 GPT Image 2 相同，支持 1K/2K/4K 原生画质、完整参数和最多 16 张参考图；计费按 Token，由 NewAPI 实际价格配置决定。

## 文生图

```http
POST https://api.jiucaihezi.studio/v1/images/generations
Authorization: Bearer <JIUCAIHEZI_API_KEY>
Content-Type: application/json
```

```json
{
  "model": "gpt-image-2-1k",
  "prompt": "一间有自然光的现代工作室，写实摄影风格",
  "size": "1024x1024",
  "n": 1,
  "response_format": "b64_json"
}
```

`size` 传最终像素尺寸，例如 `1:1 + 2K -> 2048x2048`、`16:9 + 2K -> 2048x1152`。

## 图生图

```bash
curl https://api.jiucaihezi.studio/v1/images/edits \
  -H "Authorization: Bearer <JIUCAIHEZI_API_KEY>" \
  -F "model=gemini-3-pro-image-preview" \
  -F "prompt=保留主体和构图，改为电影级夜景光线" \
  -F "size=2048x1152" \
  -F "n=1" \
  -F "response_format=b64_json" \
  -F "image=@./reference.png"
```

使用 `multipart/form-data`。普通 GPT Image 2 路由最多 8 张参考图，单张不超过 20 MB、总计不超过 64 MB；`gpt-image-2-Token` 最多 16 张，沿用 GPT Image 2 的其他参数和原生画质能力。Gemini 最多 10 张，单张不超过 10 MB。参考图必须是 `image/*`。

## 响应与参数

```json
{
  "created": 1750000000,
  "data": [{ "b64_json": "<BASE64_IMAGE>" }]
}
```

服务也可能返回 `{ "url": "<IMAGE_URL>" }`；客户端必须兼容 `b64_json` 和 `url`。`model`、`prompt` 必填；`n` 建议从 `1` 开始；`response_format` 使用 `b64_json` 或 `url`。

Gemini 支持 `1K`、`2K`、`4K`，比例为 `1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`、`5:4`、`4:5`、`21:9`；提示词当前上游上限 20,000 字符。尺寸应保持精确比例、两边为 16 的倍数，且不超过上游最大边和总像素限制。

## NewAPI 配置

1. 使用 `OpenAI` 类型渠道。
2. 上游 Base URL 填 `https://image.xiaoyiapi.xyz`，不带 `/v1`。
3. 将对应上游模型加入该渠道；GPT Image 2 按上表映射，Gemini 保持同名映射或不映射。
4. 从 Gemini/Vertex 类型渠道移除两个 Gemini 图片模型，避免误路由。
5. 为每个可售模型配置价格。

模型映射只负责改名后转发，例如 `gpt-image-2-低质量 -> gpt-image-2`；它不会把请求从错误渠道切换到正确渠道。

## 常见错误

| 错误现象 | 根因与处理 |
|---|---|
| `only imagen models are supported` | 请求误入 NewAPI Gemini/Vertex adaptor；将 Gemini 图片模型加入小易 `OpenAI` 渠道，并从 Gemini/Vertex 渠道移除。 |
| 404 或路径重复 | 上游 Base URL 已含 `/v1` 又被客户端追加；只填 `https://image.xiaoyiapi.xyz`。 |
| `model_not_found`、无可用渠道 | 模型未加入正确渠道/分组，或客户端发送名与映射左侧不一致。 |
| `model_price_error` | NewAPI 未配置模型价格。 |
| 成功但客户端无图 | 客户端未同时处理 `url` 和 `b64_json`。 |
