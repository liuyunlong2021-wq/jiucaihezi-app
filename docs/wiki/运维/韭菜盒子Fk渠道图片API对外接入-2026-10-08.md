# 韭菜盒子 Fk 渠道图片 API 对外接入

> 本文面向第三方 API 调用方，只描述韭菜盒子 NewAPI 公网接口。调用方使用韭菜盒子 API Key；Fanke 上游 Key、上游 `jobId` 和插件内部轮询均不对外提供。
>
> **接入状态：** 本文按本地 `fk` Task Plugin `0.2.0` 与创作面板合同编写。插件上传/启用、渠道模型列表及定价配置、真实生成/轮询/下载/扣费仍须以生产验收为准；调用前先用自己的 API Key 查询 `/v1/models`。

## 1. 接入信息

| 项目 | 值 |
|---|---|
| Base URL | `https://api.jiucaihezi.studio` |
| 查询可用模型 | `GET /v1/models` |
| 文生图 | `POST /v1/images/generations` |
| 图生图 | `POST /v1/images/edits` |
| 认证 | `Authorization: Bearer <韭菜盒子 API Key>` |
| 文生图格式 | JSON (`application/json`) |
| 图生图格式 | multipart/form-data；也可用 JSON 传可公开访问的 HTTPS `imageUrls` |

不要把 Fanke API Key、`X-Public-Model-Ids`、上游 `jobId` 或 `ai.fanke2026.xyz` 地址放进客户端请求。它们属于平台渠道内部配置。

## 2. 查询可用模型

```bash
export JIUCAI_API_KEY='<你的韭菜盒子 API Key>'

curl 'https://api.jiucaihezi.studio/v1/models' \
  -H "Authorization: Bearer $JIUCAI_API_KEY"
```

以该 Key 返回的模型为准。模型是否可见、可调用取决于账号权限、分组和 NewAPI 渠道状态。请求中的 `model` 必须使用下表完整 ID，不能使用创作面板显示名。

## 4. 文生图

```bash
curl --location 'https://api.jiucaihezi.studio/v1/images/generations' \
  --header "Authorization: Bearer $JIUCAI_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "ft-image-v1-211f28f47b0355abb1798f72eb65f22d",
    "prompt": "一只橘猫坐在窗边，柔和自然光，写实摄影",
    "ratio": "16:9",
    "imageSize": "2K"
  }'
```

## 5. 图生图

### 上传本地参考图

图生图通过 multipart 上传图片；多张参考图时重复传 `images` 字段：

```bash
curl --location 'https://api.jiucaihezi.studio/v1/images/edits' \
  --header "Authorization: Bearer $JIUCAI_API_KEY" \
  --form 'model=ft-image-v1-211f28f47b0355abb1798f72eb65f22d' \
  --form 'prompt=保留主体和构图，将画面改成电影感的雨夜街景' \
  --form 'ratio=16:9' \
  --form 'imageSize=2K' \
  --form 'images=@./reference-1.png' \
  --form 'images=@./reference-2.png'
```

### 传公网参考图 URL

`/v1/images/edits` 也接受 JSON。URL 必须是无需登录、服务端可访问的 HTTPS 图片地址：

```bash
curl --location 'https://api.jiucaihezi.studio/v1/images/edits' \
  --header "Authorization: Bearer $JIUCAI_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "ft-image-v1-211f28f47b0355abb1798f72eb65f22d",
    "prompt": "参考图片的主体，改成水彩插画风格",
    "ratio": "1:1",
    "imageSize": "1K",
    "imageUrls": ["https://example.com/reference.png"]
  }'
```

公网 URL 别名还包括 `imageUrl`、`image_url`、`image_urls`、`images`、`image`。本地文件请用 multipart；不要把本机路径、`file:`、`blob:`、`data:` URL 当作公网图片 URL 传入。

## 6. 请求字段

| 字段 | 类型 | 用途与限制 |
|---|---|---|
| `model` | string | 必填；使用第 3 节完整模型 ID。 |
| `prompt` | string | 必填；图片生成描述。 |
| `ratio` | string | 可选；比例枚举见第 3 节，默认 `auto`。也接受 `aspect_ratio`、`aspectRatio`。 |
| `imageSize` | string | 可选；`1K`、`2K`、`4K`。也接受 `image_size`、`resolution` 作为兼容别名；旧 `quality` 字段也必须传这三个值之一。 |
| `imageUrls` | string[] | 可选；图生图 HTTPS 参考图 URL。也接受第 5 节列出的 URL 字段别名。 |
| `images` | multipart file[] | 可选；图生图本地文件。多张时重复 `images` 字段。 |

`size` 仅用于 `ratio` 缺省时推算最接近的支持比例；推荐显式传 `ratio`。`n`、`response_format` 不控制 Fanke 上游的生成张数或结果编码：不能依赖它们请求多张或要求 Base64。结果张数由上游返回决定，计费按实际返回张数结算。

## 7. 响应与轮询

成功后返回 OpenAI 图片响应的 `data` 列表：

```json
{
  "data": [
    { "url": "https://...signed-image-url..." }
  ]
}
```

图片任务在 Fanke 侧异步执行，但 `fk` 插件由 NewAPI 服务端使用上游 `jobId` 轮询；调用方等待 `POST /v1/images/generations` 或 `POST /v1/images/edits` 返回结果即可。**调用方不会收到 Fanke `jobId`，也没有供调用方查询该图片任务的 `GET /v1/images/...` 轮询接口。** 这与视频接口返回 NewAPI task ID、由客户端轮询的模式不同。

响应目前返回带签名的图片 URL，而不是 `b64_json`。URL 中的签名查询参数必须完整保留；请在 URL 失效前下载图片。当前 FK 图片接口没有独立的 `/content` 下载端点。

如果客户端等待超时或连接中断，不要立刻重复提交：上游任务可能仍在运行并产生费用，而对外响应不暴露上游 jobId。先保留时间、模型 ID 和脱敏请求信息，再联系平台管理员排查。

## 8. 计费

图片插件报告 `image_count` 用量；任务完成后按实际结果 URL 数量更新用量。NewAPI 模型定价表达式按对应单价设置，例如：

```text
FK-image2 / FK-image2.5 / FK-image2.5-flare / FK-image2.5-sunburst:
tier("base", u("image_count") * 0.08)

FK-banana-2:
tier("base", u("image_count") * 0.2)

FK-banana-pro:
tier("base", u("image_count") * 0.3)
```

这是配置合同，不代表生产定价、退款与实际账单已验收；最终以调用账户账单为准。

## 9. 常见错误

| 返回情况 | 排查方向 |
|---|---|
| `400` / `prompt is required` | 检查提示词、JSON/multipart 格式和字段名。 |
| `Unsupported Fk image model` / `model_not_found` | 使用完整模型 ID；确认模型已在 `/v1/models` 返回、渠道模型列表包含该 ID、映射配置正确。 |
| `401` / `403` | 检查韭菜盒子 API Key、账号权限、分组和渠道状态。不要把供应商 Key 当作调用方 Key。 |
| `429` | 降低并发和提交频率；先检查已有请求结果，避免重复生成。 |
| `5xx` / 超时 | 保存时间、模型 ID 和脱敏请求信息联系管理员；创建请求不要盲目重试。 |
| `Fk image task completed without result URLs` | 上游虽报告完成但未提供可用结果链接，联系管理员并提供请求时间。 |

错误状态与响应体由 NewAPI、Task Plugin 宿主及上游共同决定；上表是排查方向，不保证每种错误都固定使用某个 HTTP 状态或 JSON 结构。
