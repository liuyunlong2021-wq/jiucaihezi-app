# 创作模型运行矩阵

> **最后更新**: 2026-08-01
> **当前分支**: `main`
> **原则**: 模型名是调用合同；渠道由 NewAPI 选择，客户端不保存渠道 ID。

## 事实源

| 内容 | 唯一事实源 |
|------|------------|
| 模型名、任务类型、前端字段、路由 | `src/runtime/creation/creationModelRegistry.ts` |
| RunningHub 模型到端点 | `rh-adapter/src/models/mapping.py` |
| RunningHub 官方参数能力 | `rh-adapter/src/models/capabilities.json` |
| 显示价格 | [[运维/模型价格表-2026-07-29]] |
| NewAPI 是否有可用渠道、真实扣费 | NewAPI 管理后台与调用日志 |

本页只记录跨层合同和运维风险，不复制一份完整模型注册表。新增、删除或改价必须修改上述事实源，不能只改本页或 UI。

## 请求路由

```text
创作面板选择模型名
  → CreationRunPlan 保留原始 model
  → NewAPI 按 model 选择当前可用渠道并计费
  ├── 直连上游
  └── RunningHub Channel → rh-adapter → 对应 RH API
```

| 类型 | App 提交合同 | 适配层 | 结果处理 |
|------|--------------|--------|----------|
| OpenAI 兼容图片 | `/v1/images/generations` 或 `/v1/images/edits` | NewAPI 渠道 | 同步结果或任务结果落项目文件 |
| NewAPI 视频任务 | `/v1/videos` | NewAPI 渠道 | 轮询后落项目文件 |
| RunningHub 标准图片/视频/音频/3D | 现有 `/v1/*` 或 `/rh/submit/*` | `rh-adapter` 按模型 mapping | `/rh/tasks/{id}` 轮询后落项目文件 |
| RunningHub AI 应用 | 通用模型 `rh-aiapp` + `webappId` + `nodeInfoList` | `rh-adapter` AI App 合同 | 按声明的媒体类型保存与展示 |

请求只发送注册表中的模型名，例如 `gpt-image-2`。不得加入 `newapi/t8/...`、渠道 ID 或供应商前缀来绑定渠道；NewAPI 有该模型的启用渠道就能调用，没有就明确失败。

### 已有技术证据

- `rhart-video-g/image-to-video` 页面明确提示迁往全球站；当前 `rh-grok-image-video` 使用此端点。
- RunningHub 标准模型仍共用 `RH_BASE_URL=https://www.runninghub.cn`。
- AI App 的运行、状态、结果端点已是 `runninghub.ai`，节点发现和上传仍有 `.cn` 端点。

因此不能全局替换域名。必须逐模型在全球站确认端点、Key 和请求参数，再只调整受影响 mapping。用户反馈“不可用”是停用/排查依据，不等于全球站合同已经验证通过。

### 官方公开资料核查（2026-07-30）

- [RunningHub 全球站首页](https://www.runninghub.ai/) 是官方全球站；公开模型目录包含 Grok Imagine、Sora 2、Google Veo 3.1/3.1 Lite。
- `https://www.runninghub.ai/openapi/v2/rhart-video-g/image-to-video`、`/rhart-video-s/text-to-video`、`/rhart-image-g-2/text-to-image` 的公开说明页均存在，但页面可打开不是 API Key、上传、提交和结果轮询可用的证据。
- [HM-RunningHub/ComfyUI_RH_OpenAPI](https://github.com/HM-RunningHub/ComfyUI_RH_OpenAPI) 是 RunningHub 官方组织维护的 OpenAPI 工具仓库；截至本次核查，仓库未提供中国站迁往全球站的逐端点迁移名单。

结论：官网可确认全球站覆盖的厂牌范围，不能替代单模型真实任务。以下清单是后续核验顺序，不是批量切站名单：

创作面板当前只有一个通用注册模型 `rh-aiapp`。下列项目只是 UI 快捷入口，不是六套独立前端模型：

| 名称 | AI App webappId |
|------|-----------------|
| 极速数字人 | `2028055408421642241` |
| 数字人 | `2036019863617015809` |
| 我是导演 | `2029950473750454274` |
| 声音克隆 | `2046193597401276417` |
| 声音设计 | `2035739697670000642` |

手动输入未注册的 `webappId` 会被服务器拒绝；应用必须先进入可信目录并声明计费模型和输出类型。App 通过 `/api/runninghub/app-info` 读取可修改节点并动态生成表单，当前支持文本、列表、布尔、整数/浮点、图片、视频和音频字段。

`2082627353599107074` 已决定不注册，不加入白名单、可信目录或 NewAPI 渠道。

- `rh-gpt2-official`；
- `rh-grok-video-edit`；

- `grok-imagine-1.0`；
- `rh-midjourney-v81`；

## 新增或迁移验收

1. 在事实源中确认模型名、端点、输入字段和输出类型。
2. 在 NewAPI 管理后台启用同名模型并配置价格；不在客户端写渠道 ID。
3. 重建受影响 adapter，健康检查只作为服务可达证据。
4. 从正式 App 提交真实任务，核对 NewAPI 日志、扣费、上游状态和项目文件。
5. 分别验证预览、下载、放到画布或音频播放器；构建成功不能代替用户功能通过。
