# 韭菜盒子图片模型 API 对外接入

> 适用：第三方客户端通过韭菜盒子 NewAPI 调用图片模型。本文只描述韭菜盒子公开接口，不包含任何上游渠道信息。

## 接入信息

| 项目 | 值 |
|---|---|
| Base URL | `https://api.jiucaihezi.studio` |
| 文生图 | `POST /v1/images/generations` |
| 图生图 | `POST /v1/images/edits` |
| 认证 | `Authorization: Bearer <你的 API Key>` |

```http
Authorization: Bearer <YOUR_API_KEY>
```

## 可用模型

| 显示名 | 请求 `model` |
|---|---|
| GPT Image 2 1K | `gpt-image-2-1k` |
| GPT Image 2 低质量 | `gpt-image-2-低质量` |
| GPT Image 2 中质量 | `gpt-image-2-中质量` |
| GPT Image 2 VIP | `gpt-image-2-vip` |
| GPT Image 2 官方 | `gpt-image-2-官方` |
| gpt-image-2-Token | `[按token]gpt-image-2` |
| Gemini 3.1 Flash Image | `gemini-3.1-flash-image-preview` |
| Gemini 3 Pro Image | `gemini-3-pro-image-preview` |

GPT Image 2 常规模型支持 1K/2K/4K；Token 模型支持 1K/2K/4K 原生画质和最多 16 张参考图。Gemini 图片模型支持 1K/2K/4K、十种常用比例和最多 10 张参考图。

## 文生图

```bash
curl --location 'https://api.jiucaihezi.studio/v1/images/generations' \
  --header 'Authorization: Bearer <YOUR_API_KEY>' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "gpt-image-2-1k",
    "prompt": "一间有自然光的现代工作室，写实摄影风格",
    "size": "1024x1024",
    "n": 1,
    "response_format": "url"
  }'
```

## 图生图

```bash
curl --location 'https://api.jiucaihezi.studio/v1/images/edits' \
  --header 'Authorization: Bearer <YOUR_API_KEY>' \
  --form 'model=gemini-3-pro-image-preview' \
  --form 'prompt=保留主体和构图，改为电影级夜景光线' \
  --form 'size=2048x1152' \
  --form 'n=1' \
  --form 'response_format=url' \
  --form 'image=@./reference.png'
```

图生图使用 `multipart/form-data`。参考图字段可重复提交；只接受 `image/*`。

## 请求参数

| 参数 | 说明 |
|---|---|
| `model` | 必填，使用上表请求名。 |
| `prompt` | 必填，图片描述文本。 |
| `size` | 像素尺寸，例如 `1024x1024`、`2048x1152`。 |
| `n` | 生成数量，建议 `1`。 |
| `response_format` | `url` 或 `b64_json`。 |
| `image` | 图生图参考图片，可传多张。 |

常用尺寸：`1:1 + 2K = 2048x2048`，`16:9 + 2K = 2048x1152`。客户端应按所选比例传递对应像素尺寸。

## 响应格式

```json
{
  "created": 1750000000,
  "data": [
    { "url": "<IMAGE_URL>" }
  ]
}
```

也可能返回：

```json
{
  "created": 1750000000,
  "data": [
    { "b64_json": "<BASE64_IMAGE>" }
  ]
}
```

客户端必须兼容 `url` 和 `b64_json` 两种结果。

## 错误处理

| 错误 | 处理 |
|---|---|
| `401` / `403` | 检查 API Key 和请求权限。 |
| `model_not_found` | 检查 `model` 拼写及账号可用模型。 |
| `model_price_error` | 该模型尚未配置计费价格，请联系管理员。 |
| `400` | 检查必填字段、`size`、参考图格式和数量。 |
| `5xx` / `524` | 服务端或渠道暂时超时；稍后重试并避免重复提交大量任务。 |

## 兼容边界

- 第三方客户端只需要连接本页 Base URL，不需要知道任何上游服务地址。
- API Key 仅放在请求头，不要写入前端公开代码、日志或文档。
- 模型可用性、价格和限额以韭菜盒子 NewAPI 当前配置为准。
