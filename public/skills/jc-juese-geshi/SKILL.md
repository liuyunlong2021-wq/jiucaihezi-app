# jc-juese-geshi｜角色画风与排版

输入已选定的人物参考图或已有角色文字提示词、画幅及目标画风，输出一条完整中文三格人物设定图提示词。有图时用于图生图，只有文字时用于文生图。人物内容以用户选定的材料为准，本 Skill 只负责画风、三格排版、视角、姿态、背景与照明。

## 输入与选择

- 图片模式：使用用户附图或明确指定的已有参考图，先查看参考图；沿用图中身份与造型。角色小传只用于核对身份。
- 文字模式：使用用户本轮提供或明确指向的已有角色文字提示词，包括刚由角色设计 Skill 生成的结果。文字模式不要求先生成或提供参考图；直接提取已有外貌、发型、身材、服装、配饰和画风，整理成三格格式，不重新设计人物或服装，不声称已经看过不存在的图片。只有人物小传或名字、没有可用外貌与造型描述时，说明缺少哪些设定，不擅自替用户重新设计。
- 图文并用时按用户明确指定的身份、造型来源处理；来源冲突且影响角色时再询问。用户只要求“按格式整理”时，不自动生图或要求先跑其他制作阶段。
- 多张参考图时按用户指定的面部／造型职责取用；身份或服装相互冲突时先明确采用哪张，不混成新角色。
- 环境角色图未展示的背面或隐藏结构，优先沿用已有造型设定；没有依据的必要补全须简短标明为设计补充，不能声称已由参考图锁定。影响身份或关键造型的缺口才询问，不因普通背面衣料延续而强制增加生图步骤。
- 画幅与画风从本轮要求或已确认的创作方向读取；缺少画幅且无法推断时询问。画风未指定时沿用下面模板的真实照片级质感。
- 图片和已有角色文字提示词都没有时，才要求提供其中一种材料。已有参考图或已有角色文字提示词可直接进入本 Skill，无需先跑角色生活照设计。H3／Seedance视频提示词的格式转换不属于本Skill，交回对应视频Skill。

## 模板

只读取本轮所需的一份模板：

- `9:16` 竖屏：读取 [references/9-16.md](references/9-16.md)，上方身份特写，下方左格正面无头人台、右格带头背面全身。
- `16:9` 横屏：读取 [references/16-9.md](references/16-9.md)，左格正面无头人台、中格带头背面全身、右格身份特写。

保留模板的身份、造型一致性，正面人台的干净切边与肩线上方留白，背面完整带头，统一18%中灰背景、无阴影正面照明和纤细分隔线。正面无头格是完整衣着的人台式展示，不是伤害情节。不要把生活照中的表情、动作、场景和光线带进参考板。

文字模式仍用同一份横竖屏模板，以已有角色描述为身份与造型来源，将原材料的具体人物与服装细节写入提示词；模板中的“角色文字提示词或人物参考图”须按实际输入明确为本轮采用的来源。没有图片时，不保留“所附参考图”等虚假引用；不要只输出模板或遗漏原有造型。原材料未定义的背面结构沿用现有造型作必要延续，关键缺口简短标明或询问，不新增与格式整理无关的角色设计。

## 文字模式的交付顺序

按以下顺序输出一条可直接用于文生图的完整提示词，不要求先生成单幅角色图：

1. 整体构图：说明横竖屏三格布局、纤细分隔线、同一人物与同一套造型。
2. 共用身份描述：保留原提示词的年龄、体型、面容、五官、发型发色、妆容和固定身份配饰，单独成段，注明“此段身份描述适用于全部三格”。不重新随机设计或美化成另一张脸。
3. 共用造型描述：保留原服装、材质、颜色、鞋履与配饰，单独成段，注明“此段造型描述适用于全部三格”。不换装，不为了背面展示擅自添加交叉肩带、开背等未定义结构。
4. 各格画面：完整展开本轮横竖屏模板的正面无头全身、带头背面全身、身份特写；各格只展开该视角可见的原设定。共用身份不代表无头格也应出现头发，长发角色的正面无头格仍须肩线上方留白、肩胸无垂发。
5. 统一背景与照明：保留模板的18%中灰无缝背景、均匀无阴影正面照明和无投影要求。
6. 画风与质感：沿用用户已经认可的画风；写实时保留摄影质感，二维/三维时按相应媒介表达，不把原画风改成写实。

原提示词中的故事场景、镜头动作与环境光照仅在本次三格版式需要时替换；人物身份、脸部细节、服装与材质不因此丢失。不输出“请参考上文”的省略版，也不自动生图；用户另行明确要求生成时，由可用影音工具按新提示词提交文生图，文字模式不凭空附加参考图。

目标为写实摄影时直接使用模板末段；目标为二维、三维或其他指定画风时，仅将末段照片质感替换成统一的目标媒介表达，不再混入真实相机、照片毛孔、胶片颗粒或“绝非CGI”等冲突要求。身份、身体比例、服装结构与固定辨识特征继续继承原材料，画风转换不等于重新设计人物。

## 交付

只输出完整提示词，默认中文；用户指定其他语言时遵循。模板中的所有模块都应出现在最终提示词中，不能只写“按模板排版”。不自动生成图片；若用户要求提交，由调用方使用可用的异步影音工具处理。

交付前核对：横竖屏格位正确；同一人同一造型；身份特写为头顶略上方至锁骨的紧凑构图；正面无头格肩线上方留白、肩胸区域无垂发；背面带头且从头顶到鞋子完整；背景和光照统一；目标画风唯一。
