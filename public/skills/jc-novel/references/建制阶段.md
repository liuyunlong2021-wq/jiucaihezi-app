# 建制阶段（阶段1-7）

任务入口与确认规则见[SKILL.md](../SKILL.md)。只执行本轮请求的阶段或设定任务，已有条件直接沿用；下方交互模板用于补缺失条件，不逐项重复询问。完成当前交付后，由用户决定是否进入下一阶段。

创作规划与资产通过 `wiki_save_artifact` 归档；先读运行时索引复用真实页面，工具负责推导路径、写入与索引。完整落位与提交规则见[落位与提交](落位与提交.md)。引擎只按[引擎路由表](engines/index.md)选择，不要求每个阶段调用引擎。

## 阶段 1：灵感策划

**交互模板**：
```
请告诉我你想写什么类型的小说：
A. 玄幻/修仙
B. 都市/现实
C. 悬疑/惊悚
D. 言情/甜宠
E. 科幻/末世
F. 历史/架空
G. 用户自定义

目标读者：[男频/女频/通用]
目标字数：[50万/100万/200万/其他]
```

根据用户给定或补齐的条件产出创意方案；未指定数量时可给 3–10 个，每个含一句话梗概和类型标签。市场判断标明依据与不确定性，不编造近期榜单或市场数据。

**产出**：`创作/灵感方案.md`（路径以运行时索引登记的真实文件名为准）

---

## 阶段 2：市场分析

**目标**：赛道定位 + 对标作品。

1. 分析赛道竞争格局
2. 推荐 2-3 部对标作品
3. 提炼可复用的成功要素

**产出**：`创作/市场分析.md`

---

## 阶段 3：核心梗

**目标**：一句话高概念 Logline。

**Logline 公式**：
```
当一个[极致角色]遇到[催化剂]，
必须在[两难选择]中[做什么]，
否则[代价]。
```

需要选方向时提供 2–3 个 Logline；用户已有核心梗并要求完善时，直接完善该版本，不重新要求选方向。

**产出**：`创作/核心梗.md`

---

## 阶段 4：角色设计

**目标**：主角/配角/反派/关系网。

**主角**：极致维度（8-10/10）+ 内核动机 + 红线 + 性格 + 弧光
**配角**：与主角关系 + 独立动机
**反派**：对立面 + 核心冲突

模板见 [核心机制](核心机制.md)。

**产出**：

- `资产/角色/<角色名>.md`（一个角色一个页面，文件名 = 规范名，模板见 [核心机制](核心机制.md)）
- 关系写成 `[[资产/角色/主角]] → [[资产/角色/对手]]` 这类双链，写进两个角色页的「设计」节；关系的事实版本由节点分析产出

---

## 阶段 5：大纲

**目标**：全书结构 + 情节节点 + 节奏曲线。

- 三幕/五幕结构
- 关键转折点（≥3个）
- 字数分配
- 伏笔布局

**产出**：

- `创作/大纲.md`
- `创作/世界设定.md`
- `创作/伏笔.md`

---

## 阶段 6：章纲

**目标**：逐章详细规划。

每章：目标/冲突/信息增量/字数预估/催化剂类型/钩子

**产出**：`创作/章纲.md`

---

## 阶段 7：文案包装

**产出**：
- 3 个备选书名
- 简介（≤200字）
- 标签（5-8个）

**产出**：`创作/文案包装.md`（含 3 个备选书名、简介≤200字、5-8 个标签）
