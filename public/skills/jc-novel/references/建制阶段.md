# 建制阶段（阶段1-7）

每个阶段产出一个页面，落到 `创作/`。**落盘前先读运行时给的索引拿真实路径**：索引里已有 `创作/index.md` 就按它登记的名字写，没有就先建页面再登记索引。完整落位表、写入顺序和禁止事项见 `references/落位与提交.md`。

## 阶段 1：灵感策划

**交互模板**：
```
请告诉我你想写什么类型的小说：
A. 玄幻/修仙
B. 都市/现实
C. 悬疑/惊悚
D. 言情/甜宠
E. 科幻/末世
F. 历史/架空
G. 用户自定义

目标读者：[男频/女频/通用]
目标字数：[50万/100万/200万/其他]
```

用户回复后，产出 3-10 个创意方案，每个含一句话梗概 + 类型标签 + 预估市场空间。

**产出**：`创作/灵感方案.md`（路径以运行时索引登记的真实文件名为准）

---

## 阶段 2：市场分析

**目标**：赛道定位 + 对标作品。

1. 分析赛道竞争格局
2. 推荐 2-3 部对标作品
3. 提炼可复用的成功要素

**产出**：`创作/市场分析.md`

---

## 阶段 3：核心梗

**目标**：一句话高概念 Logline。

**Logline 公式**：
```
当一个[极致角色]遇到[催化剂]，
必须在[两难选择]中[做什么]，
否则[代价]。
```

**交互模板**：生成 2-3 个 Logline，用户选一个。

**产出**：`创作/核心梗.md`

---

## 阶段 4：角色设计

**目标**：主角/配角/反派/关系网。

**主角**：极致维度（8-10/10）+ 内核动机 + 红线 + 性格 + 弧光
**配角**：与主角关系 + 独立动机
**反派**：对立面 + 核心冲突

模板见 `references/核心机制.md`。

**产出**：

- `资产/角色/<角色名>.md`（一个角色一个页面，文件名 = 规范名，模板见 `references/核心机制.md`）
- 关系写成 `[[资产/角色/主角]] → [[资产/角色/对手]]` 这类双链，写进两个角色页的「设计」节；关系的事实版本由节点分析产出

---

## 阶段 5：大纲

**目标**：全书结构 + 情节节点 + 节奏曲线。

- 三幕/五幕结构
- 关键转折点（≥3个）
- 字数分配
- 伏笔布局

**产出**：

- `创作/大纲.md`
- `创作/世界设定.md`
- `创作/伏笔.md`

---

## 阶段 6：章纲

**目标**：逐章详细规划。

每章：目标/冲突/信息增量/字数预估/催化剂类型/钩子

**产出**：`创作/章纲.md`

---

## 阶段 7：文案包装

**产出**：
- 3 个备选书名
- 简介（≤200字）
- 标签（5-8个）

**产出**：`创作/文案包装.md`（含 3 个备选书名、简介≤200字、5-8 个标签）
