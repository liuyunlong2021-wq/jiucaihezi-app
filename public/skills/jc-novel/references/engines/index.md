# 写作引擎路由表

用途：按阶段查「这一步该读哪个引擎」，不用通读 `engines/` 下的 100 个文件。

读法：先确定当前阶段 → 在本表找到对应小节 → 按「什么时候读」挑 1-3 个 → 只读挑中的那一个文件。**不要一次读多个引擎**，也不要因为想知道有什么而读完整目录。

本表按**何时读**组织，不按内容分类。同一个引擎只登记在最常触发的阶段，跨阶段复用写在行内。

---

## 阶段1 灵感策划

| 引擎 | 什么时候读 |
| --- | --- |
| 发散穷举器 | 用户只给了一个词或一句话，要铺开选项 |
| 爆款迁移引擎 | 用户点名"想要 XX 那种感觉"，要拆骨架迁移 |
| 屠龙宝刀三问法 | 点子平庸、或用户卡在"想不出" |
| 原始动力扫描仪 | 创意成型前，检查是否触及原始驱动力 |
| 逆毛摸引擎+格式化 | 想要反套路、反差开场 |
| 多频道AB测试器 | 同一创意要评估男频/女频等不同频道 |
| 游戏化剧情设计器 | 系统流、面板流、升级流题材 |
| 三维风险评估器 | 方案要交付前，做市场/执行/政策三向扫描 |
| 排毒自检过滤器 | 概念刚确立，剔自恋、无聊、逻辑不通 |
