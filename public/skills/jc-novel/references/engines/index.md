# 写作引擎路由表

用途：按阶段查「这一步该读哪个引擎」，不用通读 `engines/` 下的 100 个文件。

入口、任务范围和确认规则见[SKILL.md](../../SKILL.md)。本表是引擎选择的唯一来源；流程文件描述工作目标，不另列必调引擎链。

## 选择顺序与读取额度

1. 用户点名引擎时，按下方真实文件链接读取；没有点名时先确定当前任务与具体问题。
2. 仅讨论、检查落位、确认章节、已有充分方法的简单任务可读取 **0 个**引擎。
3. 有具体问题时优先按下方「什么时候读」选择 **1 个主引擎**；仅当主引擎未覆盖另一明确问题时，再选 **0–2 个条件引擎**。找不到更具体匹配时才用默认主引擎表。
4. 每个当前任务最多读取 **3 个不同引擎**，逐个读取；一章的四个写作阶段共用额度，跨阶段重复行不重复读取文件。用户明确要求的专项范围优先。问题解决后交付，不为了凑数量追加引擎。
5. 两个引擎处理同一问题时选择最贴切的一项：单一视角用「视角修正器」，多视角或频繁切换用「视角修正器_v2」；开篇体验承诺用「确定性承诺器」，章末断章用「确定性承诺引擎」。

本表按触发时机组织。同一引擎可在多个阶段出现，行内标明复用；实际文件只有一份。引擎内旧 Agent／SKILL 编号是方法标签，执行仍在当前会话内，不调用不存在的 Agent、独立 Skill 或扩展目录。名称含“爬虫”“Excel”不代表已有相应工具；只使用当前实际可用的资料和工具，不编造抓取结果。
