# 角色服装设计图提示词

## 任务

把用户提供的角色身份、时代与场景、性格、服装描述、画幅、视觉风格和可选服装参考图，整理成**一条完整中文服装设计图生图提示词**。产物用于把服装图与既有角色参考图组合，生成同一角色的新造型。

输出聚焦可复用的服装资产：主体服装、头饰、鞋履、首饰、腰封、腿部组件、披挂及其它穿戴配件。它不是人物立绘、角色三视图、时装海报或穿搭街拍。

## 适用边界

适用于：

- 为已有角色设计一套可换装的新衣服；
- 根据文字或服装参考图，生成独立、可拆分、可识别的服装资产图；
- 为漫剧、动画、游戏或连续生图建立可复用的服装造型证据；
- 需要同时设计礼服、盔甲、制服、古装、现代时装、神话服饰或舞台造型，并清楚展示头饰、鞋履和配件。

不适用于：

- 生成带脸、发型、表情或人物身份锁定的角色设定图（使用 `jc-character-prompt`）；
- 只设计单一手持道具、武器或环境物件；
- 生成真人穿搭宣传海报、品牌广告、商品详情页或带大量说明文字的服装目录。

## 输入理解与默认值

先从用户输入中提取：服装用途与身份、世界观/时代、气质、性别表达与体型适配、主辅色、材质、结构、装饰、鞋履、头饰、特殊功能、画幅和视觉风格。

用户有服装参考图时，只提取其中**可见的服装事实**：轮廓、分件关系、领口与肩部、腰线、下装、鞋型、头饰、饰品、材质、纹样、金属工艺和色彩逻辑。不要复制参考图中人物的脸、肤色、发型、体型、姿势、摄影背景、水印或品牌标识。

用户同时提供角色参考图与服装参考图时，角色图仅用于判断服装的性别表达、身材比例、时代感和角色调性；最终服装图仍不出现可识别的脸部、头发或完整人物。

用户没有给出细节时，以角色职业和世界观补足少量可见设计值。默认输出 `1:1` 的独立服装资产图；用户指定 `16:9` 或 `9:16` 时，保持同一套服装和同样的部件逻辑，仅调整排版比例。

## 服装视觉命题

先用一句话定义服装视觉命题，使剪影、材质、配色和装饰服务于同一个角色状态。格式：

`服装视觉命题：以[核心身份/情绪]为中心，用[主轮廓]、[主材质]和[标志性装饰]表达[戏剧功能]。`

例如：`服装视觉命题：以太阳女祭司的庄严与攻击性为中心，用收束金属胸衣、放射冠饰和垂落金丝流苏表达神圣、危险且可登台的仪式感。`

这句话需要转化为可见结构，不要停留在“高级、酷、仙、华丽”等抽象词。

## 设计规则

### 1. 从外轮廓到分件结构

按以下顺序描述服装：

1. 总体剪影：H 型、X 型、倒三角、钟形、战甲型、飘逸长线条或不对称结构；
2. 主体上装：领口、肩部、胸腰结构、开合方式、贴身或悬垂关系；
3. 下装：裙、裤、裙甲、流苏、披帛、护腿或分片的长度与层级；
4. 鞋履与腿部组件：鞋头、鞋跟、绑带、靴筒、金属护片和脚踝结构；
5. 头饰与首饰：佩戴位置、与主体服装的呼应关系、正面轮廓；
6. 关键配件：腰封、肩甲、臂环、手套、披挂、徽记等。

每套服装至少确定一个远景可识别的剪影锚点、一个近看可识别的结构锚点、一个材质或色彩锚点。

### 2. 材质与工艺必须可生图

把材质写成可见的物理属性：厚薄、硬软、反射方式、边缘处理、压纹、褶皱、磨损和连接方式。不要只写“高级材质”。

- 金属：说明抛光/拉丝/锤纹/氧化、板片厚度、铆钉/链环/扣具、镜面高光与暗部反射。
- 织物：说明真丝、天鹅绒、纱、皮革、锦缎、粗麻或功能布，以及垂坠、挺括、织纹与包边。
- 珠宝与装饰：说明珍珠、宝石、珐琅、刺绣、串珠、花片、流苏、羽毛或骨饰的尺寸、排列与连接逻辑。
- 旧化或战损：只在用户需要时写明磨损位置、掉漆、褪色、修补与尘土；仪式礼服默认整洁完整。

### 3. 色彩系统

明确主色、辅色、强调色及其位置。控制为二至四种主要色相，避免无逻辑的彩色堆叠。

例如：主色“镜面古金”覆盖胸衣和护腿；辅色“暖象牙白”用于内层与珠饰；强调色“深酒红”只出现在腰封内衬或宝石。金属色需说明偏暖金、香槟金、旧金、青铜或冷银，避免笼统“金色”。

### 4. 角色适配，但不画角色

提示词可以写服装适合的身体区域和比例，例如“高腰收束、适配修长躯干”“肩部外扩以增强神性剪影”“护腿按小腿弧度分节贴合”。

不要写脸、眼睛、发型、肤色、表情、手持姿势，也不要让真人、模特或完整角色穿着展示。需要人台时，只允许无头、无手臂、无皮肤细节的中性哑光人台，并且不得遮挡服装结构。

### 5. 保留角色的剪影锚点

换装后观众仍要在远景、逆光和快切里一眼认出是同一个人。角色设计里定下的剪影锚点（标志头型发型、固定头饰、大件耳饰、标志配饰、纹身等），在新造型里继续成立：

- 穿戴类锚点（固定头饰、耳饰、项链、腰牌、护腕、标志配饰等）在新服装中保留，或以相同外形、位置和颜色呼应，写进提示词的头饰与配件部分，措辞与角色设计中的写法一致。
- 身体类锚点（发型、头型、纹身、疤痕等）由身份图保留，服装不得遮挡：新的帽冠、兜帽、高领、面纱不能盖住标志发型或纹身所在部位。
- 新服装的外轮廓与人物性格一致；只有造型变化本身就是剧情上的身份或性格转变时，才可以改变整体剪影，此时仍保留至少一个锚点。
- 角色设计中没有记录剪影锚点时，按可见的标志特征推断一到两个，并在提示词外简短说明这一假设。

## 资产图排版

默认生成一张**完整的服装资产设计图**，使用干净纤细的分隔线，背景为纯白或极浅暖灰无缝背景，均匀棚拍照明，无投影、无环境布景、无文字、无标签、无水印。

### 默认四区布局

- 左侧大区：主体服装正面，使用无头中性人台或平铺悬浮展示；完整呈现领口、肩部、胸腰、下装、裙摆/流苏与正面结构。
- 右上区：主体服装背面或侧后结构；必须展示背部开合、绑带、后腰、后摆和悬挂组件。
- 右中区：头饰、耳饰、颈饰、腰封、臂环或其它核心配件，彼此留白，不重叠遮挡。
- 右下区：左右成对鞋履及腿部组件，以清晰正侧角度展示鞋头、鞋跟、绑带、靴筒或护腿分节。

如果服装复杂，扩展为五区或六区：主体正面、主体背面、头饰、鞋履/护腿、腰部与胸前结构近景、面料与装饰工艺近景。所有区块都只能出现同一套造型的部件。

### 画幅适配

- `1:1`：采用左大右小的四区或六区资产板布局，适合通用换装素材。
- `16:9`：左侧完整主体服装，右侧以两列或三列排列头饰、鞋履、背面和细节件，保证长裙和长流苏完整入镜。
- `9:16`：上部展示主体服装正面与背面，下部展示头饰、腰部配件、鞋履和材质细节；不要为了竖幅裁掉鞋履或衣摆。

除非用户明确需要文字标注，否则画面中不出现文字、尺码、编号、品牌、LOGO、说明箭头或水印。

## 参考图风格转译

当用户提供类似参考图的华丽金色仪式服时，优先提取以下可复用语言，而非照抄：

- 神圣太阳式放射轮廓；
- 镜面古金、香槟金、暖象牙白和珠光材质层级；
- 结构化束身衣与分节护腿形成的硬质骨架；
- 金属花片、放射冠、珠串与长流苏的仪式性装饰；
- 礼服、护甲与舞台装之间的混合关系；
- 成套拆分展示：主体、冠饰、腿甲、鞋履分别清晰可辨。

根据用户的新题材重构这套设计逻辑。例如可变成冰蓝祭司、赛博歌姬、唐风战舞者、深海女王或废土圣骑士；不得要求复制某一张参考图、品牌、艺人舞台服或受版权保护作品的独特造型。

## 风格收束

用户指定风格时，结尾需补充相应媒介控制：

- **高精度 3D 半写实国漫/CG**：写明清晰 PBR 金属度、织物纹理、稳定建模边缘、真实布料厚度、可用于角色换装的资产级细节。
- **二维动漫/韩漫**：写明稳定线稿、色块层级、材质高光位置、服装结构边界清楚，避免真实摄影皮肤和复杂环境。
- **真人写实服装概念图**：写明棚拍级材质真实感、纤维与金属微划痕，但仍保持无脸人台或悬浮服装部件，不出现真人模特。
- **古典、水墨、水彩、版画**：保留服装的轮廓、分件和材质证据，控制笔触与纸张质感，避免抽象到无法复用。

没有指定时，默认使用“高精度 3D 半写实国漫服装资产设定图”。

## 提示词组织顺序

严格按以下顺序写成一段完整提示词：

开头句 → 服装视觉命题 → 适用角色身份与时代 → 总体剪影 → 主体服装分件 → 下装与鞋履 → 头饰和配件 → 色彩系统 → 材质与工艺 → 身份锚点 → 对应画幅的资产图布局 → 背景与照明 → 视觉风格 → 负面约束。

开头句使用：

`基于所附服装参考图与用户描述，生成一张[画幅]角色换装用的服装资产设计图。`

无服装参考图时使用：

`根据用户描述，生成一张[画幅]角色换装用的服装资产设计图。`

## 输出

只输出一条完整中文生图提示词，不解释设计过程，不添加标题、清单、备注或多版本选项。

提示词结尾固定包含：`无人物脸部、无头发、无真人模特、无完整角色、无手持武器、无环境场景、无品牌LOGO、无水印、无说明文字；所有部件属于同一套可复用角色服装，结构完整、比例正确、彼此不遮挡。`
