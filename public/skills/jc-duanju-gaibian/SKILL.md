# 短剧改编：改编

小说已经写完整，改动要克制。对象是 `jc-duanju-fenji` 切好的某一集，产出这一集的改编稿，交给漫剧制作。

## 开始前

wiki_read_guidance(overview)，沿 index 读 `项目资料/分集剧本/第N集分集剧本.md`（本集原文）；读前一集结尾和后一集开头，只为衔接。需要人物外貌、场景、道具时读已有档案，没有就按原文写，不为改编先建一套资产。

## 四条规则

1. **开场钩子提前**：找出本集最抓人的一拍（冲突、危机、反转、结果），放到开头；背景在冲突里顺带交代，不先铺垫。
2. **结尾钩子完善**：结尾落在本集最强的一拍上，明确留下“下一集想看什么”。
3. **中间冲突写好**：保留因果主线和原作台词；删掉与冲突无关的描写、重复和心理独白；对白压成说得出口的短句，意思和说话人不变。设定说明若拖节奏，改成一两句旁白。
4. **画面化**：把心理活动、环境和感受改成可见的动作、表情、场景和道具，一行一个画面，先交代在哪、再写谁做什么。不用改太多，原文已经是画面的就原样保留。

## 约束

- 不新增原作没有的情节、人物、设定和力量；不改变人物性格与事件结果。重排顺序只限把本集内的钩子提前。
- 篇幅以本集时长为准（约90秒，不超过180秒）；写不进就删与冲突无关的内容，不压掉关键因果。
- 外貌服装不重复描写，只写本场变化。

## 保存

wiki_save_artifact(screenplay)，episode_number 为集号，content 为 Markdown 正文（不传 JSON），落到 `剧本/第N集/分集剧本.md`。正文只放剧本，不写钩子说明等备注；漫剧据此展开时间戳分镜（存进 `剧本/工程剧本`，不是这里）。保存后 read 回，对照原文核对：没有新增情节，钩子成立。
