# 招式、动作与攻防脑暴

遵循当前世界规则、人物能力、惯用肢体、持物、伤势、站位和环境状态。招式名只提供用户指定的事件锚点；其特效形态、范围与力量没有依据时是设计候选，不默认等同某部作品或自动出现龙形、爆炸、死亡。

## 两种选择分别展示

1. **呈现选择**：保持已定剧情结果，发散动作组织、观看重点、镜数与节奏。
2. **结果／反馈选择**：结果未定时发散败退、应对反击、主动投降等，并说明对后续剧情的影响。结果已锁定时只在该结果内提供反馈方式；改变胜负明确标为修订提案。

不用两组同时要求用户完整作答。用户已给呈现要求就直接落实，先问真正未定的反馈；用户只给招式时，先展示可读的呈现候选，并简短说明下一步可以选对手反馈。不要先写出一个既成胜负再让用户选择。

“给几个镜头”表示成组展示需求，未指定呈现方向时给两到三个完整镜头组织候选，用户选组后再选未定反馈；无需对起势、抬手、接触等每个执行细节逐项停问。用户明确要求三镜、连续长镜头等组织方式时直接沿用，组内有新的戏剧转折仍可定点展开。用户要逐动作选择时再按攻防变化拆开，不把整组展示误认为确认所有新剧情。

## 示例：亢龙有悔

用户只说“主角使出一招亢龙有悔”时，在已确认项目约束内可给以下候选。镜数是当前设计建议，实际内容仍应写明角色动作、路径、作用点和可见状态；不能把这张结构表直接当作完整台本。

| 呈现候选 | 镜头组织 | 适合的表达 |
| --- | --- | --- |
| A：短促压迫，3 镜 | 1 起势与对手察觉；2 发招、接触或避让；3 对手反馈与主角余势 | 快节奏，迅速读清力量变化 |
| B：蓄势爆发，5 镜 | 1 初始站位与蓄势；2 对手判断；3 发招路径；4 接触或作用；5 结果与余韵 | 有空间和时间读清预期与结果 |
| C：连续交锋，1—2 镜 | 用户选定后才采用连续镜头方案，机位连续展示发起、应对与结果；有切换就另起编号 | 重视双方持续空间与攻防关系，须有充足时长和可执行摄影路径 |

若人物没有远程能量能力，发招通过既定身体／武器动作表现；如果能力已允许远程效果，再提出符合该规则的特效来源、轨迹与作用点。选定呈现后，写出所选镜头的具体候选内容，尚未选定的反馈明确标为待选，不写成已经发生。

结果未定时，对手反馈可提供：

- A 被击败：防御失效，从接触点引出身体位移及失去继续交战条件的可见结果；伤势与力量相称。
- B 反击：使用已确立的应对能力，动作从当前站位与余势发生，具体写出反击威胁；不能临时赋予无依据的新能力。
- C 投降：察觉差距后放弃抵抗，用可见动作或对白成立；不把人物自动改成胆怯，也不凭空让主角接受。

用户可以自由提出挡住但受伤、假投降、主角收招等。若“对手战败但存活”已经锁定，就把选项改为战败后的坚持、交出物件或提出条件；不提供反杀当作等价选择。

## 连续变招与检查

动作链沿用工程剧本：威胁 → 察觉／应对 → 接触／避让 → 身体及环境结果 → 余势。这是整段动作的因果核对，不要求塞进同一镜。连招从前一节拍结束的重心、位置和持物接起；新攻防变化、新观看主体与不同视角另起编号。同一核心动作可包含双方即时静默反馈；用户明确选定连续方案才编排多节拍长镜头，换说话人仍切镜。

坑洞、碎片、武器损伤与人物伤势持续影响后续；环境障碍先建立再使用。已定站位不能为镜头方便瞬移，特效不能遮住关键接触。镜数与时长服务可读性，避免无信息准备和反复归位；用户时长容纳不了选定动作时提出具体冲突，不靠异常速度解决。
