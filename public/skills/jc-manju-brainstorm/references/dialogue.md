# 对白与文戏脑暴

在已知人物关系、说话习惯、认知和场景目标内发散。先判断当前选择是措辞、潜台词、应对策略还是剧情走向；改变类别时明确说明。关系未定的候选不伪装成原有身份。

## 选项内容

每条提供实际台词、少量可见表演、策略与后果。人物目标相同也可以用修复、反问、掩饰等不同策略；策略改变要有当前刺激作为依据。不要只给“温柔／激烈／伤心”标签，不靠擅增出轨、怀孕、死亡或秘密制造差异。

同一原句已锁定时，给不同语气、行动和反馈，台词逐字保留。只改措辞时，信息、承诺、人物认知与剧情结果保持相同。已选台词的潜台词可用于导演设计，但不能凭它断言对方尚未作出的反馈。

## 示例：床上聊孩子

用户只有这幅画面时，先用主技能的轻量选向与资产入口起步。当前题意可提供“是否要孩子／已经有孩子后的照顾责任／经济压力”候选。床上位置不自动证明夫妻、恋人或孩子已经出生。

假设用户已选：当代生活流、两位成年伴侣、尚无孩子、一方想要孩子但担心照顾责任。以下是创作候选，不是用户提供的事实。

当前刺激：“你是不是根本不想要孩子？”

| 选项 | 实际回应与表演 | 策略与下一步 |
| --- | --- | --- |
| A | 对方放下手机，转向说话者：“我想。但我不想让你一个人扛。” | 修复误解，进入责任分配 |
| B | 对方坐起身：“那你问过我怕什么吗？” | 反问争取被理解，进入其顾虑 |
| C | 对方把手机扣在床面，稍停：“我只是觉得……现在还不是时候。” | 延后决定，引出对回避的反应 |

推荐要依人物小传与当前戏剧任务决定；若已有事实说明角色从不反问，B 应改成符合其说话习惯的表达，不让模板覆盖人设。用户选定后生成对应表演与工程镜头，再为接收者的下一节拍提供选项。

## 逐句、整组与混搭

- 逐句时每轮处理当前一句及其对应动作／接收反应；用户已指定那句就原样落笔，给其后回应或表演选择。不能每句重新随机人物策略。
- 整组时各候选都包含连贯的几轮对话，明确它们共同完成哪个状态变化；给组内节拍简短编号供定点替换。展示整组不等于该组被确认。
- “A 开头接 B 结尾”先接好指代、问答、认知与情绪递进，再出合并稿；两个选项有互斥事实时指出具体冲突并给相容替代，不硬拼。
- “先写整场再选”保持未选部分为草稿，按节拍分批提供替换方向；“按推荐写完整场”才允许代选完成指定范围。

## 工程化检查

潜台词转成最少必要的身体或声音变化。工程预览先按 [镜头可见内容方法](../../jc-gongchengjuben/references/shot-visibility.md) 确定主体、取景和物件，再写当前可见动作；脑暴讨论中的全场因果和其他角色反馈不能整段复制进单人正文。单人画面及表演括号不带画外人物名字、代称、所有格或递物来源，原台词逐字保留。对白自然语速、换气和必要动作计入时间预算，换说话人切镜，实际双方接触另用明确可见交互镜头。长句可按自然落点跨镜延续；固定时长不足给容量冲突与调整方向，保留已锁定对白。
