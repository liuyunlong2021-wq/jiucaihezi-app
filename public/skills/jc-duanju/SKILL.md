# 短剧写作 Skill

## 一、任务目标

将用户提供的素材转化为节奏紧凑、冲突明确、情绪强烈、反转有效、结尾有钩子且具备拍摄可执行性的中文短剧内容。

适用输入包括但不限于：

- 人物小传、人物关系、世界背景
- 故事梗概、小说片段、散文片段
- 分集大纲、剧情节点、续写要求
- 聊天记录、灵感片段、设定草稿
- 用户指定的场次、集数、人物或冲突

除非用户明确要求，不读取或联动任何调性文件，不自行引入外部项目规范。

---

## 二、创作前：解析素材

先在内部完成素材解析，不把冗长分析直接混入剧本正文。

### 1. 提取确定事实

整理：

- 主角、对手、关键配角及人物关系
- 当前时间、地点和事件状态
- 主线目标与当前阻碍
- 已发生的关键事件
- 用户指定的集数、场数、篇幅和结局
- 不得改动的姓名、身份、关系、道具和情节事实

不得擅自改变用户明确给出的事实。

### 2. 改编第一铁律：大情节保真与跨集因果闭环（小说/连载改编必守）

进行原著小说、连载故事或长篇多集素材改编时，必须严格执行：

- **保留核心事实，不逐段照搬**：保留主线因果、核心设定、人物身份与动机、关键道具用途及关键事件结果，不得为单集爽感凭空改写这些事实。非关键介绍、背景说明、重复事件、过渡过程和支线应合理删减。
- **下集可接性检验**：设计高潮与集尾钩子时，反查已提供的下一集/章起始事实与承接点，确保角色身体状态、认知、证据和处境可以接续。未提供后文时，只核验已知事实并注明“后文未提供，待核验”，不得声称已完成原著后续核验。
- **允许合并场景与压缩过程**：将功能相近的非关键场景、重复对抗和必要信息合并到同一现场，保留事件因果顺序。地点本身涉及证据来源、人物可达性或关键结果时，不得强行搬移；不能合理合并的独立事件拆到不同集，不得在一集中塞入多场戏。若用户锁定的集数或场次使约束无法同时满足，先指出冲突并询问，不擅自破坏事实或放宽硬指标。

### 改编处理：删减、背景入戏、场景集中

- 先提取推动主线的事件链，再按中心冲突重组分集，不按小说段落或章节机械拆分。
- 介绍、身世、历史和世界规则只作为内部创作依据。正文绝不直接叙述背景，也不通过旁白、OS、字幕或片头介绍绕过此限制。
- 当前冲突必须用到的信息，嵌入质问、威胁、交易、称呼、证据展示和人物选择；暂不影响行动的信息延后或删除。台词必须有对抗目的，不能让角色为观众背诵设定。
- 优先把分散地点的同一矛盾收拢到一个现场，由角色进场、现场道具或收到的消息推动升级；远端信息只呈现本场角色的接收与反应，不切到远端画面。
- 不得删掉反击依据、关键动机、证据铺垫或必要因果。删减后检查观众能否从现场行为理解关系与利害。

### 3. 识别创作任务

判断用户要的是：

- 单场戏
- 单集剧本
- 多集剧本
- 分集大纲
- 素材改写
- 素材扩写
- 素材续写
- 剧本润色或质量修订

如果用户没有说明范围，优先根据素材体量提出一个最小必要澄清问题；若任务可以安全完成，则先完成可交付部分，并明确范围。

### 4. 处理信息缺口

关键事实缺失且会影响因果、人物动机或结局时，先询问用户。

可以合理补充的小细节包括：

- 场景中的普通道具
- 不影响主线的过渡信息
- 可拍摄的动作和表情
- 不改变人物身份与关系的对白连接

不得擅自补充会改变主线的重大秘密、身份、死亡、感情关系或最终结局。

## 三、内部设计：中心事件与短视频工业节奏

### 1. 短视频承制方量化指标

短视频单集目标时长为 1–2 分钟，必须满足以下硬性指标。教程中的一集多场景及更宽松字数建议不适用，以用户指定的九项标准为准；新写、改编、续写、润色与分集设计均执行：

- **每集仅一场戏**：有且只有一场，统一地点、连续时间、一个中心事件。换地点、时间跳跃、闪回、梦境、平行剪辑或远端通话画面均算另起一场，禁止用不加场次标题的方式藏第二场；本场内的动作、景别切换和人物进出不算新场。
- **台词字数硬上限**：整集对白不得超过 **400 字**；为防止绕过上限，所有发声文本（对白、OS、电话声、广播、录音等）合计也不得超过 **400 字**，推荐 260–380 字。不得以加快语速换取超量信息。
- **0–3 秒黄金开篇与强爽点**：第一动作或第一句台词直接上当众受辱、身份曝光、突发险境、当众打脸等冲突名场面；至少有一个视觉锤或具有明确利害、反差、挑衅的强台词。视觉锤应一眼可读且改变局势，不是单纯大场面。严禁空镜、慢铺垫、打车、走路、寒暄和闲聊；不得等背景交代完才进入冲突。
- **20–30 秒波段起伏**：围绕同一中心事件，遵循“受压→反击→新压力”的循环，每 20–30 秒提供一个小转折或爽点。转折必须改变筹码、主动权、认知或风险，换一种辱骂、重复质问和无依据的突然救场不算转折；单集必须有可见反击或局部兑现，不能只有持续受辱。
- **集尾卡高潮（强制追更）**：每集结尾停在危机顶点、秘密揭晓前或冲突爆发瞬间，不平淡收场。
- **极致精简画面**：删除走路、等待、上下车、重复对话、重复反应和无效转场。每个动作必须改变局势、暴露关键信息或推进冲突；必要移动直接从抵达后的冲突开始，必要等待改成正在发生的限时对抗。

字数统计口径：只提取实际发声内容，不计角色名、OS等标签、表演括注、场景栏和动作行；中文、数字、字母及标点各计一字，空白不计。按最终版本逐集重算，不能以估算数字冒充统计。时长依据台词自然语速和必要动作估算，不靠停顿或空镜凑足。

写前先定开头和集尾，再填中间：内部按“0–3秒强冲突 → 每20–30秒局势变化 → 60–120秒内高潮卡断”安排节拍。时间是估算，不是实拍保证；正文不必堆砌镜头编号或时间标签。

### 2. 每场戏只设一个中心事件

写作前，内部用一句话确定：

> 谁，在什么压力下，被什么催化事件逼到什么选择，结果造成什么新变化。

一场戏只能有一个中心事件。所有台词、动作、冲突和道具都必须服务于它。不要在正文展示这句分析。

### 3. 冲突设计

冲突可以来自：

- 角色对角色
- 角色对环境、阶层、财富或身份压迫
- 角色对自身缺陷、价值观或选择困境

冲突强度取决于：

> 施力点的狠度 × 受力点的反馈强度

反派、环境、误会、时间限制、身份压迫或亲密关系背叛负责施力；主角必须出现明确的损失、羞辱、危险、愤怒、沉默或反击冲动。

### 4. 催化事件与危机感

好的催化事件至少满足以下两项：

- 触碰角色红线
- 制造两难选择
- 放大已有误会
- 引爆隐藏矛盾
- 打破安全状态
- 迫使角色立刻行动
- 让观众期待反击
- 解决一个问题，同时制造下一个问题

冲突场景至少加入以下一种危机感：

- **信息差**：观众与角色掌握的信息不一致
- **时间锁**：必须在限定时间内解决
- **生死局**：赌上性命、全部身家或最重要的人

## 四、人物、反派与反转

### 1. 人物行为

人物必须通过可见的动作、表情、沉默、台词和选择表现状态，不用冗长旁白解释心理。

主角不能一帆风顺。应先被压制，再通过有代价、有依据的行动逆袭。

反派必须主动出击，不能只是坐等主角行动。主角刚获得喘息，反派应能发起新的攻势。反派不能弱智，主角的胜利必须有价值、有铺垫、有代价。

### 2. 反转

反转必须：

- 打破已经建立的预期
- 出人意料但符合前文因果
- 改变人物处境或事件方向
- 不一次性泄露全部秘密

可以使用：
- 身份反转
- 认知反转
- 证据反转
- 关系反转
- 立场反转
- 物品或能力反转
- 背后还有更大对手的层级反转

### 3. 信息释放

遵循“鸟食原则”：

- 不一次倒完所有信息
- 一个秘密尽量拆成 2—3 次释放
- 最重要的信息尽量留到场尾或集尾
- 让每次信息释放都改变观众对局势的判断

## 五、台词、内心独白（OS）与画面表达

### 1. 台词要求

每条台词至少承担一种功能：
- 塑造人物
- 推动剧情
- 加强情绪
- 交代必要信息
- 递进人物关系

没有功能的台词直接删除。

台词应当：
- **短**：通常每句不超过 15 个汉字
- **爆**：直接、有攻击性、有情绪冲击
- **贴**：符合人物身份和当前压迫状态
- **准**：每句只传递一个主要信息
- **围**：围绕当前冲突，不闲聊、不跑题

能用动作表达，不用解释性台词。一名角色连续说超过 3 句时，应插入打断、动作、沉默或对方反击。

### 2. 内心独白（OS）与身份认知规范（针对穿越/重生/金手指短剧）

- **简短有力**：单条 OS 严禁大段抒情，长度通常控制在 **1~2 句（不超过 25 个字）**。
- **不承担背景介绍**：穿越、重生与身份反差优先通过异常称呼、行为选择、试探台词或现场证据自然显露。OS 仅用于当下判断或反击意图，不准讲身世、复述前史或解释世界设定；不能为了使用 OS 增加闪回场景。
- **心行合一，不破因果**：OS 表达主角的心智觉醒，但**外在物理行动必须严格服从身体机能与原著大情节**（如重伤虚弱时，内心震惊但身体依然保持暗中观察或装晕，绝不能超前做出破坏下一集大情节的突兀动作）。

### 3. 禁止的不可拍表达

不要直接使用以下心理或抽象叙述：发现自己、意识到、心想、觉得、明白了、知道了、想起、穿成了、穿书了、内心、脑海中、记忆中。

将其转化为可拍内容：
- 眼神、表情、停顿、呼吸变化
- 具体动作和身体反应
- 可听见的台词或明确标记的内心独白（OS）
- 道具变化、环境变化

动作行只写演员可执行、观众可见的行为及必要道具状态，通常一行一个有效动作。不写文学化环境、履历介绍、抽象心理和冗长细节，也不把删掉的台词改成长篇动作叙述。必要的时间、地点、内外景标记保留；“不描述背景”不等于删除拍摄所需的动作说明。

## 六、钩子设计

每集末尾必须留钩子。可使用：

1. **悬念钩子**：事件即将揭晓却在关键处中断
2. **断章钩子**：高潮进行到一半突然切断
3. **出场钩子**：关键人物在最危险时刻出现
4. **情绪/认知钩子**：现场证据或一句关键台词改变认知，角色在后果即将爆发时作出强反应；单独的震惊表情或眼神定格不构成有效钩子

结尾不能只是情节自然结束，必须让观众产生继续观看的理由。

内部明确“下一集观众要追问什么”。先兑现本集一个局部爽点，再在更大的危机或答案前卡断；不反复拖延同一个答案。钩子必须由本场因果产生，新人物也必须进入本场，不能靠切换地点制造悬念。卡断后不追加旁白总结、背景补充或平静收尾。

## 七、标准输出格式

每集剧本交付时，必须包含以下规范结构。人物简表只在首次交付或人物状态发生必要变化时给出，限本场所需身份、关系与状态，不擅自编造年龄和外貌，不代替正文中的自然展示。每集只出现一次场次标题：

```markdown
# 《剧名》

### 第N集：[核心事件与冲突提炼]

**人物：**
- **主角**：本场所需身份、关系与状态。
- **主要对手/配角**：本场关系、动机与功能。

---

**第1场（本集唯一场）**  
**场景**：地点  
**时间**：日/夜/清晨  
**环境**：内/外  
**人物**：登场角色  

△ [开场3秒动作与冲突]
...

**【本集完】**

---

### 【工业指标与大情节衔接核验】
1. **场次与时长**：1场；预计 XX 秒（目标60–120秒）。
2. **台词字数统计**：对白 XXX 字；全部发声文本 XXX 字（均 ≤ 400 字，按本 Skill 口径实数统计）。
3. **开篇与节拍**：指出首3秒的视觉锤/强台词；简列各20–30秒节点的局势变化及本集反击爽点。
4. **集尾钩子**：指出卡断动作/台词与下一集待解问题。
5. **下集大情节接续说明**：核验已提供后文的因果承接；未提供则注明待核验，不编造后文。
```

分集大纲以事件罗列，不写背景散文。每集列“唯一场景｜中心事件｜3秒开篇｜受压与反击的节拍｜高潮卡点｜下集承接”，不得在同一集列多个地点。仅交付大纲时不虚报台词字数；实际写正文后逐集统计。

## 八、交付前逐集验收

以下九项逐集检查，任一不合格先修订，再交付；不靠核验文字宣称合格：

1. **合理删减、背景入戏**：无介绍段、背景旁白、设定OS和借人物之口背设定；保留必要因果，信息从现场对抗中自然显露。
2. **强开头**：首个动作或台词有明确视觉锤或吸引力，主角利害立刻可辨。
3. **场景与矛盾集中**：分散的同类对抗已合理合并，无无关支线和为转场而转场。
4. **仅一场戏**：恰好一个场次标题，并检查正文没有藏入地点切换、时间跳跃、闪回或平行场景。
5. **不超过400字**：按最终文本核算对白和全部发声文本，两项均不超限；超限先删冗余，不删关键因果。
6. **黄金3秒**：冲突、危机或名场面已发生，不是预告将发生；无空镜、慢铺垫和闲聊。
7. **高密度短频反转**：自然演出约1–2分钟，每20–30秒有实际局势变化，受压后有反击，不以重复羞辱充数。
8. **集尾卡高潮**：在危机顶点、秘密揭晓前或冲突爆发瞬间卡断，有具体待解问题且后文能接。
9. **精简画面**：无走路、等待、重复对白和无效动作，无文学化长描写或填充时长的画面。
