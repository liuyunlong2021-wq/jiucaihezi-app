# 短剧改编方案

本流程只做改编。理解用户本轮基本思路，读取wiki_read_guidance(overview)，沿真实index定位`项目资料/原作/故事梗概.md`及本次涉及的人物小传、背景/规则、场景/道具和必要原文章节。旧库沿实际索引查找，原作、改编版、用户新要求分别辨清；刚生成的聊天或index摘要不能代替read正文，同版本本轮已读可复用，修改后重读。

已有明确改编思路就直接完善，不再强迫选六类方向，也不先设计另一套故事。只有影响人物身份、因果或边界的关键缺项合并询问；用户委托的范围内直接工作。

## 一份可执行的方案

保存到`改编方案/项目总纲.md`，包括：

- 原作、真实来源与本次章范围；核心吸引力以及要保留的冲突、关系和情绪。
- 用户基本思路；原人物→新人物的姓名、身份、关系、称呼与认知对应；背景、能力规则、场景道具的必要等价替换。
- 原文明示的五官、身材、服装和标志特征如何沿用；用户明确的造型变化单列。未给出的设计可按授权补在改编版并注明设计来源，不冒充原作事实。
- 允许改变与必须保留的内容。可以在每集切分内扩写/缩写表达，但不新增原作没有的事件、能力、胜负、关系或信息；方案不授权挪用相邻集/章的大段内容。用户要求实质改动与此冲突时指出具体冲突，不偷偷执行。
- 集长：**每集不超过3分钟**，下限不限，用户或项目另有规格的以用户为准。超时在章内再拆集，不为时长删关键因果、补对白或改变语速。
- 剧本定位：供漫剧制作直接使用的小说化电影剧本，写清角色、场景、道具；原作没写的外形由逐集改编按设计Skill创作并补进改编版资料，方案只记录用户已明确的整体造型或风格要求。
- 对后续逐章切分和落稿的约束、未决项与实际确认状态。

只有确实变化的人物/背景/规则/场景道具才保存改编版资料，`research_version=adapted`；未变化字段关联原作，不复制全套事实。人物关系、当时认知、力量边界和动机必须能承接章内实际事件。

## 归档与交接

完整方案调用wiki_save_artifact(project_overview)。改已有方案先read完整原文，保留无关内容，更新同一路径；新增改编版资料沿工具类型存到`项目资料/改编版/`。方案保存不等于用户确认，用户明确不保存时遵守。修改方案先列受影响的章、切分和已有集稿，按授权更新，不能自动覆盖全部旧稿。

方案交给[jc-duanju-fenji](../jc-duanju-fenji/SKILL.md)逐章规划。普通模式明确请求独立原创策划时保留[既有独立写作说明](references/独立写作旧规则.md)，本改编流程不加载该资源。
