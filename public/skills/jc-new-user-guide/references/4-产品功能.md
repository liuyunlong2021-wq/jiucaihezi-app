# 韭菜盒子 Studio · 页面介绍

> 打开韭菜盒子你会看到这些区域。每个都能干啥，往下看。

## Chat（聊天区）

页面正中间最大的区域。你跟 AI 说话的地方。

**能干啥**：
- 打字问问题，AI 回答
- 粘贴一大段内容（小说、剧本、代码），让 AI 帮你处理
- @ 引用项目里的文件，让 AI 基于文件回答
- 表达目标（比如“填充 Wiki”），启动 AI 的对应能力
- 桌面端：所有对话走 OpenCode Agent，AI 能直接改你的文件

## Rail（左侧导航栏）

页面最左边那一竖条图标。

**能干啥**：
- 切换工作区：创作面板 / 对话 / 历史记录 / 用户中心
- 手机端精简到 3 个按钮

## 项目

页面左上角，显示当前项目名。

**能干啥**：
- 切换项目：换个文件夹干活
- 一个项目 = 一个文件夹，所有文件、对话、Wiki 都在里面
- 桌面端直接操作本地文件夹，Web 端在浏览器里管理

## 会话

Chat 区域上方的历史对话列表。

**能干啥**：
- 查看之前跟 AI 聊过的对话
- 切换回某个旧对话继续聊
- 删除不需要的对话

## 编辑区

代码和文件的查看/编辑面板。

**能干啥**：
- 打开项目里的文件看内容
- 编辑 Markdown、代码、配置文件
- 语法高亮（不同语言显示不同颜色，方便阅读）
- Markdown 预览

## 创作面板

用于一键生成图片、视频、音频和 3D 模型。具体可用模型取决于当前端和账号配置。

**能干啥**：
- 选一个模型（图片/视频/语音）
- 填一段提示词描述你想要什么
- 提交后 AI 生成媒体文件
- 生成的媒体存在项目的 `jc-media/` 文件夹里
- 支持的模型：GPT Image、Banana、Seedance、Veo、LTX、Qwen TTS

## 记忆工作台的本地基础工具

记忆模式里还有和 `read`、`write` 同级的基础工具，不需要安装 Skill，也不会弹 AI 媒体确认卡：

- **导出图片**：把已有 Markdown/文字排版成 PNG；它不是生图。
- **导出文档**：把文字保存为 DOCX、Markdown 或 TXT。
- **导出网页**：把完整 HTML 保存为单文件网页，浏览器可以直接打开。
- **创建 3D 白膜**：用自然语言搭建可旋转的空间草模，摆放人物、墙、门、地面、桌椅、车辆和建筑，调整机位后可截图。它是构图参考，不是写实 3D 生图。

直接说：

```
把刚才的内容导出成一张图片
把这段内容做成 Word 文档
把这份 Markdown 做成一个可以打开的网页
创建一个宫殿白膜，皇帝在中间，两列大臣面向大门
```

3D 白膜保存为 `.jcscene`，截图保存为项目图片；打开场景时才加载 3D 查看器，普通聊天不会因此变重。

## 审查变更

AI（OpenCode Agent）改完你的文件后，所有改动在这里显示。

**能干啥**：
- 绿底 = AI 加的内容
- 红底 = AI 删的内容
- 逐条看，对的点**接受**，不对的点**拒绝**
- 拒绝后文件恢复原样

## Skill 仓库

管理所有 Skill 的地方。

**能干啥**：
- 看已经装了哪些 Skill
- 从 GitHub 安装新的 Skill
- 从本地文件夹安装 Skill
- 禁用暂时不想用的 Skill
- 更新 Skill 到最新版本

> 内置 Skill 来自产品资源；你从 GitHub 或本地安装的 Skill 也会进入同一个仓库。名称冲突时内置 Skill 优先，本机独有 Skill 仍可正常使用。

## 工具仓库

管理外部工具和 MCP 集成。

**能干啥**：
- 安装 MCP 工具（让 AI 连接外部服务）
- 管理 API 密钥
- 配置媒体生成后端

MCP 连接成功后，会和产品自带工具一起成为模型可选工具；模型按任务需要调用，不是每次请求都把所有工具塞进去。

## 设置

**能干啥**：
- 填 API Key（各模型平台的通行证）
- 选默认模型（平时用哪个 AI）
- 切换文/武模式（文=省钱本地模型，武=强模型）
- 改语言（中文/English）
- 账号：手动 Key → Keychain → 账号登录 → Worker 代理
- 存储位置：`~/.jiucaihezi/data/`（数据库）+ `~/.jiucaihezi/output/`（媒体文件）

## 常见问题

### 桌面端和 Web 端有什么区别？
两端都能聊天、管理项目、使用记忆工作台和已支持的媒体/本地基础工具；桌面端额外提供本机文件能力和本地 MCP，Web 端不能执行本地 `stdio` 工具。模型和具体媒体能力仍以当前端显示的列表为准。

### 我想用的功能找不到？
如果找不到某个模型或入口，先确认当前端、账号和模型服务是否已配置；不同端不会承诺完全相同的模型列表。
