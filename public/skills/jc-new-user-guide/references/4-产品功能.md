# 韭菜盒子记忆工作台产品功能

## 产品核心

韭菜盒子用“用户信息 + 模型 + 插件”完成对话；项目中的长期资料、索引和文档全部是普通文件。

## 对话与模式

- **统一工作台模式**：每次发送自动保留当前对话最近最多三个完整问答轮次；项目文件、附件、文档转换和媒体等能力仍需按当前平台与用户选择提供。
- 新建对话不会自动读取其他对话；每个对话都有自己对应的 Markdown 记录。
- 用户选中的具体 Skill 会在当前对话继续生效，直到移除或新建对话；新建对话不继承上一对话的 Skill。
- 在“我的 Skill”点击“修改”会自动选择 Skill Creator，按 Skill ID 读取中央 Skill 根目录中的真实 `SKILL.md`；用户点击安装卡后覆盖原 Skill。

### 记忆与查询

- 右上角“记忆”：默认开启。成功回答写入 Raw 后，自动生成 `summary + keywords` 并记录到当前对话的 `.raw/记忆索引`；关闭只停止后续自动记录，不删除已有内容。
- 右上角“查询”：默认开启。下一轮发送前自动调用一次原生 `memory_search`，只查询当前对话索引；关闭后不查询历史索引，但最近三轮仍保留。
- 两个开关独立，状态属于当前对话；重开同一对话恢复原状态，新建对话默认同时开启。发送途中切换从下一轮生效。
- `.raw/记忆索引` 不是 Wiki。需要把内容沉淀为项目长期知识时，用“保存到文件”选择 `wiki/` 中的 Markdown 文件。

## 项目与文件

- 项目负责隔离不同工作的文件和对话；索引文件由 Skill 按规则维护。
- 文件支持查询、读取、写入、修正、巡检、一致性检查和关系图等操作；选择 `@Wiki` 时按索引递进读取，`wiki-memory` 负责 Wiki 的组织、查询、写入和检查。
- 标准 `.canvas` 用于项目关系图；`.jccanvas` 用于图片、箭头、文字、编号和画笔等 2D 创作。
- 登录同一账号后可以按项目中心的方向按钮覆盖同步允许的文字资料；图片、音频、视频、原始附件和 `.raw/.sync` 不同步。

## 附件与媒体

- 支持上传图片和文档；支持的 Office / PDF 可以转为可读文本并继续对话。
- DOCX、PDF、XLSX、PPTX 会保留原件，并生成 Markdown 可读副本发送给模型；Markdown 不替代原件。
- 云端图片、视频和音频生成通过创作面板执行，结果保存在当前项目。
- 关闭创作面板后，已提交的媒体任务继续运行；再次打开可以查看状态。

## 平台边界

| 能力 | Desktop | Web / Mobile |
| --- | --- | --- |
| 项目、对话、普通文件与索引 | 支持 | 支持 |
| 项目内读写、附件、文档转换 | 支持 | 支持 |
| 云媒体、`.canvas`、`.jccanvas` | 支持 | 支持 |
| Three.js `.jcscene`、本机 FFmpeg | 支持 | 不提供 |
| Terminal、本地模型、自定义 MCP | 支持 | 不提供 |
| 自定义 Skill / MCP 管理 | 支持 | 不提供 |

## Desktop 专属本机能力

- 用 Three.js `.jcscene` 搭建、调整和截图 3D 白膜场景。
- 用本机 FFmpeg 把确定性 3D 动画导出为 MP4。
- 使用 Terminal、本地模型和本地 `stdio MCP`。

## 版本与发布

- Desktop 的 macOS Apple Silicon、macOS Intel、Windows x64 由 GitHub Actions 的 `v*` tag 自动构建；推送 `main` 本身不会生成安装包。
- 发布时先提交并创建版本 tag，再分别执行 `git push origin main` 和 `git push origin vX.Y.Z`。不要直接推送不存在的 tag，也不要使用 `git push --tags`。
- iOS / Android 是否可安装、Web 是否为最新版本，以正式发布页和当前应用状态为准；桌面三平台发布不等于移动端商店上架。

## 常见问题

### 为什么 Web / Mobile 功能少一些？

它们保留项目、对话、普通文件、附件和云媒体这些核心能力，去掉依赖本机运行时或持续占用设备图形资源的功能。

### 为什么另一台设备看不到项目里的视频？

跨端只同步允许的文字资料，媒体二进制不会上传。媒体仍保存在生成或导入它的设备上。

### 我想用的入口找不到？

先确认当前平台。Three.js、FFmpeg、Terminal、本地模型、自定义 Skill 和 MCP 管理只在 Desktop 提供；模型和云媒体列表以当前界面为准。
