# 产品功能速览

## 从项目开始

韭菜盒子以项目组织对话、创作资料和产物。打开或新建一个项目后，再开始对话。不同作品建议分开放在不同项目里，避免小说、剧本、角色设定和生成媒体混在一起。

项目文件树用于查看项目中的 Markdown、图片、音频、视频和画布。短剧、漫剧与小说路线生成正式文字产物后，会将文件保存到当前项目并返回文件位置。

## 输入框上的 @ 能力

敲 `@` 会弹出本轮可启用的能力：**Wiki Memory、Skill、Office、影音、3D、MCP、会话**，另外可以直接 `@` 项目里的文件。它们只在本轮生效，选中哪个就只拿到那个的能力；其中只有 `@影音` 会扣费，且必须经用户确认才提交。

输入框左下角的「权限」档负责能不能动本机文件与终端（旧称 `@文件`，芯片已下线）。完整说明见 `references/2-输入框的@能力.md`。

## 三条文字创作路线

Desktop 对话输入框下方依次提供三个入口：

- **漫剧制作**：整理漫剧项目资料、确定视觉方向、设计角色/场景/道具，并把已确认文学剧本转成工程台本或模型专用视频提示词。
- **短剧写作**：创作原创短剧，或把小说、故事、剧本改编为短剧；负责改编方向、分集大纲、逐集文学剧本和剧本修订。
- **小说创作**：选择长篇小说路线。按阶段完成创意、核心梗、人物、全书大纲、章纲和正文，逐章推进并等待用户确认。

点击按钮只切换当前对话的创作路线。用户还需要发送本轮目标；路线不会自行生成整部作品，也不会自动提交图片或视频任务。三个路线互斥，切换后可继续使用同一项目 Wiki。短剧文学剧本完成后，切换到“漫剧制作”并要求编写工程台本，即可进入逐镜拍摄设计。

## 创作面板

创作面板是独立的媒体工作区，可按界面当前提供的任务选择图片、视频、音频等类型，再选择相应模型、填写提示词和参数、添加参考素材并提交任务。模型目录与聊天区的文本模型分开。

面板和 `@影音` 用的是同一套媒体模型与参数：面板里选好后点「复制参数」，粘到输入框再接着写提示词，`@影音` 会按面板的选择执行，不用手动敲型号。

创作结果会保存到当前项目，任务状态可在生成历史中查看。模型、价格、参数和可用性以面板当前显示为准。

## 常用设置

右上角齿轮按钮打开“账号与设置”。常见分类包括：

- **账号**：填写模型调用 API Key 即可使用（不需要登录）；Desktop 还可配置本机模型和自定义端点。
- **同步**：按界面指示上传或下载项目文字资料。同步不是媒体备份，具体覆盖方向以操作按钮为准。
- **主题**：切换应用主题。
- **更新**：Desktop 检查和安装应用更新。
- **Skill、MCP、手机、截图**：按当前 Desktop 版本提供相应管理入口；部分分类只在 Desktop 显示。

现在不需要登录：账号页填入模型调用 API Key 并保存就能用。「多端同步」是以后的入口，目前灰色不可点。

## 平台提示

小说和漫剧路线按钮当前属于 Desktop 工作台功能。Web、Mobile 的能力和发布状态不同；不要根据 Desktop 的界面推断其他平台也有相同入口。跨平台可用性以正式版本和当前界面为准。
