# 创作面板与常用设置

## 打开创作面板

先打开一个项目并进入对话，然后点击工作台右上方调色板图标（提示为“创作面板”）。面板与聊天区分开：聊天区选择文字模型，面板选择图片、视频、音频等生成任务的模型。

## 提交图片或视频任务

1. 在面板底部选择“任务”，再选择任务对应的模型。
2. 写清楚主体、动作、场景、风格和希望的结果。视频提示词还要交代动作过程、镜头或时长要求。
3. 需要参考素材时，点击提示词左侧的附件按钮选择素材；也可以从当前项目的画布或媒体文件中选取。
4. 按当前模型显示的选项设置尺寸、比例、时长或其他参数。不是每个模型都有相同参数。
5. 点击生成。生成历史可以查看任务状态、错误和结果。

成功的媒体结果会保存到当前项目。生成历史可查看状态、预览结果；需要放到当前画布时，使用任务卡片里的“放到画布”。保存遇到问题时，按任务卡片提示重试保存或下载。生成中的任务不要重复提交，以免重复扣费。

具体模型、价格、参考素材限制和参数以当前面板为准。文字创作路线不会自动提交生成任务；需要付费生成时由用户明确要求。

## 面板和 @影音 的关系

面板和聊天里的 `@影音` 是同一套媒体能力的两个入口：模型、参数、价格完全同源。

常用做法是在面板里把模型、比例、尺寸、时长挑好，点面板上的**复制参数**按钮，会复制出一行 `[创作参数] …`（含类型、模型、模式、比例、价格）。粘到输入框、在后面接着写提示词，`@影音` 就按这行参数执行；不想用面板的参数就不粘贴，普通对话不受影响。

两边都遵守同一条付费规则：只有用户明确要求生成、并确认了卡片上的模型与价格，才会真正提交任务。

## 画布与参考图

面板顶部可以切换或新建画布、查看生成历史。画布用于摆放、整理和比较媒体素材，也可以把已有项目素材作为后续任务的参考。选中参考素材后，面板会显示当前模型是否支持这些素材类型；模型不支持的素材不会作为有效参考。

## 账号和 API Key

点击右上角齿轮打开“账号与设置”，进入“账号”。

**现在填 API Key 就能用，不需要登录。** 账号页上的「多端同步」是以后多端同步功能的入口，目前标着「即将开放」、灰色点不动，看到它属于正常。

- 在「模型调用 Key」里粘贴你自己的 API Key，点「保存设置」即可开始使用。
- 密钥可以自己创建和管理：点「管理密钥」会打开网页版控制台。
- 只有 Key、还没选模型时，模型列表可能为空，先确认 Key 已保存。
- 手机端账号页仍是旧的登录形态（功能冻结、不再更新），以桌面端为准。
- Desktop 可在账号页展开“本机模型与服务”，连接 Ollama 或配置兼容端点。文本模型选择器在工作台顶部；创作模型在创作面板中选择。

密钥是账号凭据，不要粘贴到公开对话、截图或项目资料中。

## 其他设置

设置抽屉中的分类随平台版本有所不同。Desktop 当前提供的常见入口包括：

- **更新**：检查应用更新。
- **同步**：执行界面列出的项目文字资料上传或下载操作。先确认操作方向和覆盖提示。
- **主题**：调整应用外观。
- **Skill / MCP**：管理当前桌面工作台可用的扩展能力。
- **手机 / 截图**：按当前版本管理手机控制器或桌面截图。
- **账号**：云端登录、API 配置、本机模型与服务。

模型选择有三个位置：顶部聊天模型选择器、创作面板里的媒体模型选择器、设置中的本机模型配置。它们各自用于不同任务，不要把一个位置的模型选择当成其他位置也已配置。
