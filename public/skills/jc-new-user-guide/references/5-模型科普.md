# 模型科普

> 模型目录、可用能力和价格都会变化。以当前界面、Gateway 返回的模型列表和官方价格页为准；本页不维护固定型号或价格表。

## 三类模型入口

- **聊天模型**：在工作台顶部选择，用于普通对话、小说和漫剧文字创作。
- **媒体模型**：在创作面板里先选任务，再选图片、视频、音频等对应模型，用于实际生成媒体。
- **本机模型**：在 Desktop 的“设置 → 账号 → 本机模型与服务”中配置，连接本机 Ollama 或兼容端点。它不会自动成为创作面板中的媒体模型。

三处目录彼此独立。切换聊天模型不会更改创作面板里的模型；连接本机文本模型也不代表已经配置云端图片或视频生成。

## 选择和排错

- 初次使用时，选择当前界面标记为可用且适合任务的模型。
- 模型名称相似不代表能力、参数、参考素材限制或计费方式相同。
- 若列表为空，先检查账号状态、API Key 配置、网络和当前平台版本。
- 遇到限流、上游失败或模型下线时，以当前错误和渠道状态排查，不把旧文档中的型号当作可用保证。
- 费用、余额、分组和接口配置以当前后台与价格页为准。

## 韭菜盒子 API

韭菜盒子提供兼容 OpenAI / Anthropic 风格接口的 Gateway。能否在第三方客户端使用，取决于客户端支持的协议、模型能力和当前接口状态。

接口地址：

https://api.jiucaihezi.studio

1. 在[密钥页面](https://api.jiucaihezi.studio/keys)生成密钥。
2. 在支持对应协议的 AI 客户端中填写接口地址和密钥。
3. 选择接口当前返回且客户端支持的模型。

查看[模型与价格](https://api.jiucaihezi.studio/pricing)、[使用日志](https://api.jiucaihezi.studio/usage-logs/common)或[充值页面](https://api.jiucaihezi.studio/wallet)时，以页面当前信息为准。接口路径和计费规则可能变化，不照搬其他客户端的配置。密钥不要分享或写入项目文件、对话截图或同步资料。
