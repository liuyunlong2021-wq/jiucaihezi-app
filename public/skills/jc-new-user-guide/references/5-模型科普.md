# 模型科普

> 模型目录、可用能力和价格都是动态信息。以当前界面、Gateway 返回的模型列表和官方价格页为准，本页不维护固定型号或价格表。

## 一、聊天模型

聊天区顶部的模型选择器从韭菜盒子 Gateway 加载当前可用的文本模型。列表可能因账号、Provider、上游状态和版本变化；未登录或 Gateway 暂时不可用时，界面可能只显示本地缓存或本地模型。

选择模型时，优先看当前界面标出的能力和可用状态，不要根据模型名称推断一定支持附件、工具或长上下文。快速模式只提供当前对话上下文和只读 Wiki 查询；记忆模式才按平台提供项目文件、附件和工具。

## 二、创作模型

创作面板的图片、视频、音频和 3D 模型目录与聊天模型分开维护。可用模型、参数、失败状态和价格以创作面板当前显示为准；某个模型下线、限流或被 Provider 拒绝时，不能把旧文档中的型号当作保证。

Desktop 还提供本地 3D 白膜、Three.js 场景和 FFmpeg 导出；Web / Mobile 不提供这些本机能力。

## 三、快速模式与记忆模式

- **快速模式**：使用当前对话上下文和模型已有知识，只能按需查询 Wiki。
- **记忆模式**：使用同一对话上下文，并按当前平台提供候选工具。

第一次使用直接选择当前界面推荐且显示为可用的模型即可。不要把本页当作价格、模型清单或默认模型公告。

## 四、韭菜盒子 API

韭菜盒子也提供兼容 OpenAI / Anthropic 风格接口的 Gateway。能否在某个第三方客户端使用，取决于该客户端支持的协议、模型能力和当前接口状态。

### 接口地址

```
https://api.jiucaihezi.studio
```

### 基本步骤

1. 在 [密钥页面](https://api.jiucaihezi.studio/keys) 生成密钥。
2. 在支持对应协议的 AI 客户端中填写接口地址和密钥。
3. 选择当前接口返回且客户端支持的模型。

客户端可能要求 `/v1`、Anthropic 专用路径或其他协议配置，以该客户端和官方接口说明为准，不要照搬另一种客户端的配置。

### 分组、价格与账单

- 新手先按当前后台提示选择自动分组。
- 需要比较模型和分组时，查看当前[模型与价格页](https://api.jiucaihezi.studio/pricing)。
- 计费规则、倍率、余额和模型价格以当前后台为准，不在新手指南中固定金额或换算公式。
- 花费记录：[usage logs](https://api.jiucaihezi.studio/usage-logs/common)
- 充值：[wallet](https://api.jiucaihezi.studio/wallet)

密钥等同于账户凭据，不要分享或写入项目 Wiki、Raw、同步文件或截图。

## 常见问题

### 不知道选哪个？

优先选择当前界面标记为可用、适合当前任务的模型。模型和价格会变动，不承诺某个固定型号“都不出错”。

### API 和 App 里的模型一样吗？

聊天区主要使用 Gateway 的文本模型；创作面板使用独立的媒体模型目录，Desktop 还可能有本地模型。三者不能简单视为同一份列表。
