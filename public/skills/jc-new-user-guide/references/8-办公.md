# 办公：附件阅读与文档输出

> 记忆工作台的重点是读懂资料、保留原件和输出常用文档，不是通用格式转换器或 GitHub 项目运行环境。

## 记忆工作台里的文档读取

上传 DOCX、PDF、XLSX、PPTX 或 EPUB 后，韭菜盒子会保留原件，并生成 Markdown 可读副本发送给模型。Markdown 是模型读取表示，不是对原文件的替换；原文件仍可下载、预览或再次处理。图片、视频、音频继续按媒体附件处理。

因此，“让模型读懂文件”和“把文件转换成另一种格式”是两件事：前者是记忆工作台的附件能力，后者只覆盖下面列出的内置出口。其他转换需要外部工具，并受平台和用户审批限制。

## 一、内置文档输出（`@Office`）

把 `@Office` 选上，或直接说「导出成 XXX」，不用安装额外 Skill。所有出口都在这个芯片下：

| 目标 | 直接说 |
|------|--------|
| Word | `把这段内容导出成 Word` |
| 表格（CSV） | `把这份名单导出成表格` |
| Markdown | `把刚才的内容保存成 Markdown 文件` |
| TXT | `把这段内容保存成 TXT` |
| 单文件网页 | `把这份 Markdown 做成一个可以打开的网页` |
| PNG 长图 | `把刚才的内容导出成一张图片` |

表格走 **CSV**：Excel、WPS、Numbers 双击就能打开，中文不会乱码。产品目前不生成 `.xlsx`，需要 Excel 原生公式或图表的，导出 CSV 后在表格软件里另存即可。

这组工具负责已有内容的排版和保存，不负责任意格式互转，也不承诺 PDF、Word 的复杂版式完全还原。

## 二、Markdown 幻灯片（同样在 `@Office` 下）

统一工作台可以把用 `---` 分隔的 Markdown 幻灯片导出为 HTML、PDF 或可编辑的 `.pptx`：

```
请把这份 Markdown 幻灯片导出为 PPTX：
# 首页
内容……
---
# 结论
内容……
```

这不是 Slidev 或 PowerPoint 全功能编辑器，也不会自动还原任意原始 PPT 的复杂版式。

## 三、平台边界

- Web / Mobile：使用内置附件读取、文档转换和项目内文档输出。
- Desktop：把输入框左下角「权限」档切到完全权限后，可用本机 Terminal 和已安装工具处理额外格式；命令失败、依赖缺失或权限不足时必须如实提示。`@文件` 芯片已经下线，本机操作只看权限档。
- 不要把“模型能分析文件”表述成“App 已支持该文件格式的完整转换”。

## 常见问题

### 能不能把任意 PDF、Excel 或 Word 互相转换？

不能把它当作内置保证。先确认当前界面提供的出口；需要额外格式时，必须使用平台可用且经过用户批准的外部工具。

### 处理速度怎么样？

取决于文件大小、内容复杂度、转换服务和当前平台；大文件或扫描 PDF 可能需要更久，不能承诺固定秒数。

### PPT 能导出 PowerPoint 格式吗？

Markdown 幻灯片可以导出 `.pptx`；导出的内容以当前内置模板为准，复杂版式需要在 PowerPoint/WPS 中继续调整。
