# 漫剧创作入门

漫剧路线适合把已有故事、短剧文学剧本或项目资料整理成可制作的漫剧资料。原创短剧写作与小说改编方向由独立的“短剧写作”路线负责；漫剧制作可从已经确认的剧本继续。它按用户本轮目标完成一个具体产物，不会自动跑完所有制作环节。

## 开始

1. 在 Desktop 打开或新建一个项目，把已有小说、剧本、人物资料或参考图放进项目；没有材料时，一句话描述故事也可以。
2. 如果还没有短剧文学剧本，先点击“短剧写作”确定改编方向并完成剧本；已有剧本则直接继续。
3. 打开或新建一个对话，点击输入框下方的“漫剧制作”。
4. 发送你当前要做的事，并说明现有材料在哪里、希望得到什么产物。

例如：

- “我有一部长篇小说，先整理故事梗概、分集梗概和主要人物小传。”
- “这是已经确认的剧本，请先帮我确定视觉方向和场景基调。”
- “先设计主角的形象提示词，保持和人物小传一致。”
- “根据这份已确认的短剧剧本写工程台本，逐镜安排表演和空间连续。”
- “把已确认的工程台本转成 MiniMax H3 视频提示词。”

不必记住 Skill 名称。说清楚目标产物，系统会按当前漫剧创作规则选择相应方法。若目标模型很重要，请明确写 MiniMax H3 或 Seedance 2.5。

## 推荐的制作顺序

以下顺序用于规划工作，不是强制流水线。已有材料可以直接复用；每次只做当前需要的一步。

1. **整理故事资料**：从小说、完整剧本或故事素材提炼故事梗概、分集梗概、人物小传、背景和世界规则。
2. **准备文学剧本**：原创短剧、小说改编方向和逐集文学剧本在“短剧写作”路线完成；漫剧路线接收已确认剧本。
3. **确定制作方向**：确认媒介、画幅、视觉风格、色彩、表演和空间方向。
4. **准备视觉资产**：按需要设计角色、场景和道具；可以先写提示词，再到创作面板生成参考图。
5. **编写工程台本**：安排逐镜表演、动作、机位、空间连续、声音和节奏。
6. **输出视频提示词**：根据用户指定的目标模型，将确认的剧本/工程台本转成对应提示词。
7. **生成媒体**：需要真正生成图片或视频时，打开创作面板，选模型并明确提交。写出提示词不等于已经生成媒体。

## 项目资料和修改

完成正式文字产物后，系统会将其归档到当前项目，并在回复中给出实际文件位置。可以在项目文件树中打开和修改。已有剧本、人物设定和视觉方向会被复用；若只要求修改某一个产物，不会自动重做其它阶段。

用户可以这样继续：

- “基于已确认的项目资料整理角色造型提示词。”
- “保留剧情和人物关系，只调整画面风格。”
- “只修改第 3 集的工程台本，其他集不动。”
- “先给我两个制作方向选，等我确认后再展开。”

## 生成前确认

漫剧制作中的文字方案、角色提示词和视频提示词都不等于媒体生成。只有用户明确要求生图、生视频或提交任务时，才使用创作面板生成。生成前确认模型、参考素材和面板展示的参数；价格和模型能力以当前界面为准。
