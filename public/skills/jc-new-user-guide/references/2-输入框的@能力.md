# 输入框里的 @ 能力

在输入框里敲 `@`（或点输入框右侧的 `@Skill` 按钮）会弹出能力菜单。每个 `@` 都是「本轮启用这一类能力」的开关，**不是提示词的一部分**：选中后该能力的工具和规则才会进入本轮。

## 菜单里有什么

| 入口 | 作用 | 产物 | 是否扣费 |
| --- | --- | --- | --- |
| Wiki Memory | 查询、整理当前项目资料，归档创作成果 | 项目里的 Markdown 与索引 | 不额外扣费 |
| Skill | 选一个 Skill 当本轮工作手册 | 由该 Skill 决定（剧本、分镜、角色卡等） | 不额外扣费 |
| Office | 把已有内容落成文件 | Word、Markdown、TXT、CSV、PPTX、PDF、网页、PNG 长图 | 不额外扣费 |
| 影音 | 生成图片、视频、音频 | 媒体文件，进入项目与创作历史 | **要扣费**，按模型计价 |
| 3D | 创建、检查、编辑 3D 场景 | `.jcscene` 场景文件、预览图、导出视频 | 不额外扣费 |
| MCP | 调用已连接的 MCP 工具 | 取决于那台服务器 | 取决于那台服务器 |
| 会话 | 引用当前项目的其他对话 | 把那段对话当作本轮材料 | 不额外扣费 |

`@文件` 芯片已经下线。本机读写、终端和 Skill 脚本由输入框左下角的「权限」档直接控制，不再需要单独一个芯片；想放开本机操作就切到完全权限，想收回就切回默认档。

项目里的具体文件用 `@` 直接引用（菜单里会列出当前项目的文件），模型只拿到路径，正文由它自己读。

## 只用你 @ 的那个

- **@哪个就只拿到哪个**：选了 Office 不会顺带得到影音生成能力，选了影音也不会顺带拿到 Office 的导出工具。两个都 @ 就是两边都在。
- **没有选 Skill 时是「自动选」**：模型可以自己挑一个合适的 Skill 用。一旦选了具体 Skill，它就不能在本轮再偷偷加载别的 Skill，避免两套规则打架。
- **付费只由「影音」和你的确认触发**：选路线、选芯片、点按钮都不会自动提交生成任务。

## 影音：唯一会花钱的入口

1. 说清意图，例如 `@影音 画一只趴在窗台的橘猫，写实摄影风格`。
2. 应用会先给一张媒体计划卡片，写着用哪个模型、什么参数、大概多少钱。
3. 你在卡片上确认（或改用别的模型）才会真正提交；卡片里的「直接生成」也会先确认一次模型与价格。
4. 结果进入项目「图片/视频/音频」目录和创作历史，需要时再放进画布。

和创作面板的关系：两边用的是同一套媒体模型和同一套参数。在面板里挑好模型、比例、尺寸、时长后，点面板上的**复制参数**按钮，会复制出一行 `[创作参数] …`；粘到输入框再接着写提示词就行，模型与参数按面板的选择执行，不用手动敲型号。

上游失败、敏感词拦截或余额不足会把原因写进任务卡片，照着提示改提示词或换模型，不要重复提交同一个任务。

## Office：把内容变成文件

| 想得到 | 直接说 |
| --- | --- |
| Word | `导出成 Word` |
| 表格 | `导出成表格`（生成 CSV，Excel 能直接打开） |
| PPT | `把这份 Markdown 幻灯片导出成 PPTX` |
| PDF | `导出成 PDF` |
| 网页 | `做成一个可以打开的网页` |
| 长图 | `导出成一张长图` |

详见 `references/8-办公.md`。

## 容易混的三件事

- **账号登录 ≠ 模型 API Key**：登录只解决身份和云端同步，模型调用要单独配密钥。
- **顶部聊天模型 ≠ 影音的媒体模型**：前者负责说话写字，后者负责出图出片，各自选。
- **权限档 ≠ `@`**：`@` 是给这一轮加能力，权限档决定模型能不能动你的本机文件和终端。

## 示例

```text
@Office 把上面这份分集大纲导出成 Word，标题「第一季分集大纲」

@影音 按下面的提示词出一张 9:16 竖版封面：雨夜霓虹招牌下撑伞的女人

@3D 把这个场景做成可以转视角的方块场景，方便我确认机位

@Wiki Memory 查一下这个项目里已经确认的主角设定
```
