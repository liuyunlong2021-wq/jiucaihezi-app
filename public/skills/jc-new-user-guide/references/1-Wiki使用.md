# 项目文件与创作产物

项目是韭菜盒子里管理一部作品的空间。每个项目有自己的对话、资料和产物；开始小说或漫剧前，先打开或新建对应项目。

## 把资料放进项目

可通过项目文件树添加小说、剧本、人物设定和参考媒体，也可以在对话中附加当前材料。告诉 AI 哪个文件是原作、哪些设定已经确认，以及本轮想完成什么。已有内容会作为当前创作依据；不需要先手动搭好一整套 Wiki 目录。

## 查看和修改产物

小说、漫剧路线完成正式文字产物后，会保存到当前项目的 Wiki，并在回复中提供实际路径。打开项目文件树即可查看、编辑和继续使用。

可以这样提要求：

- “查询当前项目里已经确认的主角设定，基于它设计角色形象。”
- “打开故事梗概和分集梗概，接着整理第三集剧本。”
- “只修改这份角色设定里的服装，其他身份特征保持不变。”
- “把本章先保存为草稿，等我确认后再追加到原文。”

小说章节先保存为草稿。用户确认后才追加到正式原文；之后需要故事拆分时，在项目文件树里手动触发“故事拆分”。漫剧每次按所请求的产物归档，不会自动替用户跑完全部制作环节。

## 项目与 Wiki

Wiki 是项目中的普通 Markdown 文件和媒体资料，不是另一种账号或单独的云端数据库。系统根据产物类型安排归档位置并维护所需索引，用户可以从文件树检查文件和真实路径。不同项目之间不会自动混用资料；要引用别的项目内容，请先将需要的材料加入当前项目。

## 同步与备份

账号登录用于启用云端文字同步。可以在“设置 → 同步”查看当前项目状态；实际上传或下载时，按提示打开左上角项目中心并选择操作方向：

- **上传并覆盖云端**：用本地项目文字资料覆盖云端版本。
- **下载并覆盖本地**：用云端项目文字资料覆盖本地版本。

同步操作按界面提示覆盖资料，不等于自动双向合并。图片、音频、视频、模型密钥和应用设置不属于项目文字同步内容；媒体请在生成或导入它的设备中管理。

## 保护账号密钥

模型 API Key 是账号凭据。不要把它写进小说、剧本、Wiki、聊天记录或公开截图中。账号登录和模型调用密钥是两项独立设置。
