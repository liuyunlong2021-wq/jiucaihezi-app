# 小说创作入门

小说创作路线适合长篇网文和连载小说。它按阶段搭建世界与人物，再逐章写作，不会未经确认就连续写完整本书。

## 开始

1. 在 Desktop 打开或新建一个项目，进入一个对话。
2. 点击输入框下方的“小说创作”。
3. 发送你想怎么开始。第一次会提供 A/B/C 三种起点，选一个即可：

- **A：已有想法**——把梗概、题材或人物灵感告诉它，请它整理成可写的故事。
- **B：还没有想法**——请它给几个创作方向，选择后再继续。
- **C：已经在写**——提供现有设定、章纲或最近章节，要求从当前进度续写。

入口只切换小说路线；发出明确请求后才开始当前步骤。小说路线会自动启用小说创作方法和项目 Wiki 归档能力。

## 创作过程

通常会逐步完成：

1. 灵感策划和市场定位
2. 核心梗与故事机制
3. 角色及世界设定
4. 全书大纲和逐章章纲
5. 书名、简介等文案包装
6. 正文逐章写作
7. 阶段性或全稿复盘

这些阶段不必一次做完。每一阶段都可以先看方案、提出修改并确认后再进入下一步。可以直接说“先只做核心梗”或“从现有第三章继续”。

## 每章草稿与确认

正文按章推进。新章节先保存为项目中的章节草稿，回复会给出真实文件位置。你检查正文后明确说“确认这章”，它才会追加到正式原文。保存完成后，系统会把草稿转换为确认记录，避免 Wiki 里留两份相同正文。

章节写入原文后，故事拆分和章节分析仍由用户决定。需要整理故事节点时，在项目文件树中手动触发“故事拆分”；保存章节不会自动开始分析。

## 产物放在哪里

创作规划、角色资产、章节草稿和正式原文都会归入当前项目的 Wiki。常见分类包括创作规划、资产、章节草稿和原始材料；系统按产物类型安排具体路径并在回复中报告，不需要用户预先手动搭建目录。

续写时可以说：

- “下一章先给我催化剂选项，我选完再写。”
- “保留已确认设定，只修改第 2 卷大纲。”
- “按刚才确认的章纲写下一章，先保存草稿，等我确认。”
- “我确认这章，请追加到正式原文。”

每本书建议使用单独项目。需要生成封面或插图时，再打开创作面板；小说正文写作不会自动触发图片生成。
