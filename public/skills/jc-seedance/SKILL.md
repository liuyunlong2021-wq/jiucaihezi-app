# jc-seedance｜Seedance 导演视频提示词

将用户素材转为可直接用于视频生成的中文连续分镜。用可见动作表达情绪，用接触与结果表达力量。学习案例的因果设计，不照搬角色、颜色、招式或参数。主文件定义工作流程、输出合同和通用原则；专项参考补充执行细节，不增加最终输出字段。

## 模型与已确认输入

- 用于用户指定 Seedance 2.5／SD2.5 的镜头或片段；具体型号的时长、参考媒体和提交参数按产品实际能力处理，不套 MiniMax H3 的字段或时长限制。本 Skill 默认交付提示词，不自动生视频。
- 有已确认工程台本时，以其指定范围为依据，保留台词、动作、镜头顺序、表演因果和空间连续；将内容表达为下方导演提示词，不重新改编剧情。没有工程台本时继续使用原有设计流程。
- 时间戳可有可无，服从用户要求或已明确的使用习惯。采用下方默认格式时按其默认规则；用户要求无时间戳时，专项里的时间分段也去掉时间标签，保留事件顺序与承接。需要时间戳时核对片段时长，并区分工程全片时间与本片段相对时间。用户明确要求优先于专项默认值。

## 工作流程
1. **提取事实**：读取用户指定素材与实际图片，确定剧情、人物关系、身份外观、场景、对白、能力、结果及规格。区分已确认事实和可自由设计部分；仅当缺失或矛盾会改变核心事实时询问，其余作克制设计。不虚构参考图核验。
2. **选择专项**：按下方路由读取相关参考；混合题材可读多个。不要为不相关题材加载整套资料。
3. **建立连续状态**：内部梳理实际位置、观察侧、视线目标、持物手、道具数量、衣饰位置、能量、伤损、环境痕迹及上段结束状态。该表只用于规划，不增加前置字段。
4. **安排事件与节奏**：确定每镜一个主要事件、首帧与结束状态。先给关键动作、情绪转折和结果留时间，再配置运镜与特效；弱剧情也有行动线与关系变化。已完成的准备不重复，非关键准备可省略，但交代省略后的状态。
5. **编写分镜**：人物动机或触发 → 主动作与反应 → 次级运动及环境反馈 → 观察方式 → 稳定落点与承接。按输出合同组织，不把内部规划直接输出。
6. **检查与交付**：核对事实、格式、连续性、时长负荷和画面可读性；冲突先在草稿内修正，涉及用户核心设定才询问。不声称文本校验等于视频生成效果验证。

## 专项路由
- 微表情、自拍、氛围人像、镜前表演、纱幔遮挡、细致衣饰互动：先读 `references/drama-performance.md`。普通文戏直接使用本文件原则，遇到这些难点再展开。
- 单场戏成片（暧昧、相遇、告别、回忆、冲突、悬疑、惊吓、行动、等待、重逢、失落等一整段戏，而非逐镜分镜）：先读 `references/single-scene-cinematic.md`，按其中的电影语言选择法与时间分段格式输出。
- 功夫、武器、追逐、群战、超能力交锋、动作准备、机械变形：先读 `references/kungfu-duel.md`。
- 动画夸张表演、动物喜剧、物理笑点、写实材质的卡通表演：先读 `references/exaggerated-animation-performance.md`；普通真人不套卡通符号。
- 茅山驱鬼、符箓、鬼域、法器与非接触斗法：先读 `references/maoshan-exorcism-action.md`，保留其具名术法多镜准备要求，仅用于虚构影视。
- 最终结构、图号、声音与时间码统一按本文件。参考内的示例是方法，不是每次必套的故事或镜头配方；茅山专项的具名术法准备要求仅适用于该题材。专项默认不附时间，在用户明确要求时间码时让位于本文件。

## 输出合同
默认全文不超过2800字；用户明确要求详细长版时按要求扩展。默认不写时间码、时长和时间轴；用户给总时长则在内部控制负荷，明确要求输出时间码时才在镜头编号后标注并核对总和。不承诺精确兑现到百分之一秒。

依次输出以下结构，不另增场景、光影、环境音、道具锁定或状态表等前置字段：

```text
生成一个[格式、画幅或媒介]的，[具体画风]的，讲述[内容、人物关系和核心冲突]的电影片段。

参考图1：[对象名称、视觉锚点；角色附完整声音九维]。
参考图2：[按实际素材逐图单独成行]。
严格遵循参考图的指令：[视觉、道具、场景与声音身份保持一致，不串图、不漂移]。

角色位置关系约束：[一句话说明实际位置、观察侧、初始画面左右前后、距离、朝向、视线及越轴规则]。

镜头1：[功能标签；必要时附引用：图号] ｜ [主体数量+景别]，[机位高度]，[拍摄角度]，[运镜及运动特征] ｜ [首帧状态、位置、朝向、动作与反应、逐字对白、声音、环境反馈和出口] ｜（转场与下一镜承接）
镜头2：[继续逐镜单独成行]
```

首行以“生成一个”开头。格式只采用有依据的信息；画风明确主要材质、摄影、美术和表演，再添加少量辅助纹理。引擎、帧率、HDR等不等于实际启用渲染或输出规格，不自行堆叠参数。

## 参考图与事实
- 只编号实际提供的图片，逐图一行；没有图片时省略图片行和镜内图号，保留声明：“严格遵循参考图的指令：本次未提供参考图，不虚构图号，以用户确认的文字设定保持一致。”未读取图片不声称已核对。
- 每张角色图写视觉锚点及声音九维：年龄感（听感成熟度）、音高（音区重心）、明暗（音色方向）、厚薄（体积）、共鸣（胸口鼻头腔）、气息（气息量与稳定性）、颗粒感（质地）、口音（语言地域强度）、稳定表达习惯（语速停顿重音句尾）。不把单句情绪当声音身份。
- 声音依据用户录音或设定；不足时按明确身份提出克制的中性设计，重要不确定项先问。无语言发声角色仍列九维，不适用项注明“无语言发声，不适用”，不增人声。
- 非角色图只写场景、道具等锚点。立绘不证明动作、站位、声音或隐藏布局。逐镜引用只列实际可见且需锁定的对象，不虚构缺失图。
- 保留用户身份、服装、数量、能力、时代、胜负、结局和对白；对白逐字嵌入动作，不另设字段。不新增机械肢体、武器或魔法能力。

## 通用镜头与连续性
- 每镜围绕一个主要事件，主体集合稳定；允许双方完成发起、回应、接触和结果，不因换人回应或进入下一动作相位机械切镜。无关事件或未经交代的主体替换才另起镜。
- 写主体数量，动物用只数，道具微距说明局部归属，群战说明核心交锋者与敌群层次。出入画交代方向；禁止同框时排除对手本体、倒影、影子和背景人形，转场不用叠化重叠。
- 区分实际空间与屏幕左右：环绕允许改变屏幕左右，以固定地标重建方向；反打不强求相反方向都出现相同背景。场景布局、自然光与地标不为构图移动。
- 跨镜与跨段核对位置、视线、持物手、道具数量与状态、能量、伤损及余势；换手、挂鞘、落地等有过渡。环境破坏持续保留。
- 每镜一行，不拆表情、对白或SFX字段。功能标签选 HOOK、SETUP、RISING、CRISIS、SIGNATURE、LAUNCH、LANDING、INVITE、PUNCHLINE、RIDE OUT。
- 每镜写景别、机位高度、角度与主要运镜路径，明确起点、落点和避障。先决定观众需要看清什么，再选择推近、跟拍、环绕或俯瞰；贴背为第三人称，不混称主观视点。甩镜写重新稳定后的主体、位置和朝向。
- 一镜优先解决一个主要难点；精细接触、镜面反射、大面积遮挡和复杂运镜不同时堆满。景深与运动模糊服务当前信息，关键表演或接触不能被模糊、遮挡和特效共同淹没。
- 声音在发生处写入，不擅加旁白；只保留同期声时使用环境、接触、衣料、呼吸等，不添加音乐。
- 每镜写出口及硬切、动作相位切、声音桥、遮挡或运动接力等承接，说明前后如何接上。最后按用户要求悬念保持、结束或淡出，不默认结束战斗。保持姿态仍有呼吸与余势，真正冻结帧仅在明确要求时采用。

## 文戏与人物表演
- 每个重要情绪落实为可见的视线、眼眉嘴、呼吸、手部或重心变化；先有察觉、倾听、犹豫等触发，再发生回应，不只堆气质形容词。
- 以“建立基础状态 → 一次有意义的变化 → 停留与落点”组织短表演。保持时间属于表演；允许同一镜内完成连续情绪变化，不为每次眨眼或歪头切镜。
- 明确看向谁、何处，头部转动后是否保持视线目标。对白保留原文，倾听和反应围绕对白发生，不擅改台词来配表情。
- 人物主动作带动少量次级运动：躯干先转，衣发或饰品稍后跟随，人物停住后它们逐渐停止。写清风向、接触点与衣饰原位置，不让所有细节同时抢戏。
- 弱剧情用连续行动路线、视线对象、观看距离或遮挡关系的变化推动；道具承担使用、反射、照明或转场功能。光线写来源、方向和材质响应，风格有主次。
- 时长不足时从已就位状态开镜，减少走到、坐下、拿起等非关键准备；保留决定情绪的动作与停顿。微表情、镜面、自拍与遮挡细节按文戏专项执行。

## 动作戏核心原则
- 用“威胁来源 → 应对 → 接触或避让 → 目标及环境结果 → 余势”写攻防。肢体、武器、方向和重心明确；连招以上一动作的落脚、朝向和余势衔接。
- 不同角色使用不同动作词汇；技巧型的卸力需看见避线、接触外缘、转体引偏与攻击落点，抽象武术名词不能代替可见动作。
- 武器准备、充能、机械变形展示初始、中间、最终状态及可见证据；持握、数量和连接关系稳定，部件有来源。细节按动作专项，不把拔刀或变形配方套到所有战斗。
- 群战让反击与补位改变主角路线；阶段升级改变动作方式、形状或覆盖范围。命中有接触、目标响应和相容的反馈方向，强弱有层级。
- 特效有来源、路径、作用点与消退，不遮关键结构；能量转化须有设定支持。环境痕迹与人物伤损持续，幻想规则和材质惯性分别限定。
- 速度有变化；慢动作解释关键接触，不以每秒动作数替代编排。时长过载先减次要招式、运镜与特效，保留决定因果的接触和结果。

## 视觉喜剧核心原则
明确异常规则对谁生效、结果与不变量，保留用户的胜负和笑点。先证明普通属性，再让观众看见异常发生；用可见反应连接观察、误判与行动。物理笑点尽量连续展示动作起因、碰撞和结果，给角色意识到失败的时间。卡通变形与真实材质分别限定；具体反应、拟人转换和符号使用按专项参考。

## 交付前检查
- 格式：首行、逐图绑定、声音九维、一致性声明、位置关系、逐镜单行、编号、字数和按需时间码。
- 可读性：情绪有动作、攻防有因果，每镜有重点；重要视线、结构、接触与结果可见。
- 连续性：空间、光源、持握、衣饰、道具、能力、跨段状态与环境痕迹一致。
- 节奏：动作、对白、停顿与运镜能容纳在目标时长；无平均分镜或动作堆积；关键难点有观看时间。
- 冲突：清除不受击却被击中、禁止冻结却冻结、单人却出现对手倒影等矛盾；禁项限定对象与时段，并配正向执行要求。仅声明实际完成的核验与测试。
