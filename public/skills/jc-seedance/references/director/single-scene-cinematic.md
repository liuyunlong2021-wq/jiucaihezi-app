# 单场戏电影语言与声画组织

用于暧昧、相遇、告别、回忆、冲突、悬疑、惊吓、行动、等待、重逢、失落等一整段场戏。只补充导演设计方法，按工程台本主文件的时间码、镜头规格与表演节拍输出；不另立单场戏视频提示词格式。

## 选择电影语言

1. 从原稿与已确认资料提取人物关系、角色此刻知道什么、想得到什么、核心事件、场景天气、现有镜头与时间轴。没有固定总时长时按自然对白与动作估算制作预算并标明；有硬时长或真实音频时服从其边界。
2. 根据当下行为机制选择观看方式，不套固定镜头顺序：
   - 暧昧：错开视线、共享有限空间、试探性递物、停顿、被发现后回避、二次确认、距离变化。
   - 雨中亲密：共享屋檐、让出干燥位置、递伞、雨声留白与有限遮蔽空间里的靠近。
   - 重逢：先看见、迟疑确认、表情变化、身体先于语言行动、距离缩短或错失。
   - 冲突：空间对峙、动作打断、沉默压迫、物件成为张力中心、节奏改变。
   - 悬疑：信息延迟、遮挡、局部揭示、主观误认、先见反应后揭对象、环境声制造不确定。
   - 动作：明确目标、身体预备、启动、障碍、重心与速度变化、结果。
   - 告别或失落：动作变慢、看向空处、触摸已有遗物、环境继续流动、人物停留。
   - 回忆：光线、细节、动作节奏与停留服务记忆的主观感受。
3. 可借鉴电影传统中的镜头、表演、剪辑与情绪机制，不复刻既有角色、台词、具体情节或逐帧设计；内部借鉴不增加“电影语言参考”输出字段。
4. 为当前原稿设计独有的情绪链和行为链。咖啡馆可围绕已有杯子、蒸汽和目光，门口避雨可围绕屋檐与让位，电车相遇可围绕窗框、遮挡和错过；这些是选法示例，不授权新增事件或道具。不能把“全景—偷看—主观—对视”套进所有场戏。

## 已给出镜头的处理

明确的镜头顺序、时间范围、景别、机位、动作和结尾保留。文字含混可在不改变动作、信息和节奏的前提下澄清；改变表演策略、增补反应、调整切点或重新调度属于导演修订，只在用户授权范围内做。缺少关键刺激、空间、反馈或时间容量时指出具体镜头与缺项，不能把猜测包装成已确认设计。

## 声画与切点

镜头服务观众此刻应看清的一个核心戏剧任务，该任务的直接子动作可以连续发生。采用合适的单人过肩、中近景、反应特写与插入特写；不同剪辑视角各有独立编号。全景与固定镜头按主文件偏好和实际需要使用，不为数量凑镜。同镜按规格连续调整构图，不以跟移或环绕串接多个独立任务。新观看主体、独立任务及剪辑切换进入新编号；多任务长镜头须有用户明确要求或已选方案，换说话人仍必切。

人物情绪从视线、呼吸、嘴角、手部、重心、步伐、距离或回避中挑选一项最有效的变化落实；不要求每镜把这些线索逐项写全。停顿承担真实等待、判断或策略变化，不能只有标签。光源、方向、冷暖和材质响应在影像基调统一，镜头仅补发生的变化。

普通回应镜头先确定主体与取景范围，只用其可见清单写新动作和台词。单人正文及表演括号不带画外人物的名字、代称、所有格或物件来源，药碗入镜不能引出递碗者的手；角色能看到画外刀也不代表本镜能展示刀。上下文留在内部，当前物件可见变化照常写；必要真实接触另用可见交互镜头。详见主文件的镜头可见内容方法，不能以因果或持物连续为由扩大单人范围。没有必要结果变化时，台词结束就是正文结束。

自然声音来自实际场景与动作：脚步、雨、风、衣料、门轴、杯碟、车轨、人流、呼吸或远处城市声。根据原稿选择有作用的声音，如杯碟落下使试探停顿被听见、脚步由急变慢体现犹豫；不擅加对白、旁白、歌曲或字幕。声音桥交代哪一声跨到下一镜及如何承接，不破坏一镜一个说话角色。

## 检查

观看信息是否随事件推进；触发与策略是否已在内部判断，而未写成“看见对方做了……所以……”的上下文复述；单人正文的每项动作（包括察觉句中的嵌套动作）是否只来自本镜可见主体；原台词与动作是否完整；声音、切点及时间是否有依据；已确认镜头是否只在授权范围内改动。
