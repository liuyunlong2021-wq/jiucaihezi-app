# 从剧情状态到本镜可见内容

用于单人对话、过肩、递物、持械威胁和有画外互动的镜头。角色在故事里能看见什么，不代表当前摄影机拍到了什么；物件入镜不代表其来源、所有者或另一人的手同时入镜。

## 先确定范围，再起笔

内部逐镜确定：核心任务、镜头类型、主体、取景内的身体部位、明确入镜的物件、当下新增动作。完整剧情状态另行保留，用于连续性，不能整体复制到正文。这里的清单是写作依据，不是交付字段。

单人清单只能包含这一名角色，不得为了补全交接而把画外人的手、身体或表情临时加入。过肩可保留无动作的肩背前景关系，不能借此增加另一人的持物、递物或接收动作。确需双方接触的新任务须单独安排交互取景，用户已锁定单人镜头时不能擅自扩成双人。

例如当前是大郎的单人中近景：可见大郎的脸、上身和手，以及药碗、瓷勺。画外潘金莲是谁、她是否仍握碗、刀垂在哪一侧、床沿是否挡住脚跟，都是场景状态；未经当前取景显示，不成为画面句子。

只从可见清单写：主体的新动作、可见物件变化、原台词、必要同期声音。叙述与表演括号不使用画外人物的名字、代称或所有格。原台词中的人物名和“你／她／他”逐字保留，不受这个叙述限制影响。

过肩默认只说明观察关系，不在规格中用画外人物名字提示模型把该人物带入正文；若用户已锁定具名肩后规格，保留规格但只按本镜可见清单写内容。需要显示另一人的手或其他身体部位来完成关键接触时，明确安排交互特写或多人镜头，不将单人镜头偷偷改成双人。

## 同一件事的画面写法

| 整场状态或越界叙述 | 当前可见范围 | 画面表达 |
| --- | --- | --- |
| 看见潘金莲递来的药碗 | 大郎与药碗可见，递碗者不显示 | 大郎看向药碗，左手托住碗底 |
| 潘金莲的左手仍握着碗侧 | 本镜没有这只手 | 不写；只描述大郎自己的握持 |
| 看她右手垂着的匕首 | 大郎可见，匕首不在取景内 | 只写大郎低头／视线偏向画外；不写画外刀和持刀者 |
| 将药碗推回她面前 | 大郎的手与药碗可见 | 大郎将药碗缓缓向前推 |
| 潘金莲看见大郎望门，挡住退路 | 本镜只拍潘金莲 | 潘金莲侧移半步，挡在门前 |
| 大郎脚跟仍抵着床沿 | 中近景只覆盖上身 | 不复述脚跟状态；原稿必需的脚部动作另选能看清的镜头 |
| 说完托碗的手停住，等她接招，硬切到她 | 没有新增动作结果 | 在原台词结束处停止正文 |

不是所有“看见”都要删：主体看向本镜确实显示的物件可以写。要删的是画外人物行为、物件来源说明、未显示的身体和重复上下文。若原稿本轮有必须展示的新事实，则调整相应取景或另镜呈现，不能丢事实或凭空编造物件动作。

## 输出前重新对照

把单人镜头的画面句子和表演括号逐句对照清单，检查每一个名词、代称、所有格及动作归属，而不只看句首主语。出现清单外的角色、身体或物件时，重写该句，再核对原动作与台词是否仍完整。只交付修订稿，不交付可见清单或通过声明。
