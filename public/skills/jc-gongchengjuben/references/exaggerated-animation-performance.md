# 动画夸张表演与视觉喜剧专项参考

用于动画、动物喜剧、表情反应及写实渲染的卡通表演。分别约束材质真实性、表演夸张程度、身体变形和超现实规则；不把普通真人表演改成卡通。

## 导演分镜整合

使用工程台本的连续时间码与节拍格式，将触发、脸部变化、姿态、余波、声音与转场写入动作。每镜一个主要反应或喜剧事件；允许围绕同一触发形成连续情绪变化，不因眨眼、歪头、理解或误判机械切镜。不同独立事件或表演中心转移再切镜；换说话人仍须切镜。

## 表演设计

先确定看见、听见或感受到什么，再选择反应强度：
- 轻度：眼神偏移、眉峰轻挑、嘴角压住、手指短停。
- 中度：眼睛放大、捂嘴、扶额、叉腰、肩膀内收。
- 高度：跳起后缩、夸张后仰、双手抱头、身体短暂僵住。

每个反应节拍选一个主要脸部变化、一种主手势与一个身体反应，不同时堆满。无适合手势时用头颈、翅膀、尾巴或重心；不强迫动物长出人手。

用“预备 → 爆发 → 保持 → 余波”组织：眼神预备，主动作发生，留出看清时间，最后以呼吸、肩膀轻颤、衣摆或尾巴收尾。保持姿态不等于冻结帧；真正冻结须用户要求。

常用组合：惊讶可为睁眼、张嘴后僵住、身体微退；得意可为半垂眼睑、抬下巴、重心后置；无语可为眼神放空、嘴角下垂、肩膀下沉；偷笑可为弯眼、捂嘴、肩膀轻颤。随角色比例与动物形态调整，不照搬模板。

## 喜剧规则与因果

- 明确异常规则对谁生效、导致什么结果、哪些物体外观不变。角色与结果的对应关系不得颠倒。
- 先通过具体动作证明正常属性，再让观众看见异常发生的关键边界。例如画笔接触岩石证明平面，再连续展示对象进入画内纵深；这只是方法，不将壁画故事套入所有任务。
- 地面线、轨道、门框等可连接真实与异常空间。选择能读懂边界的机位，不用剪辑省略决定笑点的过程。
- 不擅加传送门、魔法光效、机关开合等解释，除非用户设定需要。保持指定的不对称规则与物体外观。
- 平静执行异常规则的角色与认真误判的角色可形成反差；不要让所有角色同时惊讶抢戏。
- 反应可按“接收事实 → 审视 → 错误理解 → 恢复自信 → 行动”展开，每步有眼眉嘴或姿态证据，省略与剧情无关步骤。
- 失败前的少量认真准备强化自信并延迟结果，不添加冗长检查或重复热身。

## 物理笑点与余波

优先连续展示助跑、接触、身体受阻及后果，关键接触不被镜头背面或特效遮挡。事故之后留出理解失败的时间，如保持撑墙姿态后睁开一只眼睛，再失去支撑倒地。

碰撞是受控卡通打闹，不增加血腥伤害。明确允许压缩或拉伸的范围；要求三维实体时不变成剪纸。拟人作画与四足奔跑的切换有姿态过渡，角色身份和比例稳定。

需要保留时间的事件包括异常发生、反应转折、接触与意识到失败；制作准备可以通过省略剪辑压缩，但道具完成状态需连续合理。按用户总时长调节，不把关键边界事件压缩为结果跳切。

## 图形符号与声音

汗滴、星星、蒸汽、旋涡等只在风格或用户允许时采用，每个节拍必要的一至两类，位置明确，不遮挡关键表演。不得借符号增加字幕或旁白。静默动物不补人声，音效依据实际动作和环境。

## 资产依据

角色图说明外貌和比例，表情卡说明眼眉嘴变化，手势卡说明姿态，符号图说明视觉风格。依据实际素材设计，立绘不证明动作或表情；不复制图中文字、水印或排版。动作仍须连续，具体图号与提交引用留给下游适配。

## 检查

是否有明确触发；主要反应是否可见；异常规则和结局是否保持；关键边界与碰撞是否被看见；停顿是否仍有表演；材质与卡通物理是否分别限定；道具和空间是否连续；符号是否克制；是否未套用到普通写实人物。
