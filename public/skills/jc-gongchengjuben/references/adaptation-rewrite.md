# 逐集改编：删减、压缩与扩写

来源剧本可能是文学剧本、分场文本，也可能已经是短剧改编稿。本技能不只做格式转换：在保住事件因果、胜负、人物关系与伏笔的前提下，**删掉不推动剧情的，把动作扩到可拍**。一次只改一集。

## 一次只改编一集

- 每轮只处理用户指定的一集；多集时逐集出稿、逐集保存，不把两集合成一稿，不跨集统一镜头编号，不提前消耗下一集的冲突。
- 上一集只读结尾状态做衔接：谁在哪、拿什么、伤到哪一步、气场如何。不重演上一集演过的内容。
- 下一集只读开头确认钩子落点，不把它的爽点提前搬来。

## 开写前先体检本集资料

第 1 集逐项体检；后续集只查本集新出场、新换装的实体。缺什么补什么，**补完再动笔**，不要把缺失硬写成空话（"俊美""古色古香""一把剑"）。

| 要用的资料 | 必须写清的东西 | 缺了怎么办 |
| --- | --- | --- |
| 人物小传 | 脸型、五官、发型发色、身形、年龄感、稳定记忆点 | 按[角色形象](../../jc-juese-sheji/SKILL.md) 的骨相／五官／身材／记忆点方法设计，写回该角色的 `character_bio`（先读原文，只补缺，不改原文事实） |
| 场景说明 | 空间结构、方位与动线、主要材质、光源、时辰与天气 | 按[场景设计](../../jc-scene-prompt/SKILL.md) 补写 `scene_research` |
| 道具说明 | 形制、尺寸、材质、颜色、纹饰、磨损 | 按[道具设计](../../jc-prop-prompt/SKILL.md) 补写 `prop_research` |
| 人群 | 群体名、人数、服制、队形 | 按[人群群像](../../jc-renqun/SKILL.md) 建 `crowd_asset` |
| 造型 | 发型、服装、配饰、伤损 | 按[服装设计](../../jc-fuzhuang-prompt/SKILL.md) 建造型表与 `costume_asset` |

- 原文或资料已经写明的外观**照用不改写**；只补两边都没写的空档。
- 设计服从当时的时点：不把后期造型、后期能力、后期伤势提前用到本集。
- 属于日常物件的（杯碗筷、桌椅、食物）写进场景的"陈设"，不单列资产；没有独立戏份的配角写进场景的"人群"。
- 流水线里资料已由 materials／assets 阶段建过：这里只做体检与补缺，不重复生成，不覆盖已确认内容。

## 删：不推动剧情的删掉

逐个段落问一句：**去掉它，剧情因果、人物关系、信息差、后文伏笔会变吗？** 全都不会，就删。

该删的：

- 过场过程：走到、开门、进门、坐下、起身、上马、来回传话。
- 重复交代：同一信息在相邻场景说两遍；人物复述观众刚看过的事。
- 无冲突无爽点的日常：吃饭、闲聊、赶路、准备，除非其中有信息或情绪转折。
- 同义反复的心理活动与总结性感慨。
- 已经演过的内容再演一遍（闪回只保留新增的那几秒信息）。

不能删的：

- 原台词（逐字保留，标点与顺序不变）。
- 关键事件、胜负、能力、关系变化。
- 伏笔与它的回收点。
- 集尾钩子。
- 打戏的结果（谁占上风、留下了什么痕迹）。

删完在回执里用一句话说明删了什么、为什么，**不写进正文**。

## 压：对白电影化

- 对白按每分钟 240 字占时间，本场对白秒数不得超过本场时间。
- 小说腔长句改成人物当下能说出口的短句；书面语、解说话、总结陈词改成有动机的对话。
- 信息靠动作、停顿、反应分担：能演出来的不让人物说出来。
- 保留意思、说话人、对象和信息差；不为压字数删掉关键信息。
- 一场戏里没有动机的长篇独白，拆成几个短句或改成动作。

## 扩：把动作写成可执行的节拍

扩写只展开**已有动作和已有反应**，不新增事件、证据、角色选择或力量。细度标尺见[镜头细度](shot-density.md)，这里是改编层面的取舍：

- 哪些该扩：打斗与追逐、术法与特效、关键情绪转折、人物首次展现性格的那一下、爽点落地的瞬间。
- 哪些只压不扩：过场、交代、重复反应、普通应答。
- 扩写的最小单位是**镜内节拍**：把一秒到两秒里发生的事按先后写出来（谁先动、怎么动、动了多少、谁受影响、镜头怎么应），而不是给一句"激烈交手"。
- 打戏必须写全四件事：发起（动机与朝向）、轨迹（接触点、被击部位、受力方向）、反馈（碎屑、扬尘、火星、衣摆、发丝、镜头震动）、结果（谁占优、留下什么痕迹、下一拍怎么接）。
- 特效必须有几何与颜色：起点、形状（线／环／面）、颜色与质感、消散方式。
- 文戏的"细"不是加数量，是加精度：部位、方向、幅度、速度、次数，外加由它带出的次级运动（发丝、衣料、饰品滞后一瞬）。
- 禁止用结论词代替动作：不写"打斗激烈""气势磅礴""美感十足""特效拉满"。

## 改写的边界

- 不新增原文没有的事件、证据、角色选择、能力或胜负。
- 不改变人物当时掌握的信息与认知。
- 不为了镜头好看改变空间关系与因果顺序。
- 时间不够时优先删过场、压对白，不动关键动作与伏笔；仍不够就报告具体缺口与最小调整方案。

## 交付前检查

1. 这一稿只含一集吗？有没有把下一集的内容提前搬来？
2. 本集要用的角色／场景／道具，长相、空间、形制都写清了吗？空缺是补过资料还是硬写？
3. 删掉的部分里，有没有其实承担伏笔或信息差的？
4. 打戏是否每一拍都有发起、轨迹、反馈、结果？还有没有"激烈""震撼"这类结论词？
5. 文戏的关键情绪，是否落到部位、方向、幅度、速度或次数？
6. 原台词是否逐字在位，说话人与信息差有没有变？
