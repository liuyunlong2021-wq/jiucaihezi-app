# 场景与对白打磨

落稿后逐场检查。所有改动都在本集原文切分内进行：可以重写表达、调整呈现，不新增事件、能力、胜负和关系。

## 一、场景

**逐场转向表。** 每场戏过一遍：

| 项 | 要回答的问题 |
| --- | --- |
| 进入 | 是什么把我们带进这场？尽量短。 |
| 初始方向 | 观众以为这场会走向哪里？ |
| 冲突 | 谁和谁、和什么、和自己在较劲？ |
| 交代 | 推进剧情所需的信息，藏进冲突里给出，不单独讲解。 |
| 人物 | 通过行为和对白看出什么性格？ |
| 结果或反转 | 谁赢了、谁输了，或者出了意外；结束局面要和开始不同。 |
| 接出 | 下一场接什么？用一个动作、一句话或一个道具交接。 |

有一项答不上来，就回原文找。原文这场确实只是过渡的，压缩成几行，把时长留给重场戏。

**冲突。** 关系再好的人物，在一场戏里也要有目标上的分歧；单人戏可以是人与环境、人与物、人与自己较劲。冲突来自原文，只加强呈现，不编造新矛盾。

**晚进早出。** 删掉寒暄式的开头和总结式的结尾，从冲突即将发生处进场，结果一出就离场。走路、上楼、备马、传话等过程，原文没有承载情节的，直接切到结果。

**重复中的变化。** 原文中同一个动作、道具或场景出现多次，比如同一杯酒、同一句话、同一把剑，在剧本里保持一致的写法，让观众看出前后的差别，用重复和变化表达人物的变化，不靠台词说破。

**开场。** 本集第一场就让观众看到人物、处境和冲突。从本集原文中选最能抓人的那个画面或那句话开场，不额外加戏。

## 二、描写

**只写看得见的。** 搜一遍“意识到、以为、感觉、觉得、想、心中、明白”这类词，把人物脑子里的东西改成能看见的动作、表情、反应，或者让人物说出口。确实需要交代心理时，节制地写一句，不展开成小说式心理描写。东西在镜头里打开或亮出之前，不写里面是什么，比如鼓起的信封、盖着的箱子。

**影像顺序。** 先交代地点，再写人物和动作；先远后近；原因在前，结果在后。一句话里的画面顺序，就是读者脑中出现画面的顺序。

**一行一个画面。** 说明书要写全，但拆成短行：一行写一个画面或一个动作节拍，读起来就像一串镜头，下游可以直接拆镜。

**强动词，删弱词。** 删掉“正在、开始、然后、非常、真的、这个、那个、一下”这类弱词，改用具体动词，比如用“踹开”替代“用力地推开”，用“攥紧”替代“紧紧地握住”。

**关键词放句尾。** 一句话的分量在最后几个字。卡点、反转、包袱放在句尾和段尾，台词也是如此。

**有名字的人物开口，就写出台词。** 只有群众可以在描写里一笔带过，比如“人群怒吼”。有名字的人物说了话，就写出具体台词，配音需要。

## 三、对白

**不写问答式。** 一问一答、对方复述问题再回答，会让戏停住。回答时跳过显而易见的部分，同时带出新信息或新态度。

- 差：“你找到他了吗？”“是的，我找到他了，他在后山。”
- 好：“你找到他了吗？”“后山。只剩半口气。”

**潜台词。** 人物真正想说的话往往不说出口，用回避、反问、转移话题、动作来表达。原文直白说破的，在不丢信息的前提下，可以改成更含蓄的说法加上可见的反应。

**演员提示。** 括注只在台词字面与真实情绪不一致时写，比如提示写“压着怒气”，台词却是“您说得对”。台词已经清楚表达的情绪不重复标注；动作写进描写行，不塞进括注。

**每个人说话要不一样。** 遮住名字也能认出谁在说话：身份、出身、年龄、性格决定用词、句子长短、语气和口头禅，小角色也要有自己的说话方式。原作已经写出的说话方式要保持并放大，不另造。写一场多人对白时，可以先顺着一个人物把他的台词全部写完，再写另一个，最后合成，避免几个人说成一个腔调。

**少说一句。** 每段对白写完后，试着删掉最后一两句；删了意思不受影响的，就删掉。

**读出来。** 按人物的语气默读或念一遍台词，拗口的、念不出口的、太长的，改短。
