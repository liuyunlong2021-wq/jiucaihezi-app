# 场景设定图提示词

把用户本轮提供的故事、文字、参考图和修改要求，转化为一条可直接提交给生图模型的中文场景提示词。优先锁定空间结构、功能动线、时代地域、材质、标志物、镜头视角和光线逻辑，再承载叙事情绪。

## 输入边界

读取用户本轮直接提供的文字、图片和明确修改要求。缺少信息时依据用户文字做最小必要推导，不把推导写成已知事实。

参考图只锁定可见的空间布局、建筑/物件形状、材质、颜色、固定标记和时代线索；不继承原图构图、人物动作、光线或旧画风。参考图看不见的区域按结构连续、功能合理的最保守方式补全。

## 工作流程

1. 锁定场景名称、类别（室内/室外/半室内/自然/城市/抽象空间）、时代地域、功能、规模和叙事用途。
2. 写出可见空间边界、前中后景层次、主要入口/出口、动线、视线焦点、标志物和空间比例。
3. 拆解建筑与环境材质、颜色、纹理、固定陈设、使用痕迹、天气或季节线索。
4. 选择镜头视角：默认 3/4 斜角俯拍用于同时读出平面布局和纵深；用户明确指定时服从用户。需要纯正立面、鸟瞰、轴测或平视时，不强行套用 3/4 俯拍。
5. 选择与用户要求一致的媒介和视觉风格；缺失时只选一种不冲突的默认风格，不堆叠写实、CG、动漫等互斥术语。
6. 生成一条完整中文主提示词，确保脱离本 Skill 字段也能直接生图。

### 画幅与构图适配

- `16:9` 横屏：优先使用 3/4 斜角俯拍或平视宽构图，横向展开空间边界和动线。
- `9:16` 竖屏：优先使用 3/4 斜角俯拍或轻微仰/俯视的纵深构图；前景放在画面下方约 1/3，中景核心区域位于中央，远景、天际线或天花板延伸至上方约 1/3，入口/出口沿上下或斜向动线布置。避免把横屏场景简单裁切成竖屏，关键标志物、动线和视觉焦点必须完整入镜。
- 用户指定画幅时，必须在主提示词开头明确写出比例，并让摄影机位置、留白和空间层次服务于该比例。

## 主提示词模板

```text
生成一张[16:9横屏或9:16竖屏]的[场景名称]场景设定参考图/空镜概念图。场景类型为[室内/室外/半室内/自然/城市/抽象空间]，位于[时代、地域或世界观]，承担[功能和叙事用途]。

空间结构：整体边界为[墙体、地形、道路、水面或其他边界]；前景为[前景元素]，中景为[主体空间与主要陈设]，后景为[远景、开口、天际线或背景层次]；入口、出口和主要动线为[空间关系]；视觉焦点是[标志物或核心区域]。保持结构、比例、透视和空间连通关系清楚可读。

材质与固定细节：[建筑/地面/植被/设施]的主体材质、颜色、纹理、加工方式、固定标记和使用痕迹；只加入与场景身份相关的物件，不添加无关装饰。

镜头与构图：采用[3/4 斜角俯拍/平视/正立面/鸟瞰/轴测/用户指定视角]，摄影机位于[位置、高度、朝向和焦段感]；画面完整展示[空间范围]，前中后景层次分明，保留适配[16:9或9:16]的必要留白，不出现人物或只出现用户明确要求的角色。若为 9:16，前景位于下方约 1/3，中景核心区域居中，远景或顶部延伸至上方约 1/3，主要动线沿纵向或斜向清楚可读。

时间与光线：[时间、季节、天气]；光线来自[方向]，具有[软硬、色温、雾气、反射和阴影]特征；光影服务于空间结构读取，不遮挡关键标志物。

统一采用[媒介与视觉风格]表现；[线条/材质/渲染/颗粒/纸张或摄影质感]。画面为干净、可复用的场景资产，不加入剧情文字、标题、水印、无关人物、第二地点或不属于该场景的物体。
```

## 输出

只返回一条完整中文场景主提示词。

## 质量检查

1. 主提示词可脱离字段直接生图，且明确场景身份、空间结构、材质、镜头和光线。
2. 画幅比例明确且布局匹配：16:9 横屏展开横向空间，9:16 竖屏采用上下分层和纵向/斜向动线；未指定视角时优先使用能读清平面和纵深的 3/4 斜角俯拍。
3. 前景、中景、后景、入口/出口、主要动线和视觉焦点互不矛盾。
4. 参考图只影响可见空间事实，不覆盖项目或用户指定媒介、风格和构图要求。
5. 场景是单一可复用地点，不擅自拼接第二地点、剧情动作或无关人物。
6. 缺少信息时仍能依据用户本轮内容补齐必要设计值；不输出“无法执行”、空模板或上游字段。
7. 不混用互相冲突的摄影、CG、二维动画和手工媒介术语。
8. 图片文字、标题、水印和尺寸标注只有用户明确要求时才加入，并固定内容与位置。
