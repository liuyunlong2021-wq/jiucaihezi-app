# 项目参数与视觉风格选项

本文件只供用户在运行 `jc-film-style` 前选择项目参数。Skill 不读取本文件，只使用用户已经确认的项目参数。
这里的“风格”是可执行的生产约束，不是作品名、导演名或搜图关键词。

## 使用顺序

1. 画面比例
2. 国别与地域
3. 媒介
4. 风格大类
5. 风格小类
6. 把最终选择作为项目参数交给 `jc-film-style`

未选择的值写“未明确”，不得由 Skill 猜测。用户已明确的项目参数优先于本表的建议值。

## 画面比例

比例影响主体安全区、构图方向、分镜图尺寸和视频输出。每个项目只确认一个比例。

| 比例 | 适用场景 | 点一点当前状态 |
| --- | --- | --- |
| `9:16` | 手机竖屏、短视频、信息流 | 当前生产界面可直接选择 |
| `16:9` | 横屏剧集、电影感叙事、桌面播放 | 当前生产界面可直接选择 |
| `1:1` | 方形社交媒体、头像式内容 | 项目类型已支持，当前生产界面未开放 |
| `4:3` | 复古电视、纪录片、旧影像 | 项目类型已支持，当前生产界面未开放 |
| `3:4` | 竖向海报、人物卡、编辑肖像 | 项目类型已支持，当前生产界面未开放 |
| `21:9` | 超宽银幕、横向片头或环境展示 | 项目类型已支持，当前生产界面未开放 |

## 国别与地域

国别不是画风。它只约束文化语境和可核对的环境事实：建筑、道路、服装、道具、文字、生活方式和社会关系。没有剧本文字或用户确认时写“未明确”。

可选方向：

- 中国大陆
- 中国香港/澳门/台湾
- 韩国
- 日本
- 美国
- 欧洲
- 东南亚
- 中东/北非
- 拉丁美洲
- 架空世界
- 未明确

填写规则：可以写“美国·偏远山区·当代”，也可以写“韩国·首尔·当代”。不要把“韩国”自动写成“韩漫”，也不要把“美国”自动写成真人电影。

## 媒介

媒介决定材质、渲染方式和角色比例；它与国别、题材、视觉风格分开记录。

| 媒介 | 生产约束 |
| --- | --- |
| 真人 | 真实人体、服装、材质和摄影光；不得出现插画或 CGI 皮肤 |
| 二维动画 | 线稿、平涂或手绘上色、二维层次和动画比例；不得漂移为照片或三维塑料 |
| 三维动画 | 体积、材质、灯光和三维空间连续；不得退化为二维平面或游戏 UI |
| 定格/手工媒介 | 纸张、粘土、木偶或微缩布景的可见手作痕迹；不得变成光滑 CGI |

## 选择规则

- 一个项目选择一个比例、一个媒介和一个主视觉风格；国别可以是一个国家加一个地域。
- 风格 ID 原样写进视觉风格 `project.visualStyle`。显示名称只用于人读，不能替代 ID。
- `jc-film-style` 将比例、媒介、国别和风格原样写进项目方向。
- 角色、场景、道具可以补充局部材质或时代要求，但不得覆盖项目主风格。
- 没有明确选择时写“未明确”；不要从国别、题材、导演或参考作品推断风格。
- 风格小类只描述生产规则，不指定具体艺术家、导演、作品或版权角色。

## 最终确认格式

```text
比例：9:16
国别/地域：美国·偏远山区·当代
媒介：真人
风格大类：真人
风格小类：冷暖对比电影
风格 ID：cinematic-contrast
```
