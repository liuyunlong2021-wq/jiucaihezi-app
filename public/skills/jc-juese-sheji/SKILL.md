# jc-juese-sheji｜环境中的单角色设计

以一张有气氛的单角色画面建立可复用的角色身份：角色处在与自身经历、职业、时代或物种相符的环境里，有可信的当下状态，面貌、体态和造型仍清晰可辨。输出可直接生图的提示词，用户选定实际图片后可用于后续参考板和视频。

## 依据与补全

- 读取本轮相关人物小传、背景与世界规则、已确认创作方向和用户指定的参考素材；独立请求只需已有描述，不强制补建项目资料。
- 用户明确要求和已确认设定优先于默认值。保留人物年龄、性别、身份、时代地域、身体特征和已定造型；不默认成人女性、年轻、美貌或现代时装。普通人、老年人、丑角、动物、异形与怪物均可设计。
- 区分原作事实和本轮视觉设计。原作未给的衣服、发型或环境细节可合理补全，但不能写回为原作事实；不凭空增加人物经历、关系、伤病、能力或剧情事件。关键设定相互冲突时询问冲突点，其余按现有信息推进。
- 有参考图时先查看图片，按用户说明区分身份参考、服装参考、风格参考。用户要求延续已有身份时保留可见特征，不为美化而换脸；纯风格参考不自动继承其人物身份。

## 角色类型与画风分别确定

角色类型决定形体设计，画风决定表现方式，两者不能互相替代。

| 类型／媒介 | 设计重点 |
| --- | --- |
| 真人与人形角色 | 脸部骨骼与五官组合、年龄感、发型、体态、服装结构与穿着状态；选少量稳定辨识特征，避免统一模板脸 |
| 喜剧或丑角 | 将用户要求落实为具体轮廓、比例、表情习惯和造型；保留人物生活感，不默认丑陋等于邪恶或缺陷等于笑点 |
| 动物、怪物及非人角色 | 先确定身体轮廓、尺度、肢体数量与连接、头部及感官结构、表面材质和运动／支撑方式，再安排姿势；没有人脸或双手时不套五官、手势与人类站姿 |
| 真人摄影 | 自然面貌、真实衣料与皮肤、可信环境光，生活照式状态；按构图选择摄影术语，不默认棚拍精修 |
| 二维漫画／动画 | 对应画风的线条、色块、阴影、轮廓和形体概括，不混入真实照片毛孔、相机散景与皮肤次表面散射 |
| 风格化三维动画 | 统一的形体夸张程度、面部结构、材质与三维光照，不自动等同于真人皮肤或照片质感 |
| 写实三维／CG | 合理形体、材质与空间光照；可采用写实质感，不同时要求“绝非CGI” |

有既定成片画风时默认直接按该画风出环境角色图。用户也可明确选择先用真人生活照确定人形角色，再在格式阶段转画风。未指定画风时，普通人类采用自然写实摄影；明确非人幻想角色可采用写实幻想表现并简短注明假设，不能把怪物改成人。其他媒介按用户要求设计，不堆叠互相冲突的风格词。

## 让环境与状态共同支撑角色

1. **选所属环境。** 从职业、生活条件、时代地域、世界规则或用户场景里选择一个可信地点。用少量空间、材质和生活痕迹建立归属，不给每个角色统一套咖啡馆、豪宅或霓虹街道。环境图服务于角色定形，不替代空镜场景资产。
2. **给一个当下状态。** 选择符合人物及当前情境的简单瞬间，例如收工后松开袖口、在熟悉的工作台前停下、雨后在自己的巢穴入口警觉观察。用重心、肩颈、目光、表情或非人身体张力表达状态，避免只写“有气质”。场景小动作属于视觉设计，不伪装成已发生的原剧情。
3. **建立气氛。** 通过具体光源、光线方向与软硬、时间天气、色彩和前后景关系传达情绪；只保留与人物有关的细节。光影在脸、服装和环境上须有一致来源。气氛感不等于统一暗调、过量雾气、强轮廓光或夸张表演。
4. **让身份可读。** 画面只有一个主体角色，避开背景人群和镜面重复人像。姿势自然而稳定，脸或关键身份部位可见；不默认闭眼、纯背影、遮脸、极端俯仰角或运动模糊。根据目标选择中景、四分之三身或全身：人脸定形可偏中近景，服装及非人轮廓定形优先完整身体。不要在远景堆砌看不见的细节。
5. **控制环境分量。** 环境可辨但不能压过角色，主体与背景有足够明度、色彩或空间分离；不靠过浅景深把环境抹掉，也不靠黑暗隐藏外貌。道具只保留支撑身份或动作的少量物件，不遮挡关键造型。

表情与光影是此刻状态，不能当成永久外貌。写实感来自具体身体与环境关系，不能靠 beautiful、handsome、masterpiece 等词替代设计；也不为普通、老年或怪物角色自动美化和年轻化。

## 交付与后续使用

- 默认交付一条完整英文生图提示词，用户指定语言、长度或候选数量时遵循；不强凑字数，不默认输出多套让用户反复选择。需要说明重要假设或设计补全时在提示词外简短标明；没有缺口时直接交付提示词。
- 提示词自然衔接：目标媒介与单角色身份 → 可见外貌、形体与造型 → 所属环境与当下动作状态 → 光影色彩 → 景别角度与主体可读性。参考图与文字职责保持一致。
- 本阶段交付单幅环境角色图提示词，不加入三格、多视图、中灰无缝背景、无头人台或正背面拼板指令。
- 一张环境图不能展示全部结构。后续需要背面服装、隐藏配饰或完整身体而原图不可见时，标明未定；沿用已有设定或作为待确认设计补充，不能声称这些细节已被图片锁定。用户需要补充角色视角时仍可在本 Skill 下沿用同一身份与造型设计，不自动扩展为多轮生图。
- 用户带入或选定实际角色图后，画风与参考板排版交给 [jc-juese-geshi](../jc-juese-geshi/SKILL.md)；已有合适图片时可跳过本 Skill。现有格式模板适用于人形，四足、蛇形等角色不能硬套无头人台，需先按用户需求明确适配版式。
- 写提示词不自动触发生图。用户要求生成时由当前调用方处理；在 `jc-manju-zhizuo` 路线中遵循其异步提交规则，取得队列任务号后返回，不等待或轮询。
