# 逐章规划与章内分集

只沿原作真实章节推进，不跨章重组。先读取本轮要求、wiki_read_guidance(overview)、`改编方案/项目总纲.md`、本章完整原文及必要前章结束状态、原作/改编版相关人物关系与规则。已有`逐章规划.md`或旧`分集规划.md`先沿真实index读取，不创建平行真源。旧总路由已取消，不调用不存在的Skill或拆分工具；原文可直接读取时直接按原有章界工作。材料不可读或章标题不能唯一定位时具体报告，不凭空造章。

## 逐章定首尾

一章可拆成多集，每集只取本章一段连续原文；全局集号连续，按章顺序排列，不将两章并入同一集。不要机械按字数切，按章内实际事件、动作因果、情绪变化和完整对白找自然落点。**每集不超过3分钟**：按有效对白和动作估算（打戏逐招展开后会变长，一并计入，说明性描写不计），超时就在本章内多拆一集，下限不限。

每章列：真实章标题及来源路径；涉及的集号。每集只写：

**集号｜本集主冲突/情绪｜真实起点与开头｜真实终点与结尾｜预估时长｜原文切分路径**

- 起点、终点必须是该章实际原文，不根据梗概编造开头或结尾。一个完整动作因果或对白接话不随意切断。
- 可为章内戏选择有力的开头/结尾，但不得跳过中间内容、重叠占用，或挪邻集大段原文来制造钩子。全章切分连续覆盖，只有排版空白可略去。
- 结尾有真实期待就保留；原作局部收束或末集结局就兑现，不凭空加悬念。上一集结束状态只作为衔接证据，不再演一遍上一集。
- 用户指定时长/集数与章内完整事件冲突时，先调整本章切点或具体报告，不跨章凑集、不偷删关键事实或加戏。

## 保存真实切分

规划用wiki_save_artifact(artifact_kind=adaptation_episode_plan)保存到`改编方案/逐章规划.md`；工具遇到既有旧规划会复用原路径，新旧同时存在时报告歧义，不擅自搬迁。

每集调用同一工具，artifact_kind=adaptation_cut，episode_number为实际全局集号，content传JSON：

`{"source_path":"真实原文文件路径","chapter_heading":"原文完整章标题","cut_start":"本集开头至少12字符的唯一原文","cut_end":"本集结尾至少12字符的唯一原文"}`

章标题支持常见中文第N章/回/节/集、序章/楔子/尾声、Chapter N及其Markdown标题；不支持的格式先明确定位问题，可复用现有导入得到带真实章标题的可读副本，不能默默把全书当一章。短于12字符的章使用完整正文定位。

程序从该章原文件截取正文，保存`改编方案/分集切分/第001集原文.md`等，并记录来源、章、范围和哈希。不要用模型复写代替原文，不用普通write绕过切分。先核对回执和全章覆盖，再交[jc-duanju-xiezuo](../jc-duanju-xiezuo/SKILL.md)逐集改编。

修改既有规划先读完整目标和相关切分/集稿；只重切授权章范围，明确已成稿集受影响，不自动改写其他章。普通模式明确请求原创分集时保留[独立写作旧规则](references/独立写作旧规则.md)，本改编流程不加载。
