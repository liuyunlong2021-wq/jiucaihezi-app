常见问题

必须登录才能用吗？

不必须。韭菜盒子是本地优先工具，也支持自带模型密钥：在 App 的“设置 → 账号”里填入你自己的 API Key 并保存，就能直接使用，不需要注册账号。

登录不成功，或者点了没反应怎么办？

一键登录需要账号服务可达，网络受限时会失败。这种情况下改用上面说的 API Key 方式，功能不受影响。仍然失败请邮件联系我们，并附上错误提示。

我的项目数据存在哪里？

默认保存在你自己的设备本地。只有你主动同步的纯文字（对话 Raw、Wiki 和普通文本）会进入云端；图片、音频、视频等媒体不会上传。

怎么反馈一个 Bug？

写清三件事：你做了什么 → 期望发生什么 → 实际发生了什么。附上版本号和截图会快很多。

账号注销

iPhone 用户可在 App 的“设置 → 账号 → 注销账号”中发起永久注销。注销会删除账号和云端文字同步数据，但不会自动删除手机中的本地项目与媒体。无法进入 App 时，也可以通过上面的邮箱联系我们处理。
